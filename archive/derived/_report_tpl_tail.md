### 6.1 【几何与拓扑｜2018｜Individual｜第 2 题】Hopf 不变量的公理化构造

**题面（原文）**：
> 2. Consider a smooth map f : S^{2n−1} → S^n with n ≥ 2. Let ν be a volume form on S^n with volume 1.
> a). Show that f*ν is exact.
> b). Write f*ν = dα. Show that the integral ∫_{S^{2n−1}} α ∧ f*ν is independent of the choice of α.
> c). Show that the integral above is actually an invariant of the homotopy class of f.
> d). Show that the integral is 0 if n is odd.
> e). Calculate this integral if f is the Hopf map (z0, z1) ↦ [z0, z1].

**思路**：
1. (a) f*ν 是 2n−1 维流形上的 n-形式，n < 2n−1（n ≥ 2），de Rham 上同调 H^n(S^{2n−1}) = 0 ⇒ 闭形式必恰当；
2. (b) 若 α' = α + dβ，则 ∫α'∧f*ν − ∫α∧f*ν = ∫dβ∧f*ν = ±∫d(β∧f*ν) = 0（Stokes，无边）；
3. (c) 同伦 f_t 给出 S^{2n−1}×I 上的链同伦，把 ∫α_t∧f_t*ν 的导数写成恰当项积分；
4. (d) n 奇时对径映射 a 满足 a*(f*ν) = (−1)^n f*ν = −f*ν 且 deg a = (−1)^n = −1，配合同伦不变性得积分为 0；
5. (e) Hopf 映射时该积分就是 Hopf 不变量，值为 1（Hopf 纤维化的生成元）。

**核心考点**：de Rham 上同调、Stokes、映射度、同伦不变量（同一卷第 4 题又用 Künneth + 相交数考了同一套工具）。

### 6.2 【几何与拓扑｜2020｜Overall（全能）｜第 2 题】Bochner 技巧一次打通 b₁ 与 λ₁

**题面（原文；PDF 文本层把数学字体错映射，已按数学语义还原）**：
> Problem 2 Let (M^n, g) be a closed, orientable n-dimensional Riemannian manifold with positive Ricci curvature.
> (a) Prove that the first Betti number b₁ of M vanishes.
> (b) Suppose Ric_M ≥ (n − 1)λ > 0, show that λ₁ ≥ nλ, where λ₁ is the first eigenvalue of the Laplace-Beltrami operator Δ on (M, g).

**思路**：
1. (a) Hodge 定理：b₁ = dim{调和 1-形式}。对调和 1-形式 ω 用 Weitzenböck/Bochner 公式 ½Δ|ω|² = |∇ω|² + Ric(ω, ω)；由 Ric > 0 得 Δ|ω|² ≥ 0，极大值原理 ⇒ |ω|² 为常数且 ∇ω = 0 ⇒ ω ≡ 0，故 b₁ = 0；
2. (b) 对第一特征函数 f（Δf = −λ₁f）用 Bochner 公式 ½Δ|∇f|² = |Hess f|² + ⟨∇f, ∇Δf⟩ + Ric(∇f, ∇f)，配合 |Hess f|² ≥ (Δf)²/n 与 Cauchy-Schwarz 积分，得到 λ₁ ≥ nλ（Ric ≥ (n−1)λ 的标准 Lichnerowicz 估计）。

**核心考点**：Bochner–Weitzenböck 公式、极大值原理、Lichnerowicz 特征值估计——这是决赛几何卷 2020 之后最反复出现的"S 级工具"（2021 Individual Q3、2023 Overall Q2 都考同族）。

### 6.3 【几何与拓扑｜2024｜Team｜第 3 题】∇ω ∝ g 的 1-形式（附 .tex 原文校验）

**题面（原文，直接取自官方 .tex 源，公式无损）**：
> Let (S², g) be the two-dimensional unit sphere with the standard round metric g and ∇ be the covariant derivative associated with g. Suppose ω is a smooth differential 1-form on S² such that ∇ω is proportional to g at each point.
> (1) Find all such ω.
> (2) What is the diffeomorphism (of S²) generated by the dual of ω?

**思路**：
1. ∇ω = λ(x)·g 是**对称**张量 ⇒ dω = 0；S² 上 H¹ = 0 ⇒ ω = df 全局；
2. 于是 Hess f = λg，取迹得 Δf = 2λ，再取散度（div(Hess f) = d(Δf)、div(g) = 0）得 Δf 为常数 μ，于是 Hess f = (μ/2)g；
3. 在 S² 上满足 Hess f = −f·g 的函数恰是一次球谐（f = c + a·x，a ∈ R³），故 λ = −f、ω = d(a·x)；
4. (2) ω 的对偶向量场是 grad f = a − (a·x)x，即绕轴 a 的旋转 Killing 场，其流就是绕轴 a 的旋转。

**核心考点**：Codazzi/共形 Killing 张量、Hodge 分解、球面一次球谐函数——一道题同时考微分几何与李群作用。

### 6.4 【几何与拓扑｜2019｜Individual｜第 1 题】T*S^{n−1} 的 Euler 类与辛结构

**题面（原文）**：
> (1) Let M = {(x₁, y₁, · · · , x_n, y_n) | Σ_{i=1}^n (x_i)² = 1, Σ_{i=1}^n x_i y_i = 0} ⊂ R^{2n}. Show that (a) M is a smooth manifold and a vector bundle over the (n − 1) dimensional sphere. Compute the Euler class of this vector bundle. (b) M is a symplectic manifold, i.e. there exists a non-degenerate closed 2-form on M.

**思路**：
1. (a) 把 (x, y) ∈ R^n × R^n 看成"底点 x ∈ S^{n−1} + 切向量 y ⟂ x"，故 M ≅ T*S^{n−1}（也 ≅ TS^{n−1}，用圆度量认同两者）；
2. Euler 类：e(TS^{n−1}) = χ(S^{n−1})·[S^{n−1}]，在 H^{n−1}(S^{n−1}; Z) ≅ Z 中，n−1 为奇数（n 偶）时 χ = 0 ⇒ e = 0；n−1 偶（n 奇）时 χ = 2 ⇒ e = 2·生成元；
3. (b) 余切丛自带典范辛形式 ω = −dθ（θ 为 tautological 1-形式），在坐标下即 ω = Σ dx_i ∧ dy_i 在 M 上的限制，它闭且非退化。

**核心考点**：向量丛、Euler 类与 Gauss-Bonnet、余切丛的辛结构（同一工具在 2025 Individual Q1、2025 Overall Q1 反复出现）。

### 6.5 【概率与统计｜2023｜Individual｜第 1 题】从 Poisson 尾部到 Stirling 公式

**题面（原文）**：
> Problem 1. Suppose that Y_n ∼ Poisson(n) is a Poisson random variable with parameter n ∈ N* = {1, 2, · · ·}.
> (1) Calculate E(Y_n − n)₊, where x₊ = max{x, 0}.
> (2) Prove that E(Y_n − n)₊/√n converges to E N₊ as n → ∞, where N ∼ N(0, 1) (standard normal).
> (3) Use the above results to derive Stirling's formula for the factorial n!.

**思路（完整的漂亮链条）**：
1. (1) 对整值随机变量用 k·P(Y=k) = n·P(Y=k−1) 得
   E(Y_n − n)₊ = Σ_{k≥n+1}(k−n)P(Y=k) = n·P(Y_n = n) = n^{n+1}e^{−n}/n!；
2. (2) 将上式除以 √n 并用 n! ~ √(2πn)(n/e)^n（这正是要证的公式，闭链时需用独立证法，例如 CLT + 局部极限定理）得极限 = 1/√(2π) = E N₊；
3. (3) 由 E(Y_n−n)₊ = n^{n+1}e^{−n}/n! 与 (2) 的极限反解即得 n! ∼ √(2πn)(n/e)^n。
   ——第三步是本题的"钩子"：把 Stirling 公式化归为一个几行可算的 Poisson 期望。

**核心考点**：Poisson 尾恒等式、CLT/局部极限定理、渐近分析的"互相推导"技巧（同一技巧见于 2016 Individual Q1 的 √X_λ − √λ 极限）。

### 6.6 【概率与统计｜2021｜Individual｜第 3 题】二叉树上的大偏差与临界 β_c（语料含官方解答）

**题面（原文）**：
> Problem 3. A binary tree is a tree in which each node has exactly two descendants. Suppose that each node of the tree is coloured black with probability p, and white otherwise, independently of all other nodes. For any path π containing n nodes beginning at the root of the tree, let B(π) be the number of black nodes in π, and let X_n(k) be the number of such paths π for which B(π) ≥ k.
> (1) Show that there exists β_c such that lim_{n→∞} E(X_n(βn)) = 0 if β > β_c and = ∞ if β < β_c. How to determine the value of β_c?
> (2) For β ≠ β_c, find the limit lim_{n→∞} P(X_n(βn) ≥ 1).

**思路（官方解答要点）**：
1. 路径数 2^{n−1}，每条路径的黑节点数 ∼ Binomial(n, p)，故 E(X_n(k)) = 2^{n−1}P(S_n ≥ k)；
2. 用大偏差/Cramér 定理：P(S_n ≥ nβ)^{1/n} → (p/β)^β((1−p)/(1−β))^{1−β}，于是 E(X_n(βn)) 的极限由 γ(β) = 2(p/β)^β((1−p)/(1−β))^{1−β} 与 1 的大小决定，β_c 由 γ(β_c) = 1 唯一确定（p < 1/2 时；p ≥ 1/2 时 β_c = 1）；
3. (2) β > β_c 用 Markov 不等式 P(X ≥ 1) ≤ E X → 0；β < β_c 用 Paley–Zygmund 不等式 P(N≠0) ≥ E(N)²/E(N²)，关键是估计二阶矩——把两条路径重叠 m 个节点的情况求和并用 p^{−m} 界住，得 Σ(2p)^{−m} 型几何级数；
4. 结论：P(X_n(βn) ≥ 1) → 0（β > β_c）、→ 1（β < β_c）。

**核心考点**：大偏差率函数、一阶/二阶矩法、Paley-Zygmund——语料中**唯一带完整官方解答**的决赛概率题（`2021 Probability (Individual) (Solutions).pdf`），可作为"决赛题标准解法深度"的标尺。

### 6.7 【概率与统计｜2025｜Individual｜第 3 题】动态随机环境中的一维随机游走

**题面（原文）**：
> Problem 3. Let (X_n)_{n≥0}, with X₀ = 0, be a discrete time simple random walk on Z in a dynamic random environment defined as follows. Fix a > 0. At each time n ≥ 0, every undirected edge e := {i, i+1} is assigned a conductance C_n(e) with C_n(e) = 1 if e has not been crossed by time n, and C_n(e) = a if e has been crossed before. Given X_n = x ∈ Z and the conductance configuration C_n(·) at time n, the random walk jumps to either x+1 or x−1 with probability P(X_{n+1} = x ± 1 | X_n = x, C_n) = C_n({x, x±1}) / (C_n({x, x+1}) + C_n({x, x−1})).
> Show that, almost surely, X will return to 0 infinitely many times.

**思路**：
1. 关键观察：任意时刻所有电导取值于 {1, a}，故 **一致地有 C_n(e) ∈ [min(1,a), max(1,a)]**；
2. 电导网络上的一维随机游走：常返 ⟺ Σ_e 1/C(e) = ∞（有效电阻无穷）。由于电导有正下界 min(1,a) > 0，Σ_e 1/C(e) = ∞，故"冻结环境下的每一段"都是常返的；
3. 处理"环境随时间演化"的难点：可先在首次走到某个新边时做一次"探索"论证（每次进入未走过的区域只增加常数倍的电导总量），或用鞅/更新论证证明 ∑ P(从 X_n 再回到 0) = ∞ 后再用 Borel-Cantelli（需条件化处理）；
4. 结论：0 是几乎必然无穷次返回的常返点。

**核心考点**：电导网络与有效电阻、常返/暂留判据、随时间变化的随机环境——2025 年新题，代表决赛概率卷"研究型问题"的最新风向。

### 6.8 【概率与统计｜2012｜Individual（概率卷）｜第 1 题】三点分段的三角形概率（语料含官方解答）

**题面（原文）**：
> Problem. Take two points ξ and η randomly and independently with respect to the uniform distribution from the unit interval [0, 1]. Then in general these two points divide the interval [0, 1] into three subintervals with lengths X, Y and Z, respectively.
> (1) What is the probability that X, Y and Z constitute the lengths of three sides of a triangle in the plane?
> (2) What are the probability distributions of X, Y and Z?

**思路（官方解答）**：
1. (1) 设 0 ≤ ξ < η，则三段为 ξ, η−ξ, 1−η；能成三角形 ⟺ ξ < 1/2、η−ξ < 1/2、η > 1/2，该区域面积 1/8；由对称性再乘 2 得 **P = 1/4**；
2. (2) X = min{ξ,η}、Y = |ξ−η|、Z = 1−max{ξ,η}，三者分布函数都是 F(t) = 1 − (1−t)², t ∈ [0,1]（其中 Y 的分布由条带区域积分得到）。

**核心考点**：几何概率、次序统计量的分布——决赛早期（2012）仍是"经典口试题 + 官方解答"风格，与 2023–2025 的研究型题形成鲜明对照。
