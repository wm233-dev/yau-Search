Yau College Math Competition 2024
Final Probability and Statistics
Individual Exam Problems (June 8-9, 2024)
Choose at least 3 from the following 4 problems.
Problem 1. Let {Xi}i≥0 be iid with density function f and distribution function
F. Define N = min{n ≥1 : Xn > X0}.
(1) Find the distribution function of XN.
(2) If E|X0| < ∞, is it always true that E|XN| < ∞? If yes, prove it; if not, give
a counterexample.
Problem 2. A fair coin is tossed repeatedly and independently, and the outcome
is denoted as X1X2 · · · with Xi = H (head) or T (tail).
(1) Describe an idea about how to find the expected number of tosses required
until a particular pattern of heads/tails appears.
(2) Evaluate the expected number of tosses to get the special pattern HTHH,
i.e., evaluate E(N), where N = min{n ≥4 : Xn−3Xn−2Xn−1Xn = HTHH}.
Problem 3. Given a filtration {Fn}, i.e., F1 ⊆F2 ⊆· · · ⊆F, we define F∞=
σ(∪∞
n=1Fn).
(1) Is it correct that F∞= ∪∞
n=1Fn? If not, please give a counterexample.
(2) Let X be a random variable which is F-measurable and integrable. Prove
{E(X|Fn)}n≥1 is uniformly integrable.
(3) Prove E(X|Fn) →E(X|F∞) in L1, as n goes to infinity.
Problem 4. Consider the least squares problem. Assume Y is the n-dimensional
outcome vector and X is the n × p covariate/design matrix. Assume X is full rank.
We can run least squares of Y on X to obtain the usual estimator ˆβ, the residual
vector ˆε, and the hat matrix H = X(XTX)−1XT.
Now we want to compute the least square coefficient ˆβ[i] by dropping the ith
observation, i = 1, . . . , n.
Instead of running the least squares n times, can we
obtain {ˆβ[i], i = 1, . . . , n} from ˆβ, ˆε, (XTX)−1, and H, so that we only need to run
the least squares only once?
