## §0 方法与口径

### 0.1 判定"同一母题"的三条准据（须同时满足前两条）

1. **数学内核相同**：把题面剥到最后一层，问的是同一个数学命题/同一个量。判定方式是写出"这题到底在求什么"的一句话——例如"把一个 i.i.d. 序列的 limsup 除以 log n 求其 a.s. 值"，而不是"属于极限定理"。
2. **解法骨架相同**：即使对象、维数、分布全换掉，标准解法的**步骤序列**（第 1 步做什么、第 k 步用什么工具）可以逐条对齐。允许 3–8 步的骨架中某一步被"升级"（换成更强的工具），但不允许出现骨架完全不同。
3. **对象可替换（加分项而非必要条件）**：换分布（指数→Poisson→几何→均匀）、换维度（R²→R^n）、换载体（记录值→排列圈数）、换语言（概率→测度→统计）之后，第 1、2 条仍成立，则视为同一母题的"换皮"再考。

**反例边界（不视为同一母题）**：
- 只共享**工具**不共享内核：例如"用 Borel–Cantelli"出现在 P-S08 型问题里，但若问题问的是特征函数、只是顺手用了一次 B-C，就不并入 §M07。
- 只共享**场景**不共享内核：同一年两道题都讲"随机图"，但一道问团数上界、一道问孤立点阈值，则必须给出共同的"阈值现象"骨架才可合并（本报告 PS-M35 即以此为准）。
- 只共享**章节标签**：这是本题库最容易犯的错。诸如"都属于假设检验""都属于鞅"不构成母题；必须写出共有的命题。

### 0.2 记录粒度与"一记录多小题"的处理

本题库的 PDF 抽取存在**跨题截断/并题**现象（公式或题号被切到相邻记录），尤其是 2010 与 2012 两届：

- `(2010, individual, 3)` 以半截公式开头，其主体是正态二次型比值题；
- `(2010, team, 2)` 被截断在 `Yn,i =`，其主体是自归一化 CLT 题；`(2010, team, 3)` 开头带着上题的尾巴；
- `(2012, individual, 2)` 同时包含"依概率收敛的乘积"与另一题的 `E[X|G]`、`E(X|X+Y)` 两个小问；
- `(2012, team, 2)` 同时包含 Poisson 的 limsup 题与"几何个指数之和的分布"。

**处理原则**：以记录（`year/kind/n`）为最小成员单位，按该记录的**主体**内容归属唯一一个母题；被并进来的次要小题在 §2 的成员说明里点名，不另计成员，也不重复计数（因此 JSON 中不存在一条记录出现在两个母题里的情况）。这样统计口径（覆盖率）才有意义。

### 0.3 排除项

- `(2010, individual, 5)`：`(ST − λI)x = b` 的 O(n²) 算法（数值线性代数）；
- `(2010, individual, 6)`：SVD 存在性与 Eckart–Young 定理（矩阵分析）；
- `(2010, team, 5)`：有限差分格式的 L²/L^∞ 稳定性；
- `(2010, team, 6)`：`u_t + Au_x = 0` 的适定性与分裂格式稳定性。

这 4 条虽被标为 Probability & Statistics，但内核完全是线性代数/数值 PDE，**不纳入任何母题，也不计入"孤题"**，仅在覆盖率里单列。

### 0.4 "升要求 / 换皮 / 原样重复 / 降要求"的操作定义

- **原样重复**：题面与解法骨架几乎逐字相同（本题库 16 届内**没有**真正的原样重复，只有下面两类）。
- **换皮**：内核与骨架不变，更换对象/分布/场景，或只是问法从"证明"变成"计算"。
- **升要求**：后一版本在同一骨架上**多加了一步或收紧了一档**——例如从"证明某个界存在"升级为"求出最优常数/临界阈值"，从"一维"升到"n 维"，从"给定结论"升到"先证引理再推广"，或从"证明命题"升级为"证伪并构造反例"。
- **降要求**：后一版本给出更多提示或只要求单侧。（本报告中仅个别题在 2016 年团体卷附带"Hint:"式分步引导，记为降要求倾向，单列在成员说明里。）

## §2 母题逐条剖析

> 每个母题给出四块内容：**数学内核**（这题到底在考什么）、**成员逐一对照**（该年版本与母题的差异）、**递进关系**（升级链）、**标准解法骨架 + 最易卡的一步**。

### PS-M01 部分和/平均的几乎必然收敛与可积性（4 题｜2010–2019）

**数学内核**：一个独立（或仅不相关/两两独立）的序列，其部分和 S_n 或平均 S_n/n 何时收敛、以什么速度收敛；反过来，若"平均已经收敛"，能否反推出单个变量的矩有限。考的**不是**"大数律"这个名字，而是三个具体动作：把尾事件截断、对截断部分用可加性最强的不等式、以及用 a.s. 收敛行为反推分布的可积性。

**成员对照**
- **2010 个人 2**｜两两独立、EX_i = 1 + i^{−1}、max E|X_i|^{1+ε} < ∞，证 `(1/n)ΣX_i →P 1`。这是**弱**大数律：两两独立只能保证方差可加，必须先用 ε 阶矩把变量截断到 O(n) 量级再算方差。
- **2014 个人 2**｜不相关、均值零、`Σ nE|X_n|² < ∞ ⇒ S_n` a.s. 收敛。对象从"平均"换成"级数本身"，工具换成部分求和（Kronecker）+ Borel–Cantelli，权重 n 正好补偿"级数需要每个 X_n 衰减"。
- **2015 个人 3**｜独立 Gauss：`ΣX_n²` 的 L¹ 收敛 ⇒ 任意 L^p 收敛；`Σσ_n² = ∞ ⇒ P(ΣX_n² = ∞) = 1`。对象换成**平方和**，靠正态的三级数定理与 0-1 律（平方和要么 a.s. 收敛要么 a.s. 发散）。
- **2019 团体 2**｜反方向：`S_n/n → c` a.s. ⇒ E|X_1| < ∞ 且 EX_1 = c。这是把"几乎必然行为"反过来约束分布，是本题组里最"反直觉"的一步。

**递进关系**：2010（弱大数律，平均）→ 2014（级数 a.s. 收敛）→ 2015（平方和 / 0-1 律）→ 2019（**由 a.s. 收敛反推可积性**）。前三次是"收敛性越来越强、对象越来越非线性"，第四次是方向反转。

**解法骨架**
1. 截断：X_i^M = X_i·I(|X_i| ≤ M)，把问题分成主项 + 尾项；
2. 主项用与题目独立性假设匹配的不等式（两两独立 → Chebyshev；独立 → Kolmogorov/三级数）；
3. 沿子列用 Borel–Cantelli 得 a.s. 收敛，再用相邻项差补全整列；
4. 尾项用 `Σ n E|X_n|² < ∞` 或 ε 阶矩控制 P(|X_i| > M) 的可和性；
5. 收敛性的尺度换算（S_n/n vs S_n vs ΣX_n²）；
6. 反向命题：由 X_n = S_n − S_{n−1} 得 |X_n|/n → 0 a.s.，配合独立性/Borel–Cantelli 得 `ΣP(|X_1| ≥ n) < ∞`，再用积分判别法得 E|X_1| < ∞。

**最易卡的一步**：第 6 步。很多人会写"因为 sup|S_n|/n < ∞ 所以 E|X_1| < ∞"——这是循环论证。必须显式地把 S_n/n → c 转成 `|X_n|/n → 0` a.s.，再用"i.i.d. + 第二 Borel–Cantelli 引理"说明若 E|X_1| = ∞ 则 `ΣP(|X_1| ≥ εn) = ∞`，从而 |X_n|/n ≥ ε 无穷多次，矛盾。

### PS-M02 多项/离散结构模型的 MLE、似然比检验与渐近分布（4 题｜2010–2023）

**数学内核**：观测是多项（或复合二项）计数，而参数以**非线性且带约束**的方式进入各组概率（p_1 = θ³, p_2 = 3θ(1−θ), p_3 = (1−θ)³；p_3 = 3p_1；"1+1"罚球的 N_0,N_1,N_2）。要写的是一整条流水线：似然 → 约束 MLE → 信息矩阵/delta 方法给渐近正态 → LRT 统计量与其 χ² 零分布。

**成员对照**
- **2010 个人 4**｜p_1=θ³, p_2=3θ(1−θ), p_3=(1−θ)³：(a) 构造近似水平 1−α 的 MLE 置信集；(b) 求频率替代估计 `θ̂_2 = 1 − (N_3/n)^{1/3}` 的渐近分布。第二问是典型的 **delta 方法**题。
- **2010 团体 4**｜"1 and 1"罚球：三格计数 (N_0,N_1,N_2) 的概率是 p 的二/三次多项式。(a) 写似然；(b) MLE = (N_1+2N_2)/(N_0+2N_1+2N_2)；(c) **是否无偏**（提示 E p̂ 是 p 的高于一次的多项式，故无偏当且仅当它是 p，可用端点/次数论证证伪）；(d) 渐近分布。
- **2014 个人 5**｜三色抽样、p_3 = 3p_1：求 MLE(p_2) 的渐近分布；再对 H_0: p_1 = p_2 = p_3/3 构造 LRT 并给零分布（自由度 = 约束数）。
- **2023 个人 6**｜对象升级为**不可观测混合模型**：S~Poisson(2λ)，X、Y 条件独立 Bernoulli 且 P(X=1|S=s) = 1/2^{s+1}、P(Y=1|S=s) = θ/2^s。(a) 直觉估计 θ̂_n = Ȳ/(2X̄) 的渐近分布（用 E X = 1/4 消去 λ，再用多元 delta 方法）；(b) 对 θ=1/2 构造**精确**检验，并列举所有能提高功效的来源。

**递进关系**：2010 个人（给定参数化，求 MLE 与置信集）→ 2010 团体（同一模型再加一问"无偏性辨析"）→ 2014（**加约束假设 + LRT 零分布**）→ 2023（参数不可直接观测，先造矩估计再证渐近正态，且从"渐近"升级到"精确检验"）。

**解法骨架**
1. 写出似然 `∏ [p_j(θ)]^{N_j}`（或 `∏ f(y_i;θ_i)`），明确参数约束；
2. 求约束 MLE：拉格朗日乘子，或重参数化到自然参数后解 score 方程；
3. 算 Fisher 信息 I(θ)（对角化二阶导），得 `√n(θ̂−θ) →d N(0, I^{−1})`；
4. 对关心的函数 g(θ)（p_2、`1−(N_3/n)^{1/3}`）用 delta 方法；
5. `−2logΛ = 2(ℓ(θ̂) − ℓ(θ̂_0))`，在 H_0 下收敛到 χ²_{df}，df = 被约束的参数个数；
6. 讨论无偏性/功效时把 E g(θ̂) 展开到二阶，或写出非中心参数。

**最易卡的一步**：**似然的"结构参数—自然参数"分离**。2010 团体 4 中，只有把 (N_0,N_1,N_2) 的概率写成 p 的多项式并注意到它关于 p 的次数 ≥ 2，才能证伪无偏性；而在 2023 中，必须看出 E X = 1/4 与 θ 无关，才能用 Ȳ/(2X̄) 把 λ 消掉——漏掉这一步会误以为 θ 不可估。

### PS-M03 归一化比值导出 Beta / Dirichlet / F（3 题｜2010–2015）

**数学内核**：把一组独立的 Gamma（或正态二次型）随机变量做**归一化**——除以它们的和、或取两个和之比——结果落在 Beta / Dirichlet / F 族里。考的是"独立 Gamma 的可加性 + 归一化后与总量的独立性 + 雅可比变换"这套机器，而不是某个分布的名字。

**成员对照**
- **2010 个人 3**｜正态二次型之比：`U² = (Z_1Z_2+Z_3Z_4+Z_5Z_6)²/(Z_2²+⋯+Z_6²)`，以及在此基础上的 V²，要求求出并识别密度。（该记录被 PDF 截断，公式有残迹；核心是分子分母不独立，必须做正交变换。）答案为 Beta 型。
- **2012 个人 6**｜指数和之比 `X = (E_1+⋯+E_m)/(E_1+⋯+E_n)`（Beta(m, n−m)），再由 `Y = (n−m)X/(m(1−X))` 得到 F(2m, 2(n−m))；最后求 `(U_1⋯U_n)^{−X}` 的密度——这一小问必须把"X 与 U 独立"讲清楚才能得到 Beta 与均匀分布拼起来的密度。
- **2015 团体 3**｜指数向量归一化 `V_n = (T_1/S_n, …, T_n/S_n)` 的**联合**分布 = Dirichlet(1,…,1)，即 n−1 维单纯形上的均匀分布。从"两个数之比"升级到"整条向量的联合分布"。

**递进关系**：2010（二次型之比，识别单个 Beta）→ 2012（和之比 ⇒ Beta ⇒ 再转 F，并与均匀分布拼装）→ 2015（**向量化**：联合 Dirichlet，从比值升到单纯形上的分布）。

**解法骨架**
1. 把分子分母写成独立 Gamma（卡方）变量之和；若分子分母不独立，先做正交变换使其独立；
2. 写联合密度，换元 `(x,y) → (u = x/(x+y), v = x+y)`（或球面坐标）；
3. 对多余变量积分（Gamma / Beta 积分），得 u 的边缘密度；
4. 与 Beta(p,q) 或 Dirichlet(α) 的标准密度比对，读出参数；
5. 比值变换 `s = (n−m)X/(m(1−X))` 把 Beta 转 F；
6. 联合情形直接用 Dirichlet 密度（并注意归一化后与总量的独立性）。

**最易卡的一步**：2010 个人 3 中"分子与分母不独立"的识别与处理。若误以为 `(Z_1Z_2+Z_3Z_4+Z_5Z_6)` 的分母就是它的方差，会直接套 `N(0,1)/√(χ²/df)` 得到错误的自由度；正确做法是把 (Z_2,Z_4,Z_6) 与 (Z_1,Z_3,Z_5) 的关系理清，用正交变换把分子化成"若干个独立乘积之和"，再分离出真正的卡方分母。

### PS-M04 次序统计量与间距的分布及其渐近（3 题｜2010–2018）

**数学内核**：对 i.i.d. 连续样本，求次序统计量、相邻次序统计量之差（间距）或其函数的**精确分布**与**极限分布**。技术核心是次序统计量的联合密度（乘上 n!）与概率积分变换 `F(Y_j)`，渐近部分则要在分位数处做局部密度展开。

**成员对照**
- **2010 团体 1**｜精确分布：证 `F(Y_j) ~ Beta(j, n−j+1)`。这是概率积分变换 + 次序统计量联合密度的直接积分，是整族的"母版"。
- **2016 团体 5**｜圆上随机 2016 点 → 2016 段弧，求包含 (1,0) 的弧长的**期望与方差**。对象从"次序统计量"换成"间距的线性泛函"，用对称性 + 指示变量线性化。
- **2018 团体 1**｜极限分布：(a) `N = 2m−1`，中间次序统计量 `Y = X̃_m`，找 A、B 使 `(Y−A)/N^{−B}` 有非平凡极限（A = 1/2, B = 1/2 → 正态）；(b) `N = 2m`，间距 `Y = X̃_m − X̃_{m−1}`（A = 0, B = 1 → 指数）。

**递进关系**：2010（**精确**分布 Beta）→ 2016（间距函数的矩，圆上版本）→ 2018（**极限**分布：中心项 → 正态、间距 → 指数；并要求自己确定标准化尺度）。

**解法骨架**
1. 写次序统计量联合密度 `n!∏f(y_i)`，或先做概率积分变换化为均匀次序统计量；
2. 求目标量的边缘/联合密度（单个 Y_j、间距、或圆上弧长）；
3. 识别分布（Beta / 指数 / Dirichlet）或求矩；
4. 矩的计算用指示变量线性化或 Beta 的矩公式；
5. 极限：令 j = ⌈np⌉，在分位数 p 处用局部密度 f 展开，配上正确的尺度；
6. 用 Slutsky / 连续映射定理收尾，得正态或指数极限。

**最易卡的一步**：2018 团体 1 中**标准化尺度 N^B 的选择**。中心次序统计量的偏差是 O(N^{−1/2})、间距是 O(N^{−1})，两者的"量级"不同；必须先算出方差的阶（用 f(1/2) 的局部展开），否则会把间距误判成正态。判断依据：`Y − A` 的标准差是 N^{−B} 阶。

### PS-M05 条件期望作为最优预测（2 题｜2010–2014）

**数学内核**：求 `E[X | σ(观测)]` 并把它当作最优预测使用。联合正态时它是**线性投影**（解协方差方程）；非正态时要真的算条件密度；更进一步要比较"哪种观测能给出更好的预测"，这就触及充分统计量。

**成员对照**
- **2010 个人 1**｜`Z_i` i.i.d. N(µ,σ²)，求 `E(Σ_{i=1}^n Z_i | Z_1 − Z_2 + Z_3)`。观测是正态变量的线性组合 ⇒ 直接用 `Cov(X,Y)/Var(Y)` 得线性投影系数。
- **2014 个人 4**｜U(0,1) 序列，只观测 `Y_n = max` 或 `Z_n = 均值`：(a)(b) 分别求对 X_1 的"最佳猜测"；(c) 比较两者谁更好、在什么意义下更好。第二问的观测 Z_n 恰是**充分统计量**，所以它是更好的预测载体（同方差的条件下信息更多）。

**递进关系**：2010（纯计算，正态线性投影）→ 2014（**加一层判断**：必须自己给出"更好"的判据并论证）。

**解法骨架**
1. 明确观测生成的 σ-代数 G（线性组合 / 最大值 / 样本均值）；
2. 联合正态：`E[X|G] = EX + Cov(X,·)Cov(·,·)^{−1}(观测 − E观测)`；
3. 非常态：求条件密度 f(x|观测) 再积分（U(0,1) 的 max 型要用 `P(X_1 ≤ x | Y_n = y)` 的比例计算）；
4. 误差分解 `E[(X − ĝ)²] = E[Var(X|G)] + E[(E[X|G] − ĝ)²]`；
5. 比较两种观测下的 `E[Var(X|G)]`，或指出其中一个观测是充分统计量从而不劣。

**最易卡的一步**：2014 个人 4(c)。"更好"必须落到具体判据（MSE / 条件方差）上；同时要意识到 (a)(b) 的答案是 `E[X_1|Y_n]` 与 `E[X_1|Z_n]`，而 Z_n 的充分性使后者更优——这一步是把"条件期望"接回"统计充分性"的桥梁。

### PS-M06 极小极大估计与风险下界（2 题｜2010–2022）

**数学内核**：在参数空间有界或损失加权的情形下，求 `inf_δ sup_θ R(θ,δ)` 并给出达到它的估计量。工具是三件套：充分统计量降维、最小有利先验、以及"Bayes 风险 ≤ minimax 风险"的夹逼。

**成员对照**
- **2010 团体 3**｜`X_i ~ N(θ,1)`，已知 |θ| ≤ τ：证 `min_{a_1..a_{n+1}} sup_{|θ|≤τ} E(Σa_iX_i + a_{n+1} − θ)² = τ²n^{−1}/(τ² + n^{−1})`。题面明确提示"好好用充分性原理"——先用 X̄ 把问题压成一维，再解一维 minimax。
- **2022 个人 6**｜`X_i ~ N(θ_i, i²)`，加权损失 `Σ(d_i−θ_i)²/i²`：证明 X 本身是 minimax。要点是加权损失把坐标标准化为等方差，取先验 θ_i ~ N(0, i²) 后后验均值恰为 X_i 且风险恒为常数。

**递进关系**：2010（一维、约束参数空间、用充分性降维后手算）→ 2022（**p 维、加权损失**、对角化 + 最小有利先验，直接拿 Bayes 风险当 minimax 下界）。

**解法骨架**
1. 用充分统计量把估计问题降维（Rao–Blackwell 不增加风险的凸性论证）；
2. 把风险写成关于参数与估计量的二次型；
3. 猜一个候选 minimax 估计量（常是某种收缩/后验均值）；
4. 构造最小有利先验 π，使该估计量是 π-Bayes **且**风险在参数空间上恒定；
5. 夹逼：`sup_θ R(θ,δ) = 常数 = R(π,δ) ≤ inf_δ sup_θ R`；
6. 给出常数的显式值。

**最易卡的一步**：2022 中"风险恒定"的验证。只有取先验 θ_i ~ N(0, i²)，后验均值才恰好等于 X_i，且逐坐标的风险都等于 1；换任何别的先验都会破坏恒定风险，从而夹逼失效。

### PS-M07 Borel–Cantelli 与 limsup 几乎必然极限（8 题｜2012–2021）★ 本题库第一大母题

**数学内核**：把"事件概率可和"翻译成"几乎必然只发生有限次"（第一 Borel–Cantelli 引理），再用它把 i.i.d.（或仅有矩条件的）序列的 limsup **精确算出来**；以及研究这个翻译何时不可逆（逆命题需要独立同分布，否则要构造反例）。考的是一句话：**可和性 ⇒ a.s. 有限次**，但用在哪里、阈值取什么、不可和那一侧怎么处理，每题都不同。

**成员对照**
- **2012 团体 1**｜Exp(1)：`P(X_n > α log n, i.o.) = 0` (α>1) / `= 1` (α≤1)；并得 `limsup X_n/log n = 1` a.s.。可和与不可和的**临界点**恰在 α=1。
- **2012 团体 2**｜Poisson(λ)：`limsup (X_n loglog n / log n) = 1` a.s.。因为 Poisson 的尾部是 `e^{−c x log x}` 型，需要 **loglog 修正**。
- **2013 团体 2**｜数论版：Lebesgue 测度下几乎所有 x 满足 `|x − p/q| ≥ 1/(q log q)²` 对一切但有限个有理数成立。把"事件"换成"每个分母 q 的所有 p/q"，对 q 求和后套 B-C。
- **2013 个人 1**｜`ΣP(|X_n| > n) < ∞ ⇒ limsup |X_n|/n ≤ 1`；同题第二部分是依概率收敛的度量化（见 PS-M09 的成员说明）。
- **2016 团体 4**｜**逆命题证伪**：`limsup |X_n|/n ≤ 1` a.s. ⇏ `ΣP(|X_n| ≥ n) < ∞`。构造只在稀疏子列上取大值的分布，使概率和发散而 limsup 仍 ≤ 1。
- **2019 团体 1**｜Exp(1)：`P(limsup X_n/log n = 1) = 1`。2012 团体 1 的精简重考。
- **2019 个人 1**｜正变量，仅给矩条件 `E X_n ≤ C` 与 `E[max{0, −log X_n}] ≤ C`（**无独立性**）：证 `limsup X_n^{1/n} = 1`。全部换成 Markov 不等式，把两个矩条件翻译成两侧事件的可和性。
- **2021 个人 3**｜对称 Bernoulli 的 S_n：`P(lim S_n/n^α = 0) = 1` 对一切 α > 1/2。Chebyshev 给 `P(|S_n| > εn^α) ≲ n^{1−2α}`，可和性正好在 α = 1/2 处翻转。

**递进关系**
```
2012团1 (指数尾, 双向 B-C, 含 i.o. 的 0/1 结论)
   ↓ 换分布尾型
2012团2 (Poisson 尾 ⇒ 需要 loglog 修正)
   ↓ 换载体
2013团2 (数论/Diophantine)  &  2013个1 (一般 |X_n|/n 版本)
   ↓ 方向反转
2016团4 (逆命题证伪: 构造反例)
   ↓ 去掉独立性假设
2019个1 (只有矩条件 ⇒ 全部改用 Markov)
   ↓ 对象换成部分和
2021个3 (S_n 的 limsup, 临界指数 α=1/2 处翻转)
```

**解法骨架**
1. 把命题写成事件列 {A_n}，明确阈值 a_n（log n、loglog n、n、n^α、e^{εn}）；
2. **上界方向**：估计 P(A_n) 并对 n 求和；可和 ⇒ 第一 B-C ⇒ limsup ≤ 阈值 a.s.；
3. **不可和方向**：若 {A_n} 独立，对子列 n_k 用 `∏(1−p_{n_k})` 估计 ⇒ `P(A_n i.o.) = 1`；
4. 用对偶事件（"低于阈值"也无穷多次）把 limsup 与 liminf 夹成等号；
5. 逆命题：假设 limsup ≤ 1，构造稀疏子列大值分布，或对可积性用积分判别法 `ΣP(|X| ≥ n) ≍ E|X|`；
6. 无独立性时全部改用 Markov/Chebyshev 给出可和的界。

**最易卡的一步**：**临界指数处的不可和方向**。以 2012 团体 1 为例，α = 1 时 `Σ P(X_n > log n) = Σ 1/n = ∞`，可和性失效，必须改用第二引理；而 α ≤ 1 的一般情形（含 α<1）要整体用"对所有 α<1 的事件取交"或子列独立性来论证。同理 2021 个人 3 恰在 α = 1/2 处翻转——判断"哪一侧用哪个引理"是这个母题唯一真正的难点。

### PS-M08 用特征函数刻画与识别分布（5 题｜2012–2026）

**数学内核**：特征函数 φ(t) = E e^{itX} 是分布的指纹。三类动作：(a) **判定**一个函数是不是特征函数（正定性 / 显式构造）；(b) 在**单位根**处取值来检测离散均匀性（"消去"技巧）；(c) 由函数方程或极限**识别**分布族（正态的封闭性、Cauchy/稳定律）。

**成员对照**
- **2012 团体 4**｜`S = Σ Bern(p_i)`，证 `P(S 偶) = 1/2 ⇔ 至少一个 p_i = 1/2`。本质是 `E[(−1)^S] = ∏(1−2p_i) = 0`，即 φ 在 t = π 处取零。
- **2013 团体 1**｜证 `cos²t` **是**特征函数（= (e^{it}+e^{−it})²/4，对应 {−1,0,1} 上的显式点质量组合），`|cos t|` **不是**（破坏正定性：在 t = π/2 处为零且附近行为不对）。
- **2016 团体 3**｜(a) 若 `P{X ≡ k mod N} = 1/N` 对一切 k，则 `E e^{i2πmX/N} = 0` (m ≥ 1)；(b) 用 (a) 求"手指游戏"中使各玩家等概率的 N（解出所有满足条件的 N）。
- **2022 个人 1**｜高斯序列依分布收敛 ⇒ 极限仍高斯（含退化）。用 `e^{itµ_n − σ_n²t²/2}` 逐点收敛 ⇒ 极限必为同型。
- **2026 个人 5**｜由 `(X_1+⋯+X_n) =_d aX_1 + b` 与 α = ln n / ln a：(a) α=1, b=0 时证 `φ(t) = exp{iµt − γ|t|}`（Cauchy 律）；(b) 若再加 E|X_1| < ∞，证非退化情形下 α ≤ 1 不可能成立。

**递进关系**：2012 & 2013（判定"是不是特征函数"、在单位根处取值）→ 2016（把单位根技巧用于求参数 N 的充要条件）→ 2022（特征函数的**极限封闭性**）→ 2026（**解函数方程**，并要求排除一整段参数区间，从"验证"升到"求解 + 排除"）。

**解法骨架**
1. 写出 φ(t) 或待验证表达式；
2. 判定型：显式构造随机变量（离散点质量组合）或检验正定性 / |φ| ≤ φ(0) = 1；
3. 消去型：取 t = 2πm/N（单位根），把"均匀"翻译成 φ = 0；
4. 识别型：φ_n → φ 逐点 + 唯一性定理 + 匹配指数形式的参数；
5. 函数方程型：把 =_d 翻译成 `φ(t)^n = φ(at)e^{ibt}`，取模解 `|φ(t)| = |φ(t/a)|^n`，得 `|φ(t)| = e^{−γ|t|^β}`；
6. 回归原对象（求 N、给分布名、排除参数区间）。

**最易卡的一步**：2026 个人 5 的 (b)。得到 `|φ(t)| = e^{−γ|t|}` 只是 α=1 的情形；要证明 α ≤ 1 在 E|X| < ∞ 下不可能，必须利用 α < 1 时解的矩不有限（稳定指数 α 的稳定分布只有阶 < α 的矩存在），把"有限一阶矩"与"稳定指数"对接起来——这一步是原型题（2013 团体 1）完全没有的要求。

### PS-M09 收敛模式之间的关系（5 题｜2012–2021）

**数学内核**：依概率、依分布、L^p、a.s. 四种收敛之间的推导规则，以及传递性被破坏时需要补什么条件：Slutsky、随机下标、一致可积、矩的存在、"质量逃逸"。考的是**ε-δ 论证的手艺**。

**成员对照**
- **2012 个人 2**｜`{X_n}` 一致胎紧（`lim_{a→∞} sup_n P(|X_n|>a) = 0`）、`Y_n →P 0` ⇒ `X_nY_n →P 0`。"有界 + 小量"的经典截断论证。（该记录还夹带了另一题的两个小问：`E[X|G] > 0` a.s. 与 bivariate normal 的 `E(X|X+Y)`，前者归入 PS-M11、后者归入 PS-M05 的同类对象。）
- **2014 团体 1**｜`X_n →d X`、`Y_n →d c`（c 为常数）⇒ (a) `Y_n →P c`；(b) `X_nY_n →d cX`（Slutsky）。
- **2015 团体 2**｜`X_n →d X`，`N_t` 独立于 (X_n) 且 `N_t →P ∞` ⇒ `X_{N_t} →d X`（随机下标的 Anscombe 型结论）。
- **2017 团体 2**｜`X_n ≥ 0`、`X_n →P 0`、`E X_n → 2` ⇒ `lim E|X_n − 1|` 存在并求值（= **3**）。关键在于"质量逃逸到无穷"。
- **2021 个人 1**｜`X_n →d X` 且 `sup_n E|X_n|^r ≤ C` ⇒ `E|X_n|^s → E|X|^s`（0 < s < r）。一致可积（de la Vallée Poussin）⇒ 矩收敛。

**递进关系**：2012（胎紧 + 依概率）→ 2014（Slutsky，开始处理函数/乘积）→ 2015（下标本身随机化）→ 2017（**依概率 + 一阶矩的混合信息** ⇒ 另一个矩的极限，需要处理质量逃逸）→ 2021（由一致可积得任意低阶矩收敛，条件最弱、结论最强）。

**解法骨架**
1. 把目标写成 ε-δ 形式（依概率）或 `|E f(X_n) − E f(X)| → 0`（依分布，f 有界连续）；
2. 用胎紧/截断把变量拆成有界部分 + 尾部分；
3. "依分布 → 依概率"（极限为常数）用 `|Y_n − c|∧M` 的截断 + `P(|Y_n−c| > ε)` 估计；
4. Slutsky：写 `X_nY_n − cX = (X_n − X)Y_n + X(Y_n − c)`，前项用胎紧 + `Y_n →P 0`，后项用连续映射；
5. 随机下标：先在有限区间上截断 X，用 `N_t →P ∞` 把边界推远再取极限；
6. 矩的传递：先由 `sup E|X_n|^r ≤ C` 证一致可积（截断 + Hölder），再用"依分布收敛 + 一致可积 ⇒ 矩收敛"。

**最易卡的一步**：2017 团体 2 的**质量逃逸**。直觉容易答成 `E|X_n − 1| → 1`（因为 `X_n →P 0` 且 `EX_n → 1` 的错觉），但正确分解是
`E|X_n−1| = E[(1−X_n)I(X_n ≤ 1)] + E[(X_n−1)I(X_n > 1)] → 1 + 2 = 3`。
第一块 → 1（依概率收敛 + 有界），第二块 → 2（因为它等于 `E X_n I(X_n>1) − P(X_n>1)`，而 `E X_n → 2` 且 `EX_n I(X_n ≤ 1) → 0`）。漏掉第二块就会答 1。

### PS-M10 贝叶斯更新、贝叶斯检验与经验贝叶斯（4 题｜2012–2018）

**数学内核**：给定先验与似然，逐步计算后验；由后验做检验；或先验含未知超参数时先用数据估超参数（经验贝叶斯）再算收缩估计。核心是**后验 ∝ 先验 × 似然**这条流水线在四种不同复杂度下的运用。

**成员对照**
- **2012 个人 1**｜Pólya 罐：抽出一球后连同 a 个同色球放回，已知第二次抽出为红，求第一次为黑的概率。两步贝叶斯 + 组成比例随第一次结果改变（"换皮"型的经典题）。
- **2013 团体 4**｜`X_i ~ N(θ, σ²)`（σ² 已知）、先验 `π(θ) = e^{−|θ|/a}/(2a)`：(a) 求 `P(θ > K | x_1..x_n, a)`；(b) 求 a→∞ 的极限；(c) 与经典检验的 p 值比较（结论：后验比 p 值保守）。
- **2018 个人 1**｜潜艇搜索：先验 70%(A) / 30%(B)，单次搜索发现概率 40%(A) / 80%(B)，A 搜 4 次、B 搜 1 次均未发现，问下一步搜哪里。要按 `P(未发现 H_0^k | 区域)` 更新后比较下一步的边际成功概率。
- **2018 团体 5**｜`X_i ~ N(θ_i, 1)`，估 `τ = Σθ_i²`：(1) 证 `τ̃ = ΣX_i² − k` 无偏并求方差；(2) 先验 `θ_i ~ N(0,A)`、A 未知，先估 Â 再给经验贝叶斯 `τ̂_B = E(τ|X, Â)`；(3) 比较两估计量。

**递进关系**：2012（两步更新）→ 2013（后验的解析式 + 与频率派对比）→ 2018 个人（多次失败后的**序贯**更新与决策）→ 2018 团体（**超参数也未知** ⇒ 经验贝叶斯 + 与无偏估计的方差比较）。

**解法骨架**
1. 写出先验 π(θ) 与似然 f(x|θ)；
2. 后验 `∝ π(θ)∏f(x_i|θ)`，把不可积部分配成已知核（正态核 / 双指数核）；
3. 归一化并读出后验均值 / 尾部概率 `P(θ>K|·) = 1 − Φ((K−µ_post)/σ_post)`；
4. 做极限（如 a→∞ 给平坦先验）并与频率派结论对照；
5. 序贯观测时把"未发现"当作新的似然因子 `(1−p)^k` 逐次相乘；
6. 经验贝叶斯：由边缘矩估超参数（`E[ΣX_i²] = k(A+1)` ⇒ `Â = max{0, ΣX_i²/k − 1}`），代回后验均值，比较方差/风险。

**最易卡的一步**：2018 团体 5 中 **Â 的估计与收缩形式**。必须看出 `E[X_i²] = θ_i² + 1` ⇒ `E[ΣX_i²] = τ + k = k(A+1)`，因此 `Â` 是"矩估计再截断到 0"；进而 `τ̂_B = kÂ/(Â+1)·ΣX_i²/k − k` 型收缩。漏掉"减 k"或不做 `max{0,·}` 的截断都会得到荒唐的负数估计。

### PS-M11 条件期望的测度论性质（4 题｜2012–2014）

**数学内核**：条件期望与条件概率在**测度变换**、**分布不变性**、**独立性**下的行为。核心是两条：`E[h·E[X|G]] = E[hX]`（对 G-可测有界 h）与由 dQ/dP 得到的条件贝叶斯公式。

**成员对照**
- **2012 个人 3**｜有限双变量分布 `p(i,j)` 能否写成 `Σ_k λ_k a_k(i)b_k(j)`（λ_k ≥ 0, Σλ_k = 1，a_k、b_k 为概率质量函数）？可以——提示"用条件概率"，即按一维边缘做条件分解得到混合表示。这是条件分布作为"混合"的最小显例。
- **2013 团体 3**｜X 可积、`Y = E[X|G]`，若 X 与 Y **同分布**则 X = Y a.s.：(1) 平方可积情形用 `E Y² ≤ E X²` 取等 ⇒ 差为 0；(2) 用截断 `min{max{X,a},b}` 把结论推广到可积情形。
- **2014 个人 3**｜P、Q 相互绝对连续，`X_0 = dQ/dP`：(a) `0 < E_P[X_0|G] < ∞` P-a.s.；(b) `E_P[fX_0|G] = E_Q[f|G]·E_P[X_0|G]`（条件贝叶斯公式）。
- **2014 团体 3**｜(a) `Γ` 与 G 独立 ⇔ 对每个与 P 等价、密度 G-可测的 Q 都有 `Q(Γ) = P(Γ)`；(b) 若 (X,Y) 与 Z 独立则 `E[Y|X,Z] = E[Y|X]`。

**递进关系**：2012（条件分布的混合表示，最具体）→ 2013（**刚性**：条件期望与自身同分布 ⇒ 相等）→ 2014 个人（测度变换下的条件公式）→ 2014 团体（把独立性/条件独立刻画为测度类上的不变量）。

**解法骨架**
1. 明确要在哪个 σ-代数上验证"a.s. 相等"（检验所有该 σ-代数中的可测集）；
2. 可积情形先用 L² 投影性质 / 詹森不等式取等；
3. 一般情形对函数做 (a,b)-截断压回有界，再令 a↓−∞、b↑∞（用单调收敛）；
4. 涉及换测度时用 dQ = X_0dP，对每个 G-可测有界 h 验证 `E_P[h·(被求量)] = E_Q[h·…]`；
5. 独立性：把 `Q(Γ) = P(Γ)` 在"密度 G-可测"的 Q 类上取 `h = dQ/dP` 检验；
6. 条件独立：把条件期望化到可分解的 σ-代数上再取值。

**最易卡的一步**：2013 团体 3 的 (2)。从平方可积推广到可积**不是**自动的：必须先用 `min{max{·,a},b}` 的 Lipschitz 性质说明 `E[min{max{X,a},b}|G] = min{max{Y,a},b}`，再让 a、b 趋于 ±∞（配合控制收敛），才能从"截断后相等"回到"X = Y a.s."。跳过 Lipschitz 这一步会留下"条件期望不保持非线性函数"的漏洞。

### PS-M12 正态族的独立性层级（3 题｜2012–2018）

**数学内核**："不相关 ⇒ 独立"只在正态族内成立，对一般分布不成立；推广到条件版本则是"精度矩阵 ω_{ij} = 0 ⇔ 给定其余分量时条件独立"。三次出现分别在**反例、加强、条件版本**三个层次上。

**成员对照**
- **2012 个人 5**｜X 有关于 0 对称的 Lebesgue 密度、`Y = |X|`：证 X 与 Y 不相关（`Cov = E[X|X|] = 0` 由对称性）但**不独立**。这是"不相关 ≠ 独立"的标准反例。
- **2015 团体 4**｜X、Z 联合正态、均值 0、方差 1：对严格单调 f，`cov(X,Z) = 0 ⇔ cov(X,f(Z)) = 0`。提示给 `Z = ρX + ε`、ε 与 X 独立；等价于说正态下不相关与"与任意（单调）函数的协方差为零"等价。
- **2018 个人 4**｜`x ~ N(0,Σ)`，`Ω = Σ^{−1}`：若 `ω_{ij} = 0`，则给定其余分量时 x_i 与 x_j **条件独立**。把联合密度的指数项 `−½x'Ωx` 中的交叉项 `ω_{ij}x_ix_j` 与其余项分离即得。

**递进关系**：2012（**反例**：非正态下不相关 ≠ 独立）→ 2015（**加强**：正态下不相关 ⇒ 与任意单调函数也不相关，用 Stein 引理算）→ 2018（**条件版本**：由协方差矩阵的逆判断条件独立）。

**解法骨架**
1. 计算目标协方差（正态情形用 Stein 引理 `E[Xg(Z)] = Cov(X,Z)E[g'(Z)]`）；
2. 判断独立：看联合密度能否分解，或构造事件 A、B 使 `P(A∩B) ≠ P(A)P(B)`；
3. 正态情形写联合密度、分块求逆、配方；
4. 条件版本：把指数中的交叉项 `ω_{ij}x_ix_j` 与其余项分离，证条件密度可分解；
5. 结论必须分清"不相关""独立""条件独立"三层，不能混用。

**最易卡的一步**：2015 团体 4 的反方向。仅由 `cov(X,Z) = 0` 得 `cov(X,f(Z)) = 0` 是容易的（用 `Z = ρX+ε`）；反过来由 `cov(X,f(Z)) = 0` 推 `ρ = 0` 必须用 Stein 引理得 `E[Xf(Z)] = ρE[f'(Z)]`，再用 **f 严格单调 ⇒ f' > 0 a.e. ⇒ E[f'(Z)] > 0** 断定 ρ = 0。

### PS-M13 支撑依赖参数的非正则 MLE（3 题｜2012–2024）

**数学内核**：参数出现在分布**支撑的边界**上（球心、平移指数、次序统计量型估计量），似然关于参数不可微、Fisher 信息为零，MLE 的收敛速率**不是 √n**（常见是 n，或由样本排布控制的中间速率）。核心工具是似然的"角点"结构 + 次序统计量/极值的分布表示。

**成员对照**
- **2012 团体 5**｜`X_i` 独立均匀于圆盘 `B_θ`（中心 θ 未知）：证 `|θ̂ − θ| = O_p(1/n)`。速率是 n 而非 √n；论证靠几何约束"所有样本都在 `B_θ` 内 ⇒ θ 落在 n 个单位圆盘的交集里，交集的直径是 O(1/n)"。
- **2014 团体 5**｜平移指数 `f(y;φ,θ) = θ^{−1}e^{−(y−φ)/θ}` (y>φ)：求 MLE 及**极限分布**，提示用 Rényi 表示 `E_{(r)} =_d Σ_{j≤r} E_j/(n+1−j)`。φ̂ = Y_{(1)} 的偏差是 O(1/n)，θ̂ 的偏差是 O(1/√n)，两者尺度不同。
- **2024 个人 5**｜把样本排成 r×c 矩阵，`β̂_n = min_j max_i X_{ij}`：(a) 问 r_n 满足什么条件时 β 也是 β̂_n 分布的中位数（**中位无偏**）；(b) 求 `r_n(β̂_n − β)` 的极限分布。

**递进关系**：2012（球心 MLE 的速率 `O_p(1/n)`）→ 2014（同一现象在平移指数上，既要 n 尺度的 φ̂ 又要 √n 尺度的 θ̂，还要处理两者相关）→ 2024（换成"矩阵中的 min-max"，从"求速率"升级到"给无偏条件 + 完整的极限分布"）。

**解法骨架**
1. 写似然，指出它只在支撑角点上随参数变化：`L(φ) = θ^{−n}·I(φ ≤ Y_{(1)})·…`；
2. 支撑参数取边界（φ̂ = Y_{(1)}；球心取能覆盖全部样本的最小圆盘中心；β̂ 取次序统计量），其余参数用常规 score 方程；
3. 用次序统计量/极值的表示（Rényi 表示、最小覆盖圆的几何）写出估计量的**精确分布**；
4. 识别正确尺度：偏差 O(1/n) 的参数用 n 尺度，方差 O(1/n) 的参数用 √n 尺度；
5. 用 Slutsky / 连续映射得极限分布（指数、正态或混合）；
6. 无偏性/中位无偏性单独讨论（偏差符号可由定义直接读出）。

**最易卡的一步**：2014 团体 5 中**两种尺度的配对**。`√n(φ̂−φ)` 发散，必须用 `n(φ̂−φ)` 并证明它收敛到指数分布；同时 `θ̂` 的 √n 渐近与 φ̂ 的 n 尺度**耦合在一起**，必须用 Rényi 表示把 `Y_{(1)}` 与 `Σ(Y_i − Y_{(1)})` 化为一对独立变量，才能分别处理。

### PS-M14 检验统计量的构造、p 值分布与功效（2 题｜2012–2013）

**数学内核**：给定检验问题，构造统计量（LRT / Wald）、给出零分布与功效；或者更进一步，把 **p 值本身当作随机变量**研究其分布与随参数的变化。后者要用单参数**单调似然比（MLR）族**。

**成员对照**
- **2012 团体 6**｜两样本 Bernoulli，`H_0: p_1 = p_2`：(a) 导出 LRT 统计量（题面允许不化简）并给渐近零分布；(b) 在局部备择 `p_1 = p, p_2 = p + n^{−1/2}Δ` 下算渐近功效（要求识别漂移项）。
- **2013 个人 4**｜指数样本（均值 θ），检验 `H_0: θ = θ_0` vs `H_1: θ > θ_0`：(a) 求 `E_{θ_0}(P(X))`（精确结论：H_0 下 p 值 ~ U(0,1)，期望 1/2）；(b) 求 θ ≠ θ_0 时 `E_θ(P(X))`（n = 1 时显式）；(c) `E_θ(P(X))` 是否随 θ 递减？能否推广到任意 MLR 族？

**递进关系**：2012（"流程型"：造统计量 + 局部功效）→ 2013（"性质型"：研究 p 值作为随机变量的分布及其单调性，并要求推广到一般 MLR 族）。题型从"会不会做检验"升到"懂不懂 p 值的分布论"。

**解法骨架**
1. 写出 H_0 下的参数约束（`p_1 = p_2 = p` 或 `θ = θ_0`），得到带约束 MLE；
2. `Λ = sup_{H_0}L / sup_{H_1}L`，`−2logΛ →d χ²_{df}`；
3. Wald/得分版本用 `√n(θ̂−θ) → N(0, I^{−1})` 给出拒绝域；
4. 局部功效：在 `θ = θ_0 + n^{−1/2}Δ` 处展开，得 Z 的均值漂移 δ，功效 = `1 − Φ(z_{1−α} − δ)`；
5. p 值性质：H_0 下 `P(X) ~ U(0,1)` ⇒ 期望 1/2；一般 θ 用 T 的分布换元；
6. 单调性借助 MLR（T 的分布关于 θ 随机单调）完成。

**最易卡的一步**：2013 个人 4(c)。必须把"p 值 = 1 − F_{θ_0}(T)"与 MLR 下的**随机单调性**缝合起来，才能得到 `E_θ(P(X))` 对 θ 单调；只算 n = 1 的特例而不上升到 MLR，就答不到题目的要求。

### PS-M15 秩检验与 P(X<Y) 型效应量（2 题｜2012–2026）

**数学内核**：用"两（个）样本中 `γ = P(X < Y)`"作为效应量，并把它与非参数秩统计量联系起来：Mann–Whitney U 就是 `mnγ` 的无偏估计，Wilcoxon 秩和与它只差常数。现代版本把 γ 推广到**依赖对 + 有序结局**的 copula 框架。

**成员对照**
- **2012 个人 4**｜两独立样本、无并列：(a) 证 `W = U + n(n+1)/2`（两个统计量给出完全相同的 p 值）；(b) 用 CLT 给出 H_0 下 `µ_W = n(N+1)/2`、`σ²_W = mn(N+1)/12`。
- **2026 个人 1**｜有序结局 `Y_a ∈ {0,…,L−1}`：(1) 在联合 CDF `C{F_1(k), F_0(j)}` 下求 `ψ = Pr(Y_1 > Y_0)` 的闭式（对 k 的双重差分，约定 `F_a(−1) = 0`）；(2) 由潜变量阈值模型证明它确实诱导出该联合 CDF。

**递进关系**：2012（两样本、连续、求矩与 CLT）→ 2026（**有序 + 依赖**：把 `P(X<Y)` 从"独立两样本"推广到"依赖对的 copula 模型"，要求闭式而不是渐近）。

**解法骨架**
1. 写 `U = Σ_{i,j} I(X_i < Y_j)` 并验证 `E U = mnγ`；
2. 用"每个 Y 的秩 = 小于它的 X 的个数 + 自身名次"计数，得 `W = U + n(n+1)/2`；
3. 求 H_0 下 U 的均值与方差（指示变量两两协方差，注意 `U_{ij}` 之间的相关）；
4. U-统计量的投影法 / CLT 给渐近正态；
5. 离散依赖版：`ψ = Σ_k P(Y_0 ≤ k−1, Y_1 = k)`，用 copula 差分表示；
6. 由潜变量模型反推有序结局的联合 CDF（单调变换下 copula 不变）。

**最易卡的一步**：2026 的**求和端点**。必须用 `C(F_1(k), F_0(k)) − C(F_1(k−1), F_0(k)) − C(F_1(k), F_0(k−1)) + C(F_1(k−1), F_0(k−1))` 这类双重差分把 `P(Y_1 = k, Y_0 = j)` 精确取出；端点 `F_a(−1) = 0` 的处理决定了 k = 0 与 k = L−1 两项，漏掉就会丢掉边界贡献。

### PS-M16 充分性、完备性与 UMVUE（3 题｜2013–2023）

**数学内核**：先找充分（且完备）统计量，再由"无偏 + 完备 ⇒ 唯一最小方差"（Lehmann–Scheffé）得到 UMVUE；有时题目反过来要求证明 UMVUE **不存在**（完备性失效，或不存在无偏估计，或方差达不到下界）。

**成员对照**
- **2013 个人 6**｜坦克问题：序号 i.i.d. 均匀于 {1,…,N}：(a) 找完全充分统计量（= max X_i）；(b) 给出求 N 的 MVUE 的思路（由 `E[max] = nN/(n+1)` 反解）。
- **2022 个人 5**｜线性模型 `Y = Xβ + e`、rank(X) = k ≤ p（可能 p > n）、`γ = x_1β/σ`：求 γ 的 UMVUE 或证明不存在。难点在 γ 含未知的 σ，需借 `n−k > 1` 的卡方辅助量构造无偏因子，并检验方差是否达到 Cramér–Rao 界。
- **2023 个人 5**｜四人博弈（I、II 胜率 (1−θ)/2，III、IV 胜率 θ/2；停止规则为"I+II 共胜 r 局"或"III+IV 共胜 r+1 局"）：(a) 证或否证 `T = (X_1+X_2, X_3+X_4)` 的**完全性**；(b) 求 θ 的 UMVUE。

**递进关系**：2013（标准流程：完全充分统计量 + Lehmann–Scheffé）→ 2022（**反方向**：在奇异设计下判断 UMVUE 是否存在，先要谈可估性）→ 2023（把"完备性"本身变成考点：先证/否证完备性，再构造 UMVUE）。

**解法骨架**
1. 用因子分解定理找充分统计量；
2. 检验完备性（指数族看自然参数空间是否含内点；离散/停时分布须直接解 `E_θ g(T) = 0 ⟹ g = 0`）；
3. 用矩方法找一个关于 T 的无偏估计（把待估参数的矩写成 T 的函数）；
4. Rao–Blackwell 条件化到 T 上；
5. Lehmann–Scheffé 断言唯一性与最小方差；
6. 若要证明"不存在"：先讨论可估性/无偏估计的存在性，再比较方差与 Cramér–Rao 下界。

**最易卡的一步**：2022 个人 5。`γ = x_1β/σ` 中 σ 未知，使 γ **不是**线性可估函数；必须用 `(n−k)` 自由度的卡方变量（由残差平方和给出）构造无偏因子，再判断其方差是否等于 Cramér–Rao 下界。多数人只写"由 Lehmann–Scheffé 得 UMVUE"就停手，而题目的正确答案依赖于 `n−k > 1` 与 `rank(X) = k` 的具体取值。

### PS-M17 置信区间的覆盖概率与构造（3 题｜2013–2025）

**数学内核**：构造区间并**精确计算其覆盖概率**；更要紧的是识别"经典构造何时失效"——存在辅助统计量时条件覆盖与名义覆盖不一致；参数不可识别（一个观测估两个参数）时常规枢轴法失效。

**成员对照**
- **2013 个人 5**｜`X_1, X_2` i.i.d. U(θ−½, θ+½)：(a) 找 c 使 `P(X̄−c < θ < X̄+c) = 1−α`；(b) 证 `P(X̄−c<θ<X̄+c | |X_2−X_1| ≥ 1−ε) = 1`；(c) (b) 与 (a) 矛盾吗？观测 (1,2) 时还用 (a) 的区间吗？要点是 `|X_2−X_1|` 是**辅助统计量**，应条件化。
- **2015 个人 5**｜`Y_i ~ N(µ, γ²x_i²)`（x_i 给定）：(a) 构造 γ 的 1−α 置信区间（用 `Σ(Y_i−µ̂)²/x_i²` 型卡方量）；(b) 检验 `H_0: γ = 1`（µ 未指定）。常规枢轴 + nuisance 参数处理。
- **2025 个人 1**｜单观测 `X ~ N(µ, σ²)`，µ 与 σ² 皆未知：(1) 求形如 `c_1X ≤ µ ≤ c_2X`（X>0 时）的覆盖概率；(2) 讨论**随机化区间**的 minimax 最优性（覆盖概率下界与期望长度的权衡）。

**递进关系**：2013（发现"名义覆盖 ≠ 条件覆盖"）→ 2015（常规枢轴构造 + nuisance 参数）→ 2025（**极端情形**：一个观测估两个参数，覆盖概率只能"算"不能"查表"；并升格为随机化区间的 minimax 最优性）。

**解法骨架**
1. 找枢轴量（含未知参数、分布已知的函数）；
2. 反解参数区间（注意不等式方向随观测符号翻转）；
3. 精确计算覆盖概率（把事件化归为枢轴量的区间概率）；
4. 存在辅助统计量时改用条件覆盖概率，并讨论与名义值的差异；
5. 有 nuisance 参数时先消掉它（用其完全充分统计量或卡方分解）；
6. 需要最优性时：在覆盖约束下最小化期望长度，用随机化（混合区间）与 minimax 论证。

**最易卡的一步**：2025 第 (1) 问。`c_1X ≤ µ ≤ c_2X` 的覆盖概率**不是**查表可得：必须把它写成 `P(X ∈ [µ/c_2, µ/c_1])`（X>0 时）并注意 X<0 时区间反向，再做分类讨论；最终覆盖概率只依赖 µ/σ 的比值，需要显式算出。

### PS-M18 记录值与排列圈数：调和和型期望及其极限（3 题｜2013–2023）

**数学内核**：用指示变量 + 线性期望，把一个计数统计量化为**调和和** `Σ 1/k`，再研究其渐近（期望 ~ log n，方差 ~ log n ⇒ 有 CLT 型的涨落）。考的是指示变量法与调和数渐近这套装配线。

**成员对照**
- **2013 个人 3**｜记录事件 `A_n = {X_n = max{X_1..X_n}}`：(1) 求 `P(A_n) = 1/n`；(2) 记录总数 `Y_n` 的期望（= H_n）与方差（= `H_n − H_n^{(2)}`）。
- **2019 团体 3**｜均匀排列的**圈数** `X_n`：找 a_n 使 `E X_n / a_n → 1`（a_n = log n，因 `E X_n = H_n`）。对象从"记录"换成"排列圈数"，骨架完全一致。
- **2023 个人 3**｜记录数 `R_n` 的极限：求 `lim_n P(|R_n − log n| > m_n√(log n))`（m_n → ∞ 时极限为 0；m_n 有界时为正态尾概率）。

**递进关系**：2013（一阶、二阶矩）→ 2019（**换对象**：排列圈数，骨架不变）→ 2023（**升要求**：从"求矩"升到"求涨落的极限概率"，需要 CLT/Lindeberg 条件）。

**解法骨架**
1. 把计数写成指示变量之和 `R_n = Σ_k I(A_k)`；
2. 用对称性算 `P(A_k) = 1/k`（排列情形用"某元素属于长度 j 的圈"的概率 = 1/n），并证明 `{A_k}` **相互独立**（对 i.i.d. 连续分布）；
3. 求和得 `E R_n = H_n`，由 `Var I(A_k) = 1/k − 1/k²` 求和得方差；
4. 用调和数渐近 `H_n = log n + γ + o(1)` 得 a_n = log n；
5. 用 Lindeberg/Lyapunov 条件给标准化和的 CLT；
6. 把 m_n 的尺度代回，得 0、1 或正态尾概率的极限。

**最易卡的一步**：第 2 步中"记录指示变量相互独立"这一事实。它不是显然的（事件之间看起来相关），必须用 `P(A_{k_1} ∩ ⋯ ∩ A_{k_r}) = 1/(k_1k_2⋯k_r)` 的对称性论证（对 i.i.d. 连续分布，相对次序的均匀性给出该乘积形式）。漏掉独立性就无法用 Lindeberg，也就算不出方差 `~ log n`。

### PS-M19 正态向量的旋转/正交投影与 t 分布（2 题｜2013–2018）

**数学内核**：联合正态向量在**正交变换下仍是正态**；沿方向 a 的投影与其正交补独立。这条事实同时给出条件分布（旋转后条件区域重新参数化）与 t 分布（"正态 ÷ √(卡方/df)"）的构造。

**成员对照**
- **2013 个人 2**｜X、Y i.i.d. N(0,1)：(1) 求 `E[X+Y | X ≥ 0, Y ≥ 0]`；(2) 求 `X+Y` 在 `X ≥ 0, Y ≥ 0` 下的分布函数。提示用 `U = (X+Y)/√2, V = (X−Y)/√2`，把条件区域变成 (U,V) 平面上的楔形。
- **2018 个人 5**｜(a) `x ~ N(0,I_n)`：对单位向量 a 证 `√(n−1)·a'x/√(‖x‖² − (a'x)²) ~ t_{n−1}`；(b) 样本相关系数 r 满足 `√(n−2)·r/√(1−r²) ~ t_{n−2}`。

**递进关系**：2013（用旋转把条件事件化简，得到条件期望与条件分布）→ 2018（把旋转/投影技巧**系统化**为 t 分布的构造，并推广到样本相关系数这一经典统计量）。

**解法骨架**
1. 取正交矩阵把向量旋转到"第一坐标 = a'x"的坐标架；
2. 正交不变 ⇒ 新坐标仍独立正态 ⇒ 分子（沿 a 的分量）与分母（正交补中的平方和）独立；分子正态、分母卡方；
3. 按 `t =` 正态 `/` √(卡方/df) 组合，读出自由度；
4. 条件分布问题：把条件事件在旋转后的坐标里重新参数化，积掉多余变量；
5. 相关系数情形：先中心化，把 r 写成两个中心化向量夹角余弦，再用第 3 步；
6. 给出期望/分布函数/密度的显式表达式。

**最易卡的一步**：2013 个人 2 的 (2)。在 (U,V) 坐标下，条件区域 `{X≥0, Y≥0}` 是一个**楔形**而非矩形，必须把它正确参数化（相当于 `|V| ≤ U` 且 U ≥ 0）后再积掉 V；若当成矩形处理会得到错误的分布函数。

### PS-M20 线性模型的代数：可估性、FWL 与 OLS 投影（2 题｜2013–2026）

**数学内核**：线性模型中的可估性、投影矩阵与分块回归恒等式——**纯线性代数命题**，与误差分布无关（分布只用于谈无偏性与方差）。核心对象是列空间与投影矩阵 `M = I − X(X'X)^{−1}X'`。

**成员对照**
- **2013 团体 6**｜`Y = Xβ + ε`、X 为 n×p（1 < p < n）：(a) `Xa = 0 ⇒ a'β` 不可估；(b) 反之是否成立（证或否证）；(c) X 满秩 ⇔ 所有 `a'β` 可估。
- **2026 个人 2**｜分块回归 `Y = X_1β_1 + X_2β_2 + ε`、`M_1 = I − X_1(X_1'X_1)^{−1}X_1'`：证全模型的 OLS `β̂_2` 等于把 `M_1Y` 对 `M_1X_2` 回归的 OLS（**FWL 定理**）。

**递进关系**：2013（可估性的刻画：用零空间判定参数函数是否有无偏线性估计）→ 2026（升格为分块模型的**标准恒等式 FWL**，需要投影矩阵的代数操作）。

**解法骨架**
1. 明确"a'β 可估"的定义：`∃c` 使 `X'c = a`；
2. 由 `X'c = a` 的有解性 ⇒ `a ∈ col(X') = (ker X)^⊥` ⇒ `Xa = 0 ⇒ a'β` 不可估；
3. 反向：若不可估则 `a ∉ col(X')`，取 `v ∈ ker X` 与 a 内积非零；
4. 满秩 ⇔ ker X = {0} ⇔ 所有 `a'β` 可估；
5. FWL：写 normal equations，用 `β̂_1 = (X_1'X_1)^{−1}X_1'(Y − X_2β̂_2)` 消去 β_1，代回得 `X_2'M_1Y = X_2'M_1X_2β̂_2`；
6. 用 M_1 的幂等对称性断言 `β̂_2 = ((M_1X_2)'(M_1X_2))^{−1}(M_1X_2)'(M_1Y)`。

**最易卡的一步**：2026 的 FWL 证明。必须在一阶条件中**显式消去** `X_2'X_1` 项（这一步用到 `X_1'(Y − X_1β̂_1 − X_2β̂_2) = 0`），而不是直接去展开 `(X'X)^{−1}` 的逆——后者在 p 接近 n 时几乎无法化简。

### PS-M21 Lasso 与稀疏估计的刻画（2 题｜2013–2015）

**数学内核**：带 L1 惩罚的最小二乘（Lasso）的最优性条件与几何后果：正交设计下解就是软阈值；一般设计下"惩罚大于噪声相关 `2‖X'(Y−Xβ*)‖_∞`"会强制误差落在支撑集上的锥里（cone condition）。考的是**次梯度最优性条件**的运用。

**成员对照**
- **2013 团体 5**｜(a) 不假设 X 正交，证明分解式 `½‖Y−Xβ‖² + λ‖β‖_1 = ½‖Y−Xβ̂‖² + ½‖X(β−β̂)‖² + λ‖β‖_1`；(b) 证明正交设计下 Lasso 解就是软阈值，并给出 λ 与 γ 的关系（γ = λ）。
- **2015 团体 5**｜若 `λ > 2‖X^T(Y−Xβ*)‖_∞`，则 (1) `‖Y−Xβ̂‖² − ‖Y−Xβ*‖² > −λ‖Δ‖_1`；(2) `‖Δ_{S^c}‖_1 ≤ 3‖Δ_S‖_1`（cone condition）。

**递进关系**：2013（**正交设计**下的显式解 + 代数恒等式）→ 2015（**一般设计**下的锥条件，要求用最优性条件而非显式解）。

**解法骨架**
1. 写出目标函数 `½‖Y−Xβ‖² + λ‖β‖_1`；
2. 用 `β̂` 的最优性（0 属于次微分）写出 `X'(Y−Xβ̂) = λ s`，其中 `s ∈ ∂‖β̂‖_1`（|s_j| ≤ 1，在 β̂_j ≠ 0 处 s_j = sign）；
3. 正交设计（`X'X = I`）时目标函数按坐标分离，逐坐标解一维软阈值问题；
4. 一般设计时把 `β*` 与 `β̂` 的差记为 Δ，用 `λ > 2‖X'(Y−Xβ*)‖_∞` 控制 `|⟨X'ε, Δ⟩| ≤ (λ/2)‖Δ‖_1`；
5. 把该估计代回目标函数的不等式，得 `‖Δ_{S^c}‖_1 ≤ 3‖Δ_S‖_1`；
6. 收尾：解释锥条件在 oracle 不等式中的作用。

**最易卡的一步**：2015 的第 2 问。必须把"`λ` 足够大"翻译成**对偶可行性**（`‖X'(Y−Xβ*)‖_∞ < λ/2`），再把 `⟨X'(Y−Xβ*), Δ⟩` 按 S 与 S^c 拆分；直接对目标函数做差而不引入对偶变量，会卡在无法控制交叉项上。

### PS-M22 由函数恒等式/不变性反推分布（4 题｜2014–2026）★ 趋势最热

**数学内核**：给定一条对所有测试函数 f 成立（或对某个变换不变）的**函数方程**，反推出随机变量的分布。四道题分别用四种不同的"指纹"：Stein 恒等式（正态、Poisson）、旋转不变性（Maxwell–Herschel）、以及"和与差独立"（Darmois–Skitovich）。共同骨架：**先把方程翻译成特征函数/微分方程，再解方程**。

**成员对照**
- **2014 个人 1**｜对一切紧支撑光滑 f 有 `E[Xf(X)] = E[f'(X)]` ⇒ X 服从标准正态。这是 **Stein 恒等式**的刻画（正态是唯一满足 `E[Xf(X)] = σ²E[f'(X)]` 的分布）。
- **2020 个人 2**｜`λE f(X+1) = E[Xf(X)]` 对一切有界光滑 f ⇒ X ~ Poisson(λ)。Poisson 版的 Stein 恒等式。
- **2020 个人 4**｜Z = (X,Y)：X、Y 独立、零均值、二阶矩有限非零，且 Z 的分布在转角 θ（**非 90° 的倍数**）下不变 ⇒ X、Y 同方差正态。这是 Maxwell–Herschel 定理。
- **2026 个人 6**｜ξ、η 独立，若 `S = ξ+η` 与 `D = ξ−η` 也独立，则 ξ、η 必为（同方差）正态。这是 Darmois–Skitovich 定理。

**递进关系**
```
2014个1  (一条恒等式 ⇒ 正态; 一阶 Stein)
   ↓ 换分布族
2020个2  (Poisson 的 Stein 恒等式, 含参数 λ)
   ↓ 换成几何不变性
2020个4  (旋转不变 + 二阶矩 ⇒ Maxwell-Herschel)
   ↓ 换成独立性条件
2026个6  (和与差的独立性 ⇒ Darmois-Skitovich)
```
四题的对象都换了、指纹都换了，但骨架（"把条件写成对偶关系 → 解特征函数/递推 → 用唯一性识别分布"）始终不变；要求从"用一个已知恒等式"升到"自己把几何/独立性条件翻译成代数条件"。

**解法骨架**
1. 把给定的条件写成对**所有测试函数**成立的恒等式（或写成 `=_d` 关系）；
2. 取 f 为特征函数的实部/虚部，或取 f(x) = e^{itx}，把恒等式翻译成 φ 的微分方程 / 函数方程；
3. 对 Stein 型：令 f 任意 ⇒ 得到密度的递推（Poisson）或微分方程 `f'(x) = −xf(x)`（正态）；
4. 对不变性型：把旋转分解为"对角度求导"，得 `E[X²] = E[Y²]` 与 `E[X^{2k}Y^{2l+1}]` 类矩条件，凑出正态的矩递推；
5. 对 Darmois–Skitovich 型：由 S、D 独立得 `φ_ξ(u)φ_η(u) = φ_ξ(u+v)φ_η(u−v)` 型方程，取对数解出 `log φ` 是二次型；
6. 用唯一性定理断言分布（正态 / Poisson）。

**最易卡的一步**：2020 个人 4 中"θ **不是 90° 的倍数**"这个条件的用处。若 θ 是 90° 的倍数，旋转不变性对 (X,Y) 的联合分布只给出"两坐标可交换/可独立符号翻转"，无法锁死正态性（可以构造离散反例）；只有取一个非 90° 倍数角才能通过旋转的**复合**得到任意角度，进而用矩条件锁死 `E[X^{2k}]` 的递推。

### PS-M23 估计量的无偏性、相合性、渐近正态与渐近效率（3 题｜2014–2017）

**数学内核**：给一个具体的（常常是"看起来不太可能好用"的）估计量，逐项验证它的四大性质：无偏、相合、渐近正态、是否达到渐近有效性（与 MLE 的渐近方差比 = 渐近相对效率 ARE）。

**成员对照**
- **2014 团体 4**｜`X_i` i.i.d. `N(0,σ²)`，`M = (1/n)Σ|X_i|`：(1) 求 c 使 `σ̂ = cM` 相合；(2) 求 `√n(σ̂ − σ)` 的极限分布；(3) 给出 σ 的近似 1−α 置信区间；(4) σ̂ 是否渐近有效？四小问正好是"相合 → 渐近正态 → 区间 → 效率"的完整链条。
- **2015 个人 4**｜指数样本、`Y_1 = min`、估计量 `nY_1`：(a) 无偏；(b) 是否相合；(c) 是否有效（用方差与 Cramér–Rao 下界比较，结论：有效）。
- **2017 团体 5**｜`X_i` i.i.d. Poisson(λ)，`p = P(X_i = 0) = e^{−λ}`：(a) 零频率估计 `p̃` 的 `√n(p̃−p)` 极限分布；(b) MLE `p̂ = e^{−X̄}` 的极限分布；(c) 求 `p̃` 相对 `p̂` 的渐近相对效率。

**递进关系**：2014（四性质**串联**，一次做完）→ 2015（聚焦"有效"，用 Cramér–Rao 下界判等号）→ 2017（**比较两个估计量**的 ARE，要求分别算渐近方差再取比）。

**解法骨架**
1. 由 `E[估计量] = 参数`（或 `E → 参数`）判无偏/渐近无偏；
2. 用大数律 + 连续映射判相合；
3. 用 delta 方法（或直接算 `Var` + CLT）得 `√n(θ̂−θ) →d N(0, v(θ))`；
4. 由渐近正态反解置信区间 `θ̂ ± z_{1−α/2}√(v̂/n)`；
5. 计算 Fisher 信息 `I(θ)`，比较 `v(θ)` 与 `1/I(θ)`：相等即渐近有效；
6. ARE = 两估计量渐近方差之比。

**最易卡的一步**：2017 的 ARE。`p̃` 的渐近方差是 `p(1−p)`，而 `p̂` 的是 `(dp/dλ)²·λ = p²λ`；必须用 delta 方法把 `p̂ = e^{−X̄}` 的方差换算过去，并注意 `λ = −log p`，最后得到 `ARE = p²λ/(p(1−p)) = p(log(1/p))/(1−p)` 型表达式（< 1，说明 MLE 更优）。漏掉 delta 方法中的 `(g'(λ))²` 因子就会得到错误结论。

### PS-M24 指定模式首次出现的等待时间（2 题｜2015–2022）

**数学内核**：给定 i.i.d. 序列，求某个指定模式（连续同号、指定字符串）**首次出现**的期望时间。核心手法是"按状态递推"或"用鞅/更新方程"，并要意识到**不同模式的期望可以不同**（这就是 Penney's game 的本质）。

**成员对照**
- **2015 个人 2**｜反复掷公平硬币直到**连续两次正面**，求期望掷数（= 6）。最简单的状态递推：设 E0（无连）、E1（已有一个 H），解 `E0 = 1 + ½E1 + ½E0`、`E1 = 1 + ½·0 + ½E0`。
- **2022 个人 3**｜反复掷公平骰子：`τ_{11}` 为模式 11 首次出现时间，`τ_{12}` 为模式 12 首次出现时间。(a) 计算 `E τ_{11}`（= 42）；(b) 比较 `E τ_{11}` 与 `E τ_{12}`（后者更小，= 36），可只给直觉论证。**同一长度、不同模式、不同期望**是本母题的关键升级点。

**递进关系**：2015（单一模式的递推）→ 2022（**两个自重叠结构不同的模式**对比，需要理解"自重叠（self-overlap）使期望变大"）。

**解法骨架**
1. 按"当前已匹配的模式前缀长度"划分状态；
2. 写出状态的转移概率与一步递推（`E_i = 1 + Σ_j p_{ij}E_j`，命中态取 0）；
3. 解线性方程组得从初始态出发的期望；
4. 或等价地：对每个状态设"到达时间"的更新方程，用期望的线性性解；
5. 比较不同模式时，识别其**自重叠结构**（如 11 有重叠 ⇒ 期望更大；12 无重叠 ⇒ 期望 = 6² = 36）；
6. 收尾给直觉：重叠意味着失败后"前功尽弃"更多。

**最易卡的一步**：2022 的 (b)。直觉容易答成"两个模式长度相同、机会均等所以期望一样"；正确理解是 **11 有自重叠**（失败后可能残留一个 1 作前缀），因此 `E τ_{11} = 42 > E τ_{12} = 36`。判断依据是"模式的后缀与前缀的最长公共长度"。

### PS-M25 经典递推/对称性技巧求期望（2 题｜2015–2017）

**数学内核**：初等概率中"看似要枚举、实则有巧妙对称性或一步递推"的期望题。共同骨架：**把复杂事件化简为一个更小的同型问题**（自相似/递归），或用一个守恒量/对称性一步得答案。

**成员对照**
- **2015 团体 1**｜100 名乘客登机：第 1 人随机坐，其后每人若自己的座位空着就坐自己的、否则在空位中随机选。求最后一名乘客坐到自己座位的概率（= 1/2）。关键是看出"每当有人随机选座，他要么选到第 1 人的座位（此后一切正常），要么选到最后一名乘客的座位（失败），两者对称；这个过程可递归为更小规模的同一问题"。
- **2017 个人 1**｜盒中 750 红球、250 蓝球，不放回地随机取出直到剩下所有球同色；求剩余球数的期望落在哪个 [m, m+1] 区间。要点是把"剩余数"与"最后一段同色连续取出的长度"联系起来（等价于研究"取到最后一个异色球的时刻"），用对称性/倒数变换求期望。

**递进关系**：2015（自相似递归：把 100 人问题归约为 99 人问题）→ 2017（换对象为无放回抽样，用"最后异色球位置"的对称性）。两题的骨架都是"不枚举、找结构"。

**解法骨架**
1. 写"一步条件化"：假设第一步发生了什么，看剩余问题是否与自身同型；
2. 若自相似：设目标期望为 E，写出 `E = a + bE'` 型方程并利用同型性；
3. 找对称性/守恒量（例：乘客问题中"第 1 人座位"与"最后一人座位"的地位对称 ⇒ 概率 1/2）；
4. 无放回抽样的期望：把"剩余球数"与次序统计量（最后一个异色球的位置）对应；
5. 用期望的线性性 / 指示变量求和求值；
6. 给出整数区间或简洁分数形式的答案。

**最易卡的一步**：2015 团体 1 的**对称性论证**。必须说清"一旦某人随机选座，他选中的座位只有两类是'决定性'的——第 1 人的座位（此后不再有人被迫随机）和最后一名乘客的座位（直接失败）；其余选择只是把问题缩小"。漏掉这一分类就会陷入逐人枚举。

### PS-M26 矩约束下的极值与可达集（2 题｜2015–2016）

**数学内核**：在给定矩/协方差约束下，求某泛函的**精确上界**或**可达集合**（并要求说明等号何时可取到）。工具是 Cauchy–Schwarz、Chebyshev 积分不等式与"极值在两点分布上取到"的凸性原理。

**成员对照**
- **2015 个人 1**｜(a) X、Y 零均值、方差 1、相关系数 ρ：证 `E[max{X²,Y²}] ≤ 1 + √(1−ρ²)`。要点是把 `max{X²,Y²} = ½(X²+Y²+|X²−Y²|)` 拆开，对 `|X²−Y²|` 用 Cauchy–Schwarz（它是 `(X+Y)(X−Y)`）。（同题的 (b) 是 bivariate normal 的 `E(X|Y)`，属条件期望一类。）
- **2016 个人 4**｜`b > a > 0`，X 取值于 [a,b]，`Y = 1/X`：确定 `E(X)·E(Y)` 的**所有可能值**。这是可达集问题：由 Chebyshev 积分不等式（或直接用 `(X−x₁)(X−x₂)` 的符号）得下界 1 与上界 `(a+b)²/(4ab)`，且两端点由两点分布取到。

**递进关系**：2015（**上界**：只需给一个不等式）→ 2016（**可达集**：必须给出上下界并证明两端都能取到）。

**解法骨架**
1. 把目标泛函写成已知矩的组合（拆分 max/绝对值/乘积）；
2. 对残余项用 Cauchy–Schwarz 或 Chebyshev 积分不等式；
3. 求上界时注意常数的最优性（等号条件：两个变量线性相关 / 支撑为两点）；
4. 求可达集时，先在"支撑为两点"的分布族上优化（凸性原理：线性泛函的极值在极点上取到）；
5. 用 `(X−a)(X−b) ≤ 0` 一类不等式给出单侧界；
6. 显式给出达到极值的分布以证明可达。

**最易卡的一步**：2016 个人 4 的**可达性**。给出 `E(X)E(Y) ∈ [1, (a+b)²/(4ab)]` 只完成了"必要性"；必须构造两点分布显式达到上下界，并说明区间内的每个值都可达（用凸性/连续性）。只给不等式不给构造会被扣分。

### PS-M27 集中不等式：MGF/矩方法（3 题｜2016–2020）

**数学内核**：用矩母函数/矩估计给出偏差的**显式上界**（Chebyshev、Hoeffding 型、或"极值在两点分布取到"的 sharp 不等式）。考的是"如何把 MGF 的界翻译成尾部概率的界"，以及"如何在约束下求最紧的界"。

**成员对照**
- **2016 团体 2**｜分三步引导（"降要求"式给指示）：(1) 由 Chebyshev 得 `P(|µ̂_m − µ| ≥ 2σ/√m) ≤ 1/4`；(2) 用 Bernoulli 的 MGF 得 `P(均值 ≥ ½) ≤ (4p(1−p))^{k/2}`（p<½）；(3) 把样本随机分成 k 组取中位数（**median-of-means**），得 `P(|m̃ − µ| ≥ 2σ√(k/n)) ≤ (√3/2)^k`。
- **2017 团体 1**｜`[−1,1]^n` 上的均匀测度，`A_{H,r} = {x : dist(x,H) ≤ r}`（H 为垂直于主对角线的超平面）：证对足够大的 n，`µ_n(A_{H,n^ε}) ≥ 1 − n^{−2ε}` 与 `≥ 1 − e^{−n^ε/2}`。本质是"高维立方体的质量集中在赤道附近"。
- **2020 个人 1**｜X 本性有界、均值零：证 `E e^X ≤ cosh‖X‖_∞`。这是**sharp**的：等号在 X 取两个端点 ±‖X‖_∞ 时达到（凸性 ⇒ 指数函数在支撑上被弦控制）。

**递进关系**：2016（**引导式**三步走：Chebyshev → MGF → 中位数）→ 2017（高维几何型集中）→ 2020（**sharp** 界，要求等号可达，不再是粗糙的 Chebyshev 量级）。

**解法骨架**
1. 明确要控制的事件与目标偏差尺度；
2. 用 Chebyshev（只需要二阶矩）给出初步界；
3. 若需指数衰减：算 MGF `E e^{tX}`，用 Markov `P(X ≥ a) ≤ e^{−ta}E e^{tX}`，再对 t 优化；
4. 独立性下把 MGF 乘起来（`E e^{tΣX_i} = ∏E e^{tX_i}`）；
5. 稳健化（median-of-means）：把样本分组、每组取均值、取中位数，用"多数组表现良好"的 Bernoulli 计数把尾部概率压到指数级；
6. sharp 界：用凸性/弦不等式（如 `e^x ≤ ` 端点连线）得到最优常数。

**最易卡的一步**：2020 的 sharp 性。要证 `E e^X ≤ cosh‖X‖_∞` 必须用"指数函数在 `[−M, M]` 上是凸的，故被端点连线控制" ⇒ `e^x ≤ ` 线性插值，再取期望并用 E X = 0 消去一次项；只做 Taylor 展开是得不到 sharp 常数的。

### PS-M28 随机游走的极值与访问计数（2 题｜2016–2024）

**数学内核**：研究随机游走的**路径泛函**——"上确界的分布"与"访问某半轴的时间个数"。核心工具是强大数律（每步有负漂移 ⇒ 平均意义下远离原点）配合可数可加性/随机游走的常返-暂留判别。

**成员对照**
- **2016 个人 5**｜`X_i` i.i.d.、`E X_1 = −1`，`S_n` 部分和，`T = #{n ≥ 1 : S_n ≥ 0}`：求 `P(T = ∞)`（= 0）。由强大数律 `S_n/n → −1` a.s. ⇒ 只有有限个 n 使 `S_n ≥ 0`。
- **2024 个人 2**｜`X_i` 独立 Bernoulli(±1)，`S_n` 部分和，`M = sup_{n≥1}(S_n/n)`：(a) 求 `P(M = 0)`；(b) 证 `P(p−q < M ≤ 1) = 1`，并问哪些有理数 x 有 `P(M = x) > 0`（不是所有有理数：某些点概率为 0，需要用"游走能达到的平均值集合"（漂移谱）来刻画）。

**递进关系**：2016（**定性**：给出 P(T=∞) 是 0 还是 1）→ 2024（**定量**：求上确界的分布、支撑集与"概率为零的点"，需要刻画 `S_n/n` 的可达值集合）。

**解法骨架**
1. 写出路径泛函（`T` 或 `M`）的定义，确认它只依赖部分和；
2. 用强大数律或漂移计算给出 a.s. 的极限行为（`S_n/n → EX_1`）；
3. 对计数型泛函：`{T = ∞}` 蕴含 `S_n ≥ 0` 无穷多次 ⇒ 与 `S_n/n → −1` 矛盾 ⇒ 概率 0；
4. 对上确界型泛函：先证 `M ≥ p−q`（用任意长的良性段），再证 `M ≤ 1`；
5. 支撑集：把 `S_n/n` 的取值刻画为若干 ``+1/−1`` 频率的组合，判断哪些值可达、哪些不可达；
6. 用 Borel–Cantelli / 0-1 律或轨道拼接给出概率是否严格为正。

**最易卡的一步**：2024 的 (b) 后半。"每个有理数 x 是否都有正概率"的答案取决于 **`M` 的支撑集**：`M` 只能取那些能表示为 ``(k·1 + (n−k)(−1))/n = (2k−n)/n`` 形式、且能被游走在长时间尺度上以正概率逼近的极限点，加上 `p−q` 本身；必须具体构造（或排除）某个点，不能笼统地说"所有有理数都可以"。

### PS-M29 格点随机游走的相交与自回避（2 题｜2016–2017）

**数学内核**：`Z^d` 上随机游走的**相交/自回避**性质。核心事实是 `P(X_n = 0) = O(n^{−d/2})`——由局部 CLT 得到的对角概率衰减率；对它求和是否收敛直接决定"相交次数有限"还是"无穷"。

**成员对照**
- **2016 个人 1**｜`Z²` 上的游走：第一步走到某个邻居，之后每步走到"上一步未访问过的邻居"中等概率；`T` 为首次踩到已访问格点的时间；证 `E T < 35`。这是 d = 2 的**自回避（非回溯）**游走，需要显式估计"新格点数"的增长。
- **2017 团体 4**｜`X_n` 与 `X'_n` 两条独立简单随机游走（`Z^d`）：`I = {(s,t) : X_s = X'_t}`，证 `|I| < ∞` a.s.。提示给 `P(X_n = 0) = O(n^{−d/2})`。

**递进关系**：2016（d = 2 的非回溯游走，求**期望的显式上界**）→ 2017（一般 d 上两条独立游走的**相交次数有限**，用对角概率衰减 + 计数法）。两题的共同内核是"用相遇概率的衰减率决定相遇次数的有限性"。

**解法骨架**
1. 把目标事件写成"相遇/自交"的计数：`|I| = Σ_{s,t} I(X_s = X'_t)`；
2. 用独立性算 `P(X_s = X'_t)`，再对 s、t 求和；
3. 关键估计：`P(X_n = 0) ≍ n^{−d/2}`（局部 CLT 或特征函数）；
4. 当 d ≥ 3 时 `Σ_{n} P(X_n = 0) < ∞`（对每个 s 求和对 t 收敛）⇒ 期望有限 ⇒ a.s. 有限；
5. 非回溯/自回避情形：用"已访问格点数"的增长率（每步以正概率扩张边界）估计新格点，得到 `E T < ∞` 的具体常数界；
6. 收尾讨论维度临界现象（d ≤ 2 相交无穷多次 vs d ≥ 3 有限次）。

**最易卡的一步**：2016 个人 1 的**常数界 `E T < 35`**。必须给出一个可计算的上界（例如按"每步以概率 ≥ c 走到全新格点"做几何分布估计，再求和 ≤ 35），而不是只说"期望有限"。同时要注意该游走在 `Z²` 上确实会自交（不同于 `Z^3` 的自回避性质）。

### PS-M30 树上随机游走与信号传播的临界阈值（2 题｜2016–2017）

**数学内核**：无限二叉树上过程的**临界现象**：或者给出层级位置的期望上界，或者求出信噪比发散/收敛的临界概率 `p_c`。共同骨架是"用分支结构的递推关系（每层再分裂为 2 支）写出期望/方差的递推，再判断递推的稳定性"。

**成员对照**
- **2016 团体 1**｜无限完全二叉树上的随机游走（每步等概率走到邻居节点），`X_n` 为第 n 时刻的层级数：证 `E X_n ≤ n/3 + 4/3`。要点是向上走一步的概率随层级变化（根节点只有 2 个邻居），需小心处理边界后归纳。
- **2017 个人 2**｜根节点数值 `X_0 = ±1` 向下传播，每层符号以概率 p 翻转（p ∈ (0,½)），层级 h 的平均值 `X_h` 的信噪比 `R_h`：求阈值 `p_c` 使 `R_h → 0`（p > p_c）与 `R_h → ∞`（p < p_c）。这是二叉树上"信息能否传下去"的临界点（与"每层再分裂为 2 支、噪声也翻倍"的权衡有关）。

**递进关系**：2016（**位置期望的上界**：一阶矩的递推）→ 2017（**临界阈值**：需要同时掌握一阶矩（信号、∝ (1−2p)^h）与二阶矩（方差、∝ 增长因子^h），并令两者相除判发散）。

**解法骨架**
1. 写出树的分支结构（每层 2 支）与转移概率；
2. 建立所需量的**递推关系**（`E X_{n+1}` 关于 `E X_n` 与边界项；`E X_h`、`Var X_h` 关于 h 的递推）；
3. 解递推得闭式（信号 `E[X_h|X_0=1] − E[X_h|X_0=−1] = 2(1−2p)^h`；方差按分支数增长 `≈ (1 + (1−2p)²)^h/2^h` 之类）；
4. 求比值 `R_h = 信号²/方差`，看它的指数增长率；
5. 令指数为零解出 `p_c`（`(1−2p)²=1/2` 型方程 ⇒ `p_c = (1 − 1/√2)/2`）；
6. 分别讨论 p 在阈值两侧的极限行为。

**最易卡的一步**：2017 的**二阶矩递推**。信噪比的分母是 `Var X_h`，而每层的平均使方差被 2^h 除、同时每支独立翻转又使方差乘上因子——必须把这两股相反的力量同时写进递推，才能得到正确的临界指数。只算一阶矩（信号）会得出"任何 p<½ 都能传播"的错误结论。

### PS-M31 占位与匹配问题的极限分布（2 题｜2016–2018）

**数学内核**：`n` 个球落入 `n` 个盒（或 `N` 人互赠礼物）这类**占位/匹配**模型中，某个计数统计量的方差或极限分布。核心手法是"指示变量 + 线性期望/方差"，以及用 Poisson 近似处理稀有的重合事件。

**成员对照**
- **2016 个人 3**｜2016 个球投入 2016 个盒，概率不等（前 1008 个各 `1/(3·1008)`，后 1008 个各 `2/(3·1008)`）；`T` = 恰好含 2 个球的盒数，求 **Var(T)**。要点是写 `T = Σ_j I_j`，用 `Var T = Σ Var I_j + 2Σ_{i<j}Cov(I_i,I_j)`，协方差项来自同一对盒子的多重计数（不等概率使各盒的 p_j 不同，必须逐项算）。
- **2018 个人 3**｜聚会 `N` 人各带 `k` 件礼物，离开时各随机取 `k` 件；`X` = 被本人取回的礼物总数；固定 k，求 `N → ∞` 时 X 的**极限分布**（Poisson，参数为 `k²` 型：`E X = N·k·(k/N) = k²`）。

**递进关系**：2016（**二阶矩**：不等概率下的方差计算）→ 2018（**极限分布**：由稀有事件的 Poisson 近似给出整条分布）。从"算一个数"升到"给一个分布"。

**解法骨架**
1. 把计数写成指示变量之和 `T = Σ_j I_j`（或 `X = Σ_i I_i`）；
2. 算 `P(I_j = 1)`（`C(n,2)p_j²(1−p_j)^{n−2}` 型；匹配问题中是 `k/N` 型）；
3. 方差：`Var T = ΣVar I_j + 2Σ_{i<j}Cov(I_i,I_j)`，协方差用 `P(I_i=I_j=1) − P(I_i=1)P(I_j=1)`；
4. 极限分布：用 Poisson 近似的两条判据（`ΣP(I_i=1) → λ` 且 `ΣP(I_i=1,I_j=1) → 0`）；
5. 或者用概率母函数的逐点收敛；
6. 收尾给出参数 `λ` 的表达式。

**最易卡的一步**：2016 的**协方差项**。不等概率下 `p_j` 逐盒不同，`P(I_i = I_j = 1) = C(n,4)·(4!/(2!2!))·p_i²p_j²(1−p_i−p_j)^{n−4}` 型，不能简化成同分布情形的公式；必须承认并逐项处理 `Σ_{i<j}p_i²p_j²`（可用 `(Σp_i²)²` 展开）。

### PS-M32 随机矩阵的典型性质（2 题｜2016–2021）

**数学内核**：随机矩阵的**典型行为**——算子范数的高概率上界、行列式为奇数的概率为正。两题的技术完全不同（迹方法/trace method vs. 有限域上的线性代数与 Erdős–Littlewood–Offord 型论证），但共同的内核是"用一阶/二阶矩方法 + 并集界证明某个'病态'事件不发生"。

**成员对照**
- **2016 个人 2**｜`N×N` 的 i.i.d. ±1 矩阵：证对任意固定 δ>0，`lim_N P(‖X‖_{op} ≥ N^{1/2+δ}) = 0`。提示 `‖X‖²_{op} ≤ tr|X|²`。这是典型的**迹方法**（`E tr(X'X) = N²` ⇒ 范数是 O(N^{1/2}) 量级）。
- **2021 个人 4**｜`n×n` 的 i.i.d. Bernoulli(½)（取值 0/1）矩阵：`p_n = P(det X_n 为奇数)`，证 `lim_n p_n > 0`。要点是把行列式为奇数翻译成"模 2 的行列式非零"，即"n 个随机 0/1 向量在 F₂ 上线性无关"的概率；用逐列的条件概率（前一列张成的子空间大小 ≤ 2^{i−1}）得 `p_n ≥ ∏_{i}(1 − 2^{i−1−n})` 有正下界。

**递进关系**：2016（**连续/实数域**：算子范数的高概率上界，用的是迹 + Markov）→ 2021（**有限域 F₂**：奇异性概率的正下界，用逐列条件概率连乘）。两题从不同侧面回答"随机矩阵是否典型地非退化"。**注意**：本母题是把两题归并的边界情况，详见 §4。

**解法骨架**
1. 把"病态事件"写成某个矩阵泛函超阈值（`‖X‖_{op} ≥ t`，或 `det X = 0`）；
2. 实数域：用 `‖X‖²_{op} ≤ tr(X'X) = Σ_{i,j}X_{ij}²`，算期望（或 Markov/并集界），选 `t = N^{1/2+δ}` 使概率 → 0；
3. 有限域：把 det 为奇数化为"F₂ 上行列式非零"；
4. 逐列处理：第 i 列的随机 0/1 向量落在前 i−1 列张成子空间的概率 ≤ `2^{i−1}/2^n`；
5. 连乘得 `p_n ≥ ∏_{i=1}^n(1 − 2^{i−1−n}) ≥ ∏_{j≥1}(1 − 2^{−j}) > 0`；
6. 断言极限为正（不需要算出的具体值，只需正下界）。

**最易卡的一步**：2021 的**模 2 视角**。若不换成 F₂ 上讨论，直接用实数域的 `P(det = 0)` 估计会得到"概率 → 0"的反向结论；而正确路径是"det 为奇数 ⇔ det ≢ 0 (mod 2) ⇔ 各列在 F₂ 上线性无关"，且**逐列的条件概率只依赖子空间的基数（≤ 2^{i−1}）**，与列的具体分布细节无关——这一步是整题的关键。

### PS-M33 Markov 链的常返性、平稳分布与几何混合（4 题｜2017–2022）

**数学内核**：离散状态 Markov 链的三大问题：(a) 不可约性与常返性（含正/零常返）；(b) 平稳分布的存在唯一性；(c) 收敛到平稳分布的速度（几何遍历 / Doeblin 条件）。工具包括漂移函数（Lyapunov）、势核恒等式、全变差收缩。

**成员对照**
- **2017 个人 5**｜SIS 传染病模型：`X(t)` 为健康人数，`P(X(t+h) = n−1 | X(t)=n) = λn(N+1−n)h + o(h)`，`G(s,t) = E(s^{X(t)})`。求含 `∂_t G` 的**非平凡 PDE**。这是连续时间链的**生成元（Kolmogorov 前向方程）**在母函数上的形式（对象是"生成元"，比其余三题的"离散链"更宽一点，故本母题成员差异最大的一项）。
- **2019 个人 2**｜`γ` 是 {0,1,2} 上的概率测度且 `γ(0) > γ(2) > 0`，`Y_{n+1} = max{0, Y_n + ξ_{n+1} − 1}`（Lindley 递推/排队）：证链不可约且**正**常返。要点是用"正漂移"（`Eξ = γ(1) + 2γ(2) > 1` 由 `γ(0) > γ(2)` 保证）构造漂移函数。
- **2021 个人 2**｜转移函数 `p_n(x,y)`：证 `Σ_{n=L}^{N+L} p_n(x,y) ≤ Σ_{n=0}^{N} p_n(y,y)`。这是**势核/首次返回分解**的经典恒等式（从 x 到 y 的转移数被 y 的自返回数控制）。
- **2022 个人 4**｜存在状态 `y_0` 与 `θ > 0` 使 `p(x,y_0) ≥ θ` 对一切 x：(a) 证存在 `λ < 1` 使任意两个初始分布的下一步分布之差被 λ 压缩；(b) 证唯一平稳分布 π 且 `Σ_y|P_µ{X_n=y} − π(y)| ≤ 2λ^n`。这是 **Doeblin 条件 ⇒ 几何遍历**。

**递进关系**
```
2017个5 (连续时间生成元 / 母函数 PDE)  —— 相邻年份的工具型题目
   ↓ 离散化
2019个2 (不可约 + 正常返: 用漂移条件)
   ↓ 换工具
2021个2 (势核恒等式: 首次返回分解)
   ↓ 升级为定量
2022个4 (Doeblin 条件 ⇒ 全变差几何压缩 + 唯一平稳分布)
```
2019 到 2022 是清晰的"升要求"：从"证常返"升到"给出压缩率 λ 与指数收敛速度"。

**解法骨架**
1. 判不可约：证明任两状态互达（对 Lindley 型用"每步可 −1、且可以长跳"构造路径）；
2. 判常返：构造漂移函数 V（如 `V(y) = e^{αy}`）使 `E[V(Y_{n+1})|Y_n=y] ≤ V(y) − c` 在 y 大时成立 ⇒ 正常返；
3. 势核/首次返回：把 `p_n(x,y)` 按"首次到达 y 的时刻"分解，`Σ_{n} p_n(x,y) = P_x(τ_y < ∞)·Σ_n p_n(y,y)` 型；
4. Doeblin：设 `p(x,y_0) ≥ θ`，则 `Σ_y|P_µ{X_1=y} − P_ν{X_1=y}| ≤ (1−θ)Σ_y|µ(y)−ν(y)|`（两个测度在 y_0 处"强制混合"）；
5. 迭代第 4 步得第 n 步的几何压缩；
6. 由压缩性得 Cauchy 列 ⇒ 极限 π 存在唯一且平稳。

**最易卡的一步**：2019 个人 2 中"正漂移"与"正**常返**（而非零常返）的区别。仅证链不可约 + 常返（如用 `P(X_n = 0)` 的可和性）只给零常返或无结论；要得**正**常返必须用漂移条件构造可积的平稳测度，或显式验证存在不变分布。这一步是本母题最容易失手之处。

### PS-M34 赌局与随机游走的吸收概率、停止时间（4 题｜2017–2024）

**数学内核**：公平赌局/随机游走的**吸收**与**停止**问题：命中某个状态的最终概率、游戏结束所需轮数的期望、"输光出局"的机制是否影响结论。核心工具是**鞅**（公平赌局 ⇒ 总金额是鞅）、首达概率的调和函数刻画、以及可选停止定理。

**成员对照**
- **2017 团体 3**｜`n` 人各持 1 元，每轮随机挑两人掷硬币，输者付 1 元给赢者，为 0 者出局，直到一人独得全部：求**平均轮数**。要点：`ΣX_i²` 或某个凸泛函是鞅（每轮其期望下降固定量），用可选停止反解期望轮数。
- **2018 个人 2**｜老师 + 12 学生围成圈，礼物在相邻者之间等概率传递，"最后接触礼物者获胜"：问谁的中奖概率最高。这是**环上的吸收/末次访问**问题，用对称性 + 递推与"末次访问分解"。
- **2020 个人 3**｜简单随机游走 `S_n = a + ΣX_i`（`P(±1) = p, 1−p`），`τ_0` 为首次命中 0 的时刻：对一切 p ∈ [0,1] 求 `P_a{τ_0 < ∞}`。经典**赌徒输光**：解调和方程 `f(a) = p f(a+1) + (1−p) f(a−1)`，p ≤ ½ 时必命中，p > ½ 时 `((1−p)/p)^a`。
- **2024 个人 1**｜`r` 个玩家初始资金 `n_i`，每轮任选两人对赌 1 单位，输光者出局，直到一人独得全部：`X(S)` 为只涉及 S 中成员的局数，问 `E X(S)` **是否依赖选择机制**、若无关则求值。要点是"每次对赌是公平的 ⇒ 某个关于资金平方的泛函是鞅"，从而 `E X(S)` 与机制无关（这题把 2017 团体 3 的结论从"恰好 n 人各 1 元"推广到任意初始资金与任意选人机制）。

**递进关系**
```
2017团3 (n 人各 1 元, 求 E[轮数])
   ↓ 换问题(从"多久结束"到"谁赢")
2018个2 (环上传递, 末次访问概率)
   ↓ 换成经典单玩家
2020个3 (赌徒输光: 首达概率的显式公式, 对一切 p)
   ↓ 一般化
2024个1 (任意初始资金 + 任意选人机制, 问机制无关性并求 E X(S))
```
2024 是明显的升要求：不仅要算，还要先**论证与机制无关**（鞅性/可选停止），再给出期望。

**解法骨架**
1. 写出状态变量与终止条件；
2. 找鞅：公平对赌下总资金守恒，且 `Σ_i X_i^{(n)}` 与 `Σ_i (X_i^{(n)})² − cn` 型量是鞅（每轮平方和的期望有固定变化）；
3. 用可选停止定理：`E[M_τ] = M_0`，解出 `E τ`；
4. 首达概率：设调和函数 `f(x)`，解 `f(x) = p f(x+1) + (1−p)f(x−1)`，边界 `f(0)=1, f(∞)=0` 或反之；
5. 末次访问/获胜者概率：用"倒数第二次转移"分解或环上的对称性 + 线性方程组；
6. 机制无关性：指出鞅性质只依赖"每次对赌公平"，与选人规则无关。

**最易卡的一步**：2024 个人 1 的**机制无关性论证**。必须先用鞅（`Σ(X_i^{(n)})²` 的期望每轮下降 1/2 或类似固定量）证明 `E X(S)` 与选人机制无关，再求值；直接假设机制为"随机均匀选两人"来算会答非所问（题目明确允许机制是确定的或随机的）。

### PS-M35 随机图的阈值现象（2 题｜2017–2019）

**数学内核**：`G(n,p)` 的某个性质（团数上界、无孤立点）在阈值 `p ≍ log n / n` 或 `p ≍ n^{−2/(k−1)}` 附近发生**0-1 相变**。核心手法是"一阶矩/二阶矩方法 + 并集界"：上界方向数期望（并集界），下界方向数方差（二阶矩法）或逐点独立估计。

**成员对照**
- **2017 个人 4**｜`G(n,p)`（p 固定），`T` = 最大完全子集（团）的大小：证 `lim P(T ≤ (1+ε)·2log_{1/p}n) = 1` 与 `lim P(T ≥ (1−ε)·2log_{1/p}n) = 1`。提示给 `P(T = n) = p^{n(n−1)/2}`。上界用并集界 `C(n,k)p^{C(k,2)} → 0`，下界用二阶矩法。
- **2019 团体 4**｜`G(n,p_n)` 无孤立点的阈值：(a) `p_n ≥ (1+ε)log n/n ⇒ P(有孤立点) → 0`；(b) `p_n ≤ (1−ε)log n/n ⇒ P(有孤立点) → 1`。上界用"每个顶点孤立概率 `(1−p)^{n−1}` 求和 + 并集界"；下界用"孤立点数的方差/二阶矩"或"独立性与 Poisson 近似"。

**递进关系**：2017（**团数**：阈值的尺度是 `2log_{1/p}n`，需要二阶矩法处理"团之间的重叠"）→ 2019（**孤立点/连通性**：阈值 `log n/n`，两侧分别用并集界与二阶矩）。两题是同一套"一阶矩上界 + 二阶矩下界"机器的不同实例（换皮）。

**解法骨架**
1. 把目标性质写成"存在某个坏/好子结构"的并集事件；
2. **上界（不发生）**：并集界 `P(∃A) ≤ Σ_A P(A)`，把 `P(A)`（如 `p^{C(k,2)}`、`(1−p)^{n−1}`）代入并令其 → 0；
3. **下界（发生）**：设 `X` 为计数，用 `P(X > 0) ≥ (E X)²/E X²`（二阶矩法）；
4. 二阶矩的关键是估计 `E[X²]` 中"两个子结构重叠"的项，得出阈值的精确常数；
5. 对孤立点这类"近似独立"的稀有事件，可用 Poisson 近似把分布直接给出；
6. 断言阈值处的 0-1 相变。

**最易卡的一步**：2017 团数下界的**二阶矩计算**。必须把所有可能的"两个 k-团共享 j 个顶点"的情形枚举并逐项比较，其中"几乎不相交"的项主导 `E[X²]`；若只保留不相交项，会得出错误的阈值常数 `2log_{1/p}n` 之前的系数。**因此本母题的合并是以"骨架相同"为准，而不是以"结论形式相同"为准。**

### PS-M36 重随机化与基于设计的因果推断（5 题｜2019–2021）★ 单一年份连考最强

**数学内核**：把随机化本身当作推断的基础（design-based / Neyman–Fisher 范式）。三步固定动作：(1) **估计量在随机化分布下的期望与方差**（对全部可能分配求平均）；(2) 反事实框架下的**无偏方差估计**（在可加处理效应假设下才无偏，非可加时有偏）；(3) **重随机化 / 协变量平衡设计**（在平衡约束下重新抽分配，并证明仍可无偏估计、仍可做精确检验）。

**成员对照**
- **2019 个人 4**｜2N 个单元随机对半分入处理/对照，估计量 = 两组样本均值之差：(a) 求其期望（= ATE）；(b) 求其在随机化分布下的方差；(c) 在**可加处理效应**假设下求方差的无偏估计；(d) 非可加时求该估计量的偏差；(e) 推广到 `N_t ≠ N_c`；(f) 论证大样本下高斯性并做小规模模拟；(g) 加入协变量 X 并**拒绝**处理/对照组 X 均值相差过大的分配，讨论哪些结论仍然成立；(h) 不等样本量时的极限分布（**不是**高斯）。
- **2020 个人 5**｜同类设计：证明当两组等量时，基于样本均值之差的 A/B 因果效应估计对 **X 的任意线性函数 Y** 都是无偏的（要点：`E[Ȳ_A − Ȳ_B | 设计]` 在等量随机化下为 0，因为每个单元的期望处理指示为 1/2）。
- **2020 个人 6**｜为第 5 题在小样本、**奇数 N** 情形给出反例（等量分配无法实现 ⇒ 无偏性失效）。
- **2021 个人 5**｜1000 名患者对 200 维协变量：描述一类能同时平衡多维协变量、且保证每个患者有正概率接受任一处理的方法，并给出**显式算法**（= 重随机化 / Mahalanobis 距离下的拒绝采样 / 配对或最小化分配）。
- **2021 个人 6**｜实验由机器学习算法分配（每人有正概率接受 A 或 B，算法完全已知且为平衡协变量设计）：(a) 能否得到因果效应的无偏估计（能，用 Horvitz–Thompson / 已知倾向分的逆概率加权）；(b) 能否得到精确的小样本非参数推断（能，用**随机化分布**给出 sharp null 下的精确显著性水平）。

**递进关系**
```
2019个4  (完整体系: 期望/方差/无偏方差估计/偏差/不等样本/正态性/协变量约束/非高斯极限) —— 8 小问
   ↓ 提炼为单点题
2020个5  (只问"等量随机化 ⇒ 线性函数无偏")
2020个6  (反向: 奇数 N 时给反例 ⊂ 升要求: 必须自己构造反例)
   ↓ 从"分析"到"设计"
2021个5  (要求给出显式设计算法)
   ↓ 从"设计"到"推断"
2021个6  (ML 分配下: 无偏估计 + 精确非参数推断 ⇒ 收口到 randomization test)
```
这 5 题是同一命题人在 2019–2021 连续三年推进的一条线，属**"升要求"的教科书式例子**：分析 → 反例 → 设计 → 推断。

**解法骨架**
1. 定义潜在结果 `(Y_i(1), Y_i(0))` 与分配指示 `W_i`，明确"期望/方差是对随机化分布取的"；
2. 算 `E[W_i] = N_t/N`、`Var(W_i)`、`Cov(W_i,W_j) = −N_tN_c/(N²(N−1))`（抽样无放回 ≥ 超几何）；
3. 估计量 `τ̂ = Ȳ_t − Ȳ_c` 的期望 = ATE（由 `E W_i` 直接给出），方差 = `S_t²/N_t + S_c²/N_c − S_{tc}²/N` 型；
4. 无偏方差估计：在**可加效应**假设下 `S_t² = S_c²` 可合并，从而构造无偏估计；非可加时算其偏差；
5. 重随机化：定义平衡准则（Mahalanobis 距离），只在满足准则的分配集合上均匀抽样，保持每个单元的正概率 ⇒ 无偏性、方差有界；同时说明该设计下界（哪个估计量的方差变了）；
6. 精确推断：给定 sharp null，对观察到的统计量在**完整随机化分布**上算 p 值；不等样本量时用置换/组合分布，说明其极限非高斯。

**最易卡的一步**：2019 个人 4 的 **(c)+(d) 组合**。"在可加效应下无偏、非可加时有偏"这一对结论必须用同一个表达式同时给出：无偏估计量是 `(S_t²/N_t + S_c²/N_c)` 的样本版本，当效应可加时 `S_t² = S_c²` 使其无偏，否则偏差 = `(S_t² − S_c²)` 的某个倍数。多数解答只写"在可加假设下无偏"，无法回答 (d) 中"偏差是多少"。

### PS-M37 正则条件概率与条件期望的极限逼近（2 题｜2023）

**数学内核**：条件期望/条件概率的**"正则"版本**与**极限版本**——(a) 用一列不断加细的 σ-代数上的条件期望逼近平凡的条件期望（Lévy 上升定理）；(b) 用 Markov 核定义的"条件分布"什么时候真的等于条件概率 `P(A|T)`（正则条件概率的存在与唯一性）。

**成员对照**
- **2023 个人 2**｜`X, Y ≥ 0`，`φ(u) = u/(1+u)`，`U_n = Σ_{j=1}^{2^n} ((j−1)/2^n)·I((j−1)/2^n ≤ φ(X) < j/2^n)`（φ(X) 的 n 位二进制截断），`V_n = E(H(X,Y) | U_n)`：(a) 证存在 Z 使 `V_n → Z` a.s.；(b) 给出 Z 的表达式（= `E(H(X,Y) | φ(X))`）。这是 **Lévy 上升定理**（`σ(U_n) ↑ σ(φ(X))` ⇒ 条件期望收敛）。
- **2023 个人 4**｜给定 Markov 核 `Q(t,A)`（`Q(·,A)` 为 Borel 可测、`Q(t,·)` 为概率测度）、`Π = P∘T^{−1}`、`P(A) = ∫_R Q(t,A)Π(dt)`：证或否证 `P(A|T) = Q(T,A)` a.s.。答案是**成立**——这正是正则条件概率的定义性刻画（由 `∫_B Q(T,A)dP = P(A ∩ T^{−1}B)` 验证）。

**递进关系**（同一年、同一命题人）
```
2023个2 (极限版本: 加细 σ-代数 ⇒ 条件期望收敛; 需要自己猜出极限是 σ(φ(X)) 上的条件期望)
   ↓
2023个4 (正则版本: 用核显式给出的"条件分布"是否确实等于条件概率; 要求证或否证)
```
两题骨架相同：**验证某对象满足条件期望/条件概率的定义性方程**。

**解法骨架**
1. 明确要证的两件事：`V` 是 σ-代数可测的，且对每个该 σ-代数中的集合 B 有 `∫_B V dP = ∫_B X dP`；
2. 极限版本：先说明 `σ(U_n)` 递增、`σ(U_n) ↑ σ(φ(X))`；用鞅收敛定理（`V_n` 是鞅）得 a.s. 极限 Z；
3. 验证 Z 满足"对 ∪σ(U_n) 生成的 π-系成立"，再用单调类定理推广到 `σ(φ(X))`；
4. 正则版本：对每个 `B ∈ σ(T)` 验证 `∫_B Q(T,A)dP = P(A∩B)`（把 B 写成 `T^{−1}(B')` 后用 Fubini 换序）；
5. 由条件概率 a.s. 唯一性（两个候选只差一个零测集）断言相等；
6. 收尾说明"正则"意味着可以选出一个对每个 A 都成立的版本。

**最易卡的一步**：2023 个人 2 的 (b)（给出 Z 的显式）。很多人会答成"Z = E(H(X,Y)|X)"，但 U_n 只截断 φ(X) 而 φ 不是单射（`φ(u)=u/(1+u)` 是单射，但截断只到 2^n 位），所以极限是 **σ(φ(X))** 上的条件期望；同时要注意 H(X,Y) 关于 (X,Y) 的可积性假设 `E|H(X,Y)| < ∞` 是使用条件期望的前提。

### PS-M38 高维 M 估计量的均匀偏差界（2 题｜2024–2025）

**数学内核**：在 `p` 随 `n` 增长的高维设定下，给出一族估计量（对模型/坐标取 max）的**均匀**偏差上界，其速率形如 `√(p log n / n)` 或 `n^{−1/3}`。工具是局部二次展开（self-concordance 型）+ 凸性 + 并集界。

**成员对照**
- **2024 个人 4**｜广义线性模型（指数族）下，`α_0` 为真模型所包含的重要协变量集合，`A = {α : α_0 ⊆ α}`：在两条正则性条件（Hessian 的谱有界；局部近似）下证 `max_{α∈A}‖β̂_α − β(α)‖ = O_p(n^{−1/3})`。要点是用 Hessian 的谱上下界把对数似然在真值附近二次展开，再对所有模型取并集界。
- **2025 个人 4**｜一元方差分析 `Y_{ij} = β_j + R_{ij}`（`β_j = 0`，`p` 个单元、每单元 `n/p` 个观测），M 估计量 `β̂_j` 解 `Σ_i ψ(Y_{ij} − β̂_j) = 0`：在 `ψ` 有界、`ψ'` 在 0 附近有界连续、`Eψ(R)=0`、`Eψ'(R)=d≠0`、`p log p/n → 0` 下，证 `P(max_j |β̂_j| ≥ (B^{−1} p log n/n)^{1/2}) ≤ 2p/n → 0`。要点是`ψ` 的有界性给出 Bernstein 型偏差控制，再对所有 j 取并集界。

**递进关系**：2024（**GLM/模型选择**：max 在所有含真模型的子模型上取，速率 `n^{−1/3}`，靠 Hessian 谱条件）→ 2025（**M 估计/坐标 max**：速率 `(p log n/n)^{1/2}`，靠 `ψ` 的有界性）。两题都是"对一族估计量取 max 的均匀偏差"，但**速率来源不同**（前者来自似然的局部二次性，后者来自有界影响函数 + 并集界）。

**解法骨架**
1. 写出估计量的定义性方程（score 方程 / `Σψ(·) = 0`）；
2. 在真值附近做**局部展开**：`ℓ(β) − ℓ(β_0) = ⟨s, β−β_0⟩ − ½(β−β_0)'H(β−β_0) + 高阶`；
3. 用 Hessian 的谱界（或 `ψ'` 的下界 d）得强凸性/局部二次行为；
4. 对每个固定模型/坐标给出偏差界（用 Markov/Chebyshev/Bernstein）；
5. 对 `p` 个模型或坐标取**并集界**，得 `P(max ≥ t) ≤ p·P(单个 ≥ t)`；
6. 选择 `t` 使 `p·P(单个 ≥ t) → 0`，读出速率。

**最易卡的一步**：2024 中 `n^{−1/3}` 这一速率的来源。它不是"普通 MLE 的 `n^{−1/2}` 加上 p 的代价"，而是**在真模型附近的局部二次近似失效区域**（当 `‖β̂−β‖` 大到使高阶项不可忽略时）得到的折中速率；必须说明条件 (II) 的局部近似只在 δ-邻域内成立，因此偏差被卡在 `n^{−1/3}` 量级，无法沿用到 `n^{−1/2}`。

### PS-M39 非传递性与决策悖论（2 题｜2025）

**数学内核**：概率中的**非传递性**与决策的不可靠性：一个看起来"应该有正概率"的结论（选择正确总该 ≥ 1/2；存在一个环使得每一步都大概率递增）实际可能反向。核心是构造性反例 + 对"概率"与"期望"排序的不一致性的精确刻画。

**成员对照**
- **2025 个人 2**｜单观测 r 以 1/2 概率来自 P_1 或 P_2；`ν` 使 `E_1ν(X), E_2ν(Y)` 有限，决策规则 `φ: R→[0,1]` 是**一一**的：若 `E_1ν(X) > E_2ν(Y)`，正确选择 P_1 的概率是否总 ≥ 1/2？不是——对任意给定 φ，可构造 p_1、p_2 使该概率 < 1/2。
- **2025 个人 3**｜`n ≥ 2`：证存在独立随机变量 `X_1, …, X_n = X_0`，使 `P(X_{k−1} < X_k) = 1 − 1/(4cos²(π/(n+2)))` 对一切 k 成立（非传递环：每一步都以大概率"变大"，但绕一圈回到原点）。

**递进关系**（同一届、同一命题人）
```
2025个2 (证伪: "决策不可能总是优于 1/2", 需构造反例)
   ↓
2025个3 (构造: 显式给出非传递环, 概率精确到 1 - 1/(4cos²(π/(n+2))))
```
两题共享内核："事件层面的概率排序不能传递/不能用于决策"，区别是前者要证伪、后者要**开出精确的常数**。

**解法骨架**
1. 明确要反对的"直觉命题"（正确选择概率 ≥ 1/2；或"若每个 P(X_{k−1}<X_k) > 1/2 则整体一致"）；
2. **证伪型**：给定 φ，构造两个分布使 `E_1ν(X) > E_2ν(Y)` 但在 φ 下误判概率 > 1/2（利用 φ 一一 ⇒ 可取 p_1 集中在 φ 的低值区、p_2 集中在 φ 的高值区，同时把 ν 的期望拉开）；
3. **构造型**：设 `X_k` 由有限状态 Markov 思想的"独立但同族"构造（如 `X_k = a_k + ` 交错项），把 `P(X_{k−1} < X_k)` 化为某个三角方程；
4. 用 `4cos²(π/(n+2))` 的递推（与 `cos` 的倍角/Chebyshev 多项式相关）把最坏情形概率精确求出；
5. 验证 `n` 个不等式同时成立（环的闭合 `X_n = X_0`）；
6. 收尾：说明这就是非传递性的定量形式。

**最易卡的一步**：2025 个人 3 的**精确常数**。`1 − 1/(4cos²(π/(n+2)))` 不是随机凑出来的：它来自"独立随机变量序列的两两比较概率"的极值问题，需要把约束写成线性方程组 `p_k = P(X_{k−1}<X_k)` 并求其可行域的最大值（可由矩阵的谱/Chebyshev 多项式给出）。只给"存在非传递环"的定性构造，答不到题目要求的精确值。

## §4 存疑与边界情况

以下条目**我拿不准**是否应归为同一母题，故按保守原则处理（多数保持分立），在此列出两种解释，供后续修订。

### 4.1 PS-M32 随机矩阵两题是否同一母题（★最可疑）

- **成员**：2016 个人 2（±1 矩阵算子范数 `< N^{1/2+δ}`）、2021 个人 4（0/1 矩阵行列式为奇数的概率有正下界）。
- **解释 A（合并，本报告采用）**：两者共同的骨架是"把病态事件写成矩阵泛函超阈值 → 用矩方法/并集界证明它不发生或极少发生"，属于"随机矩阵的典型性质"。作为复习单元，两者放在一起有助于建立"随机矩阵不病态"的整体直觉。
- **解释 B（拆开）**：技术完全不同——前者是**实数域的迹方法**（`‖X‖²_op ≤ tr X'X`），后者是**有限域 F₂ 上的线性代数**（逐列条件概率）。两者除"随机矩阵"这一场景外没有共同步骤，按 §0.1 的"只共享场景不共享内核"规则应当拆分。
- **建议**：若后续统计按"解法骨架"严格判定，应拆为两个孤题。

### 4.2 PS-M33 中的 2017 个人 5（SIS 生成元）是否该留在 Markov 链母题内

- **解释 A（留下，本报告采用）**：它问的是连续时间 Markov 链的生成元作用在母函数上的方程，属于"用链的结构写出演化方程"，与另外三题的"链的长期行为"同属 Markov 链大题。
- **解释 B（拆出）**：另外三题问的是**长期行为**（常返、平稳、混合速率），2017 个人 5 问的是**瞬时演化的 PDE**，两者数学对象（生成元 vs 平稳分布）不同。
- **建议**：若把母题定义为"链的长期行为"，应将 2017 个人 5 拆为孤题。

### 4.3 PS-M11 与 PS-M37 是否应合并为一个"条件期望大母题"

- **成员**：PS-M11 = {2012个3, 2013团3, 2014个3, 2014团3}；PS-M37 = {2023个2, 2023个4}。
- **解释 A（分立，本报告采用）**：PS-M11 关注**测度变换与独立性的刻画**（换测度下的条件期望公式、同分布蕴含相等），PS-M37 关注**正则版本与极限逼近**（Lévy 上升定理、正则条件概率的存在性）。证明技术不同（一个是"验证定义性方程"，一个是"鞅收敛 + 单调类定理"）。
- **解释 B（合并）**：六题的终极判据完全一致——"验证候选对象满足条件期望的定义性方程 `∫_B V dP = ∫_B X dP`"，且工具都是单调类定理。合并后可得一个 6 题的"条件期望测度论"大母题，性价比会从榜外升到 TOP5。
- **建议**：这是本报告最影响排名的取舍点。

### 4.4 2019 团体 3（排列圈数）是否真与"记录值"同母题

- **解释 A（合并，本报告采用）**：对象可替换（记录 ↔ 排列圈数），解法骨架完全相同（指示变量 + 线性期望 + 调和和渐近 `H_n ~ log n`）。
- **解释 B（拆开）**：记录问题额外需要"记录指示变量的独立性"这一非平凡事实（PS-M18 的难点），而排列圈数只需线性期望；2023 那题（CLT 型极限）也与排列圈数无关。三者只是共享"调和和"这个中间量。
- **建议**：若把 PS-M18 缩为 {2013个3, 2023个3}，2019 团体 3 应单列为孤题。

### 4.5 PS-M25（经典递推）是否只是"初等概率杂题"

- **成员**：2015 团体 1（飞机座位）、2017 个人 1（无放回取球直到单色）。
- **解释 A（合并，本报告采用）**：两题都不是靠公式而是靠**结构性洞察**（自相似递归 / 对称性）一步化简，属于同一类"反枚举"题。
- **解释 B（拆开）**：飞机座位题的核心是"自相似递归"，取球题的核心是"次序统计量/最后异色球位置"，步骤并不共享。
- **建议**：若严格按骨架判定，应拆为两个孤题。

### 4.6 PS-M26（矩约束下的极值与可达集）两题是否同母题

- **解释 A（合并，本报告采用）**：都以"在矩/支撑约束下求泛函的极值"为内核，都依赖 Cauchy–Schwarz / Chebyshev 积分不等式，都要讨论等号可达性。
- **解释 B（拆开）**：2015 个人 1 只需给一个**上界**（且用到 `max = ½(X²+Y²+|X²−Y²|)` 的拆解技巧），2016 个人 4 要求给出**完整可达区间**并构造两端分布，后者的"可达性"部分在前者中不存在。

### 4.7 PS-S09（耦合与全变差距离）是否应并入 PS-M33

- **解释 A（保持孤题，本报告采用）**：2022 个人 2 是**耦合理论的存在性/变分刻画**（`‖µ−ν‖_{TV} = inf P(X≠Y)`），与 Markov 链的混合问题只是共享"全变差"这个度量。
- **解释 B（并入 PS-M33）**：2022 个人 4 的收敛率正是用全变差刻画的，而耦合是证明全变差收敛的标准工具；两者放在一起是完整的"全变差方法论"。
- **建议**：若并入，PS-M33 将变成 5 题、score = 9，进入 TOP3。

### 4.8 PS-S03 与 PS-S12 是否应合并为"密度变换与构造"

- **成员**：2014 团体 2（比值 Z=X/Y 的密度）、2026 个人 3（验证 `2φ(x)Φ(ax)` 是密度并求期望）。
- **解释 A（保持孤题，本报告采用）**：前者是 Jacobian 换元的机械计算，后者是"用对称性证明归一化 + 一阶矩计算"，步骤不共享。
- **解释 B（合并）**：两者都属于"分布/密度的构造与验证"这一大类，作为复习单元可以一起过。

### 4.9 PS-S13（Brownian 退出时间）是否应与 PS-M28（随机游走极值）合并

- **解释 A（保持孤题，本报告采用）**：连续时间过程的首次退出时间要用可选停止 + 鞅 `B_t² − t`，与离散游走的计数问题技术不同。
- **解释 B（合并）**：Brownian 运动是随机游走的连续极限，"首次退出/首次命中"是同一族问题；且 2026 出现 Brownian 题可能预示连续时间过程的回归。

### 4.10 PS-M14 与 PS-M16/PS-M17 之间的"检验类题目"切分

- 2012 团体 6（LRT + 局部功效）、2013 个人 4（p 值分布）、2023 个人 6(b)（精确检验 + 功效来源）三题都涉及**检验**。本报告把 2012/2013 两题合为 PS-M14，而把 2023 个人 6 整体并入 PS-M02（因为它的主体是 MLE 的渐近分布）。若把"检验"作为独立母题，则 {2012团6, 2013个4, 2023个6} 应合为一题 3 成员的"检验的构造与功效"母题，而 PS-M02 缩为 3 题。**两种切法各有道理，取决于把"检验"还是"渐近分布"当作内核。**

### 4.11 记录粒度带来的残余不确定性

2012 个人 2、2012 团体 2、2010 团体 2/3、2013 个人 1 这 5 条记录均含**跨题拼接的截断文本**（详见 §0.2）。本报告按"记录主体内容"归属唯一母题，但其中被并进来的次要小题（2012 个人 2 的 `E[X|G]` 与 `E(X|X+Y)`；2012 团体 2 的"几何个指数之和的分布"；2013 个人 1 的"依概率收敛的度量化"）**没有**被计为独立成员。若按"小题"粒度重算，PS-M05、PS-M11、PS-M09 各会各增 1 个成员，覆盖率不变但母题的内部差异描述会不同。这一粒度选择是 **口径判断**而非事实判断，特此声明。
