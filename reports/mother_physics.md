## §0 方法与口径

### 0.1 「同一母题」的判定标准

对任意两题 A、B，依次做三项测试：

| 代号 | 测试 | 判据 |
| --- | --- | --- |
| **T1 数学结构相同** | 两题的核心是同一个数学对象/方程/代数结构（不只是同一个物理场景） | 例如「配分函数 → 对 h、T 求导 → 响应函数」；「d 维圈积分 → Γ 函数 1/ε 极点 → 抵消项」 |
| **T2 解法骨架相同** | 剥掉物理外衣后，两份解答的步骤序列可以一一对应，重合步骤 ≥ 60%，且**卡点位置相同** | 这是必要条件 |
| **T3 对象可替换（换皮测试）** | 把 A 的对象整体换成 B 的对象后，题目与解答仍然自动成立 | 例如「平均场 Ising」换「3 自旋精确 Ising」；「高斯脉冲」换「突加静电场」 |

**判定规则：必须满足 T2，且满足 T1、T3 中至少一条。**

物理场景相同**不构成**合并理由（见 0.2 的 E2）。共享工具箱**不构成**合并理由（E1）。

### 0.2 明确排除的边界情况

- **E1｜只共享工具，不共享骨架。** 「维数正规化」「泰勒展开」「Feynman 参数化」「变分法」本身是工具库，任何两题都可能同时用到。若工具之外的步骤序列对不上，不合并。
- **E2｜只共享物理场景。** 电磁学的四道题（2023 n=3、2024 n=3、2025 n=2、2026 n=2）都出现 E、B，但方程（推迟波动方程 / 导体色散关系 / 近轴梯度展开 / 磁静泰勒展开）、边界条件与求解结构完全不同，**四题各自独立成母题**，不做「麦克斯韦方程组」大合并。同理统计物理的三道题（2023 n=4、2024 n=4 与 2025 n=4、2026 n=4）不合并成一个「热力学母题」。
- **E3｜共享起点但被问的东西不同。** 2022 n=6 与 2026 n=5 都以「写出 O(N)/φ⁴ 模型的传播子与顶点、列单圈四点图」为第一问，但前者要数 N 的幂次取大 N 领头阶、后者要提取 1/ε 极点并写 RG 方程。**被问的内核不同 → 不合并**（详见 §4-Q1）。
- **E4｜同卷同章不同内核。** 2023 卷的第 1 题（拉格朗日量反推矢势）与第 2 题（二维谐振子简并微扰）同属「力学」，但一道是规范结构反推、一道是简并微扰与精确解对照，不合并。
- **E5｜纯几何题不硬塞进物理母题。** 几何卷中大量「给定 Riemann 度量算 Ricci/标量曲率」「Einstein 流形的刚性（Schur 引理 / 3 维 Einstein 蕴含常曲率 / 梯度 Ricci soliton）」的题，其**提问内核是几何不等式与刚性定理**，与物理卷「先导出度规再判定 Einstein 性」不是同一骨架，**不归并**。只有结构确实同构的两处做了跨科目归并（§2.5 XSUB-01、XSUB-02）。

### 0.3 关于「仍在考」与「趋势」

- **仍在考** = 该母题在 **2025 或 2026** 卷中出现过。
- 趋势用四种词：
  - **原样重复**：对象与问法几乎不变；
  - **换皮**：对象/参数化改变，骨架与卡点不变；
  - **升要求**：每次出现都在前一版上追加新的技术环节（出现明确的升级链）；
  - **降要求**：后一版砍掉了前一版的硬环节。
- 编号规则：`MP-<领域字母><两位序号>`（M 力学 / Q 量子 / E 电磁 / S 统计热力学 / G 广义相对论与几何 / F 量子场论）；跨科目母题用 `XSUB-xx`。

## §2 每个母题一节

### MP-M01 拉格朗日力学：有效一维势 → 平衡与稳定性 → 线性化小振动频率

**数学内核。** 不是在考「拉格朗日方程」这个名词，而是在考一条固定的流水线：**（i）** 用最少广义坐标写出 L；**（ii）** 识别循环坐标/守恒量，把多自由度问题压成**有效一维**问题（把守恒量当参数塞回势能，得到 U_eff）；**（iii）** 在 U_eff 上解平衡方程，用 U_eff'' 的符号判定稳定性并定出临界参数（Ω 或 k 的阈值）；**（iv）** 在稳定平衡点线性化，读出小振动频率；**（v）** 讨论频率与参数的函数关系在极限/共振点的行为。整条链的数学实质是「**U_eff 的一阶、二阶导数分析**」，物理外衣完全可换。

**成员逐一。**

- **2024 n=1（(Classical Mechanics) 中心势 V(r)=αr^k）**——母题的最朴素版本。自由度 1（r），角动量守恒给出有效势 U_eff = αr^k + L²/(2mr²)。
  - (a)(b) 写 L、做有效一维约化；(c) 圆轨道半径与周期；(d) 对哪些 k 稳定；(e) 小振动周期 + **在什么 k 下轨道闭合**；(f) 消去时间得轨道微分方程（Binet 方程）。
  - 与母题的差异：多了 (e) 的**闭合轨道**与 (f) 的**轨道方程**，即从「频率」再往前推到「轨道形状」。
- **2025 n=1（旋转圆环上的珠子）**——母题的**含时（rheonomic）约束**版本。自由度仍是 1（θ），但约束本身带 ω。
  - (1) L 与运动方程；(2) **守恒量与哈密顿量；H 是否等于固定系中的能量？（概念辨析）**；(3) 临界角速度 Ω 与 ω≶Ω 时的稳定平衡位置；(4) 稳定平衡点的小振动频率。
  - 与母题的差异：多了第 (2) 问的**概念辨析**——H 是否等于能量、固定系的能量是否守恒。这是 2024 版没有的环节。
- **2026 n=1（滑动摆）**——母题的**两自由度耦合**版本，且加了**约束力**要求。
  - (1) x–z 平面小振动角频率（M、m 两体耦合）；(2) 滑动圆锥摆（M 可在 x–y 平面自由滑动）的圆运动角频率随 θ 的函数，并验小 θ 极限；(3) 倒立滑动摆从 θ=π 由静止下落，**张力 T 何时为零**（M 趋于无穷）；(4) M、m 任意时 θ=π/2、π 处的张力。
  - 与母题的差异：从「求频率」升级为「**求广义约束力（张力）**」，需要写出完整的约束方程并解拉格朗日乘子/受力分析；提示里还给了椭圆的曲率半径，暗示要用曲率而非纯线性化。

**递进关系（升级链）。**

```
2024 n=1  单自由度 · 中心势 · 直接给参数讨论稳定性
          └─ 加：闭合轨道判据 + Binet 轨道方程
2025 n=1  单自由度 · 含时约束 · 需自己求临界参数 Ω
          └─ 加：H 与能量的概念辨析
2026 n=1  两自由度耦合 · 圆锥摆扩展 · 约束力（张力）
          └─ 加：曲率/约束力分析，线性化已不够用
```

**标准解法骨架（7 步）。**

1. 选广义坐标（尽量少），写出 L = T − V；确认约束是否显含时间。
2. 找循环坐标 → 守恒量（角动量 L_z / 广义动量 p_θ）。
3. 用守恒量消去一个自由度，得到有效一维问题与 U_eff。
4. 令 dU_eff/dq = 0 解平衡点（含临界参数 Ω_c 或 k 阈值）。
5. 判稳定性：U_eff'' > 0 稳定；由此解出「稳定区间」的参数不等式。
6. 稳定点附近 Taylor 展开到二阶，得到 ν = √(U_eff''/M_eff)。
7. （进阶）判断闭合轨道（径向频率与角频率之比为有理数）或写出轨道微分方程；若要求约束力，联立约束方程解乘子。

**最容易卡住的一步。** **第 3 步的 M_eff**：把守恒量代回动能项时，二维动能 ½m(ṙ²+r²φ̇²) 里的 r²φ̇² 会变成 L²/(2mr²) 而并入 U_eff，这一项的 1/r² 是决定稳定性阈值与闭合轨道判据的唯一来源；漏掉它（或把它留在 T 里）会让后面全部结论错位。2026 n=1 的两体版本中，M_eff 是约化质量还是总质量也极易搞混。

### MP-M02 由拉格朗日量反推磁矢势/规范结构（并讨论对称性与守恒量）

**数学内核。** 给定一个**带 1/r² 权重的非常规拉格朗日量** L = (ẋ²+ẏ²+2(xẏ−yẋ))/(x²+y²)，要求把它**辨认成规范耦合的形式** ½f[(p−A)²]：先做 Legendre 变换求 H，再把 H 配方读出 f 与 A，最后算 B = ∇×A。这是一个「**从动力学量反推几何/规范结构**」的逆向题，而不是常规的「给你 A 求轨道」。

**成员逐一。**

- **2023 n=2（卷面第 1 题）**——本母题唯一成员。
  - (a) 求 H 并写成 ½f[(p_x−A_x)²+(p_y−A_y)²]，求 A 与原点外的 B；
  - (b) 证明 L 在**旋转**与**标度变换**下不变；
  - (c) 导出这两种对称性对应的守恒量；
  - (d) 换极坐标写 Euler–Lagrange 方程并求解。
  - 技术要点：由 p_x = ∂L/∂ẋ = 2ẋ/r² − 2y/r²、p_y = ∂L/∂ẏ = 2ẏ/r² + 2x/r² 反解并配方，可得 **f = r²/2、A = (2/r²)(−y, x)**，于是 **∇×A = 0（r>0）**——即该「磁场」只在原点有奇异性，是一支涡旋型（纯规范外）矢势。这一步的结论正是 (a) 的价值所在。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（6 步）。**

1. 由 L 求共轭动量 p = ∂L/∂q̇（注意 L 里有速度的一次项与 1/r² 权重）。
2. H = p·q̇ − L，并把 q̇ 用 p 表示。
3. 把 H 配方成 ½f[(p−A)²] 形式，读出 f 与 A 分量。
4. 计算 B = ∂_x A_y − ∂_y A_x，指出除原点外为零（涡旋势）。
5. 对旋转与标度变换分别算 δL，验证 δL = 0（或为全导数）。
6. 用 Noether 定理/直接计算给出守恒量，再换极坐标解 Euler–Lagrange 方程。

**最容易卡住的一步。** **第 3 步的配方**。因为 L 整体被 1/r² 加权，动量关系里同时混有 ẋ 与 y（或 ẏ 与 x），若按标准「½m v² + qA·v」的形式硬套，会得到错误的 f；必须先老老实实做 Legendre 变换、再从 H 的形式反推 f 与 A。第二步的常见错误是忘记 H = p·q̇ − L 中的一次项贡献。

### MP-Q01 二维各向同性谐振子的简并微扰：微扰论 vs 精确解

**数学内核。** 二维各向同性振子的能级 E_n = ℏω(n+1) 是 **n+1 重简并**的。母题要求：**在简并子空间内部**处理扰动（而不是用非简并微扰公式），然后**用精确可解的结果回验**。数学实质是「**简并子空间上的对角化 / 表示论分类**」加上「**微扰级数与精确谱的对照**」。

**成员逐一。**

- **2022 n=2（两个解耦谐振子）**——三个部分层层加码。
  - (a) 写出 H₀ 的本征态 |n₁,n₂⟩ 与本征值；
  - (b) **定义 J₊ = a₁†a₂、J₋ = a₂†a₁、J_z = ½(a₁†a₁ − a₂†a₂)，先证 [J_z,J_±] = ±J_±、[J₊,J₋] = 2J_z，再证固定 n = n₁+n₂ 的简并层构成 su(2) 的不可约表示并求自旋**——这是把「简并子空间」用**角动量代数**组织起来的做法（Schwinger 玻色子）；
  - (c) 对微扰 H′ = λx₁²p₂²，求 n₁+n₂ = 2 能级的一阶修正。
  - 与母题的差异：扰动项是**算符的四次型**（x₁²p₂²），必须用升降算符展开到正规序；且简并子空间的组织方式（su(2) 不可约表示）本身就是考点。
- **2023 n=2（卷面第 2 题，二维各向同性振子 + αmω²xy）**——母题的**精确可解**版本。
  - (a) α=0 时最低三个能级的能量与简并度；(b) 一阶微扰修正；(c) **求精确谱（提示：旋转 x、y）**；(d) 检验 (b) 能从精确谱复原。
  - 与母题的差异：**扰动是二次型**，所以只要旋转坐标即可**精确对角化**——题目明确要求「微扰 vs 精确」的对照；相反，(b) 的简并子空间对角化比 2022 简单（只需在二维简并子空间里对 xy 作对角化）。

**递进关系（换皮 + 双向对照）。**

```
2022 n=2   四次型扰动 x₁²p₂² + su(2) 表示论分类简并层 → 只做一阶微扰
2023 n=2   二次型扰动 αmω²xy + 旋转坐标精确解 → 一阶微扰与精确谱互相对照
```

两题共享骨架（列简并零级态 → 在简并子空间内对角化 → 与精确解对照），但 2022 的组织工具（su(2)）在 2023 中被替换为「坐标旋转」，属于典型**换皮**。

**标准解法骨架（6 步）。**

1. 写出 H₀ 的本征态、本征值与简并度（E_n = ℏω(n+1)，简并度 n+1）。
2. 确定目标能级的简并子空间维数。
3. 把扰动项用升降算符 a、a† 表示并正规序化。
4. **在该简并子空间内**构造扰动矩阵并对角化（或用代数/表示论分类，如 su(2) 不可约表示）。
5. 读出一阶能量修正与「好的」零级态。
6. 用精确解（坐标旋转 / 其他可积化）验证，讨论微扰级数的适用范围。

**最容易卡住的一步。** **第 4 步「只在简并子空间内对角化」**。学生最常见的错误是对 n=2 能级直接用非简并微扰公式 ⟨n|H′|n⟩，得到零修正便以为做完了——实际上扰动把简并层劈裂，必须处理 |20⟩、|11⟩、|02⟩ 三态之间的非对角元。2022 版的额外陷阱是 x₁²p₂² 中 p₂² 的**正规序展开**（会产生 a₂a₂、a₂†a₂† 项），一旦序搞错，一阶修正的符号与结构都会错。

### MP-Q02 谐振子的含时线性驱动：位移（压缩）算符、跃迁概率与期望值

**数学内核。** H = H₀ + F(t)·x 是**少数能被精确求解的含时问题**。数学实质：把驱动项识别为**相空间平移的生成元**，于是 a(t) 的海森堡方程退化为经典方程 ȧ = −iωa + iF(t)/…，解出 a_+∞ = a_−∞ + α。由于 |α⟩ 是相干态，末态布居严格是 **Poisson 分布** e^{−|α|²}|α|^{2n}/n!。整题考的是「**把算符问题化为 c-数问题**」这一招，以及由此得到的解析概率分布。

**成员逐一。**

- **2024 n=2（(Quantum mechanics) 瞬态扰动 ΔH = F(t)x）**——**脉冲驱动**版本。
  - (a) 用 a、a† 写出 Ĥ，在 **Heisenberg 绘景**下解运动方程，证明 t→±∞ 时 Ĥ = ℏω(a_±∞†a_±∞ + 1/2)，并求出 a_+∞ 与 a_−∞ 的关系；
  - (b) 求从基态跃迁到第 n 激发态的概率 |c_n|²；
  - (c) 求末态能量期望值；
  - (d) 对高斯脉冲 F(t) = F₀e^{−t²/(2σ_t²)}，F₀ = ηℏω/l，**讨论 σ_tω ≪ 1 时 η 的上限（丢布居 <1%）与 σ_tω ≫ 1 时损失可被任意压制**。
  - 与母题的差异：(d) 的**绝热/突变两极限分析**是本版独有；它把「指数抑制因子 e^{−ω²σ_t²}」与脉冲宽度直接挂钩。
- **2025 n=3（匀强电场中的一维谐振子 H = H₀ − qEx）**——**突加直流驱动**版本。
  - (1) 证明 H = e^{−A}H₀e^{A} + B（A 为算符、B 为 c-数），显式求出 A、B，由此说明 H 的谱是 H₀ 的谱经位移算符平移，并解出本征值问题；
  - (2) 把 A 用 a、a† 表示，求 t 时刻系统处于 H 基态的概率（初态为 H₀ 基态）；
  - (3) 求存活概率，并问何时该概率为 1（**回复时间**）；
  - (4) 求跃迁到 H₀ 第一激发态的概率；
  - (5) 用 a、a† 表示偶极矩 d = qx，求 ⟨d(t)⟩。
  - 与母题的差异：用「**算符因式分解 e^{−A}H₀e^{A} + B**」代替「解 Heisenberg 运动方程」，本质等价（A = i x₀p/ℏ，x₀ = qE/(mω²)，B = q²E²/(2mω²)）；但多出 (3) 的**回复时间**与 (5) 的**偶极矩振荡**，即在相干态上再取一次期望值。

**递进关系（换皮）。** 两版骨架完全相同（线性驱动 → 平移算符 → 相干态 Poisson 分布），只是驱动的时间轮廓从「瞬态脉冲」换成「突加直流」。**没有升要求的证据**：2024 的难点在 (d) 的渐近分析、2025 的难点在 (1) 的算符因式分解，各自新加了不同的枝节，属于平行换皮。

**标准解法骨架（6 步）。**

1. 把 H 写成 Ĥ = ℏω(a†a + 1/2) + F(t)·√(ℏ/2mω)(a + a†)（或 e^{−A}H₀e^{A} + B）。
2. 用 [H,a] = −ℏωa + … 得海森堡方程 ȧ = −iωa + iF(t)/√(2mℏω)（或直接做因式分解求 A、B）。
3. 解一阶线性 ODE：a(t) = e^{−iωt}[a(0) + ∫₀ᵗ e^{iωs}(iF(s)/…)ds]，得 a_+∞ = a_−∞ + α。
4. 由 a_+∞|0_−∞⟩ = α|0_−∞⟩ 认出 |0_+∞⟩ 是相干态 |α⟩。
5. 展开 |α⟩ 得 |c_n|² = e^{−|α|²}|α|^{2n}/n!，算 ⟨E⟩ = ℏω(|α|²+1/2) 与 ⟨x(t)⟩。
6. 对具体 F(t)（高斯/突加）算出 |α|²，取短脉冲/长脉冲/回复时间的极限。

**最容易卡住的一步。** **第 3 步的相位与符号**：e^{iωs} 的相位若写反，长脉冲极限下 |α|² 会趋于常数而非指数小，从而把 (d) 中「长脉冲可任意压制损失」的结论做反。2025 版的对应陷阱是第 1 步 A 的符号——A 与 x₀ 的关系必须与 e^{−A}xe^{A} = x − x₀ 一致，符号错了 B 的符号也随之错。

### MP-Q03 时间反演算符的反幺正性及其对波函数的后果

**数学内核。** 这是量子力学公理层面的一道题：**（i）** 用「保持 |⟨φ|ψ⟩| 的概率守恒 + 时间反演的物理要求」论证 Θ 只能是反幺正的（幺正算子无法实现 t → −t 又不改变动量/角动量的变换性质）；**（ii）** 由 Θ|x⟩ = |x⟩ 推出位置表象波函数变成复共轭；**（iii）** 在无简并定态上，ΘH = HΘ 且 Θ|ψ⟩ ∝ |ψ⟩，故 ψ 可取实。数学实质是**反幺正算符在坐标表象中的作用规则**（Θ 不作用在 c-数上，只对系数取共轭，对 ket 作用 Θ）。

**成员逐一。**

- **2022 n=1** —— 本母题唯一成员。(a) 证明 Θ 反幺正；(b) 证明 Θ|ψ⟩ 的位置表象波函数为 ψ(x)*；(c) 无简并能量本征态可取实波函数。三问是一条完整的推理链：**公理 → 表象作用规则 → 具体推论**。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（5 步）。**

1. 写出时间反演要求：位置不变、动量反号（ΘpΘ⁻¹ = −p），由此说明 Θ 不能是幺正的。
2. 对一般算符 Θ 定义反幺正性：Θ(α|ψ⟩+β|φ⟩) = α*Θ|ψ⟩+β*Θ|φ⟩ 且 ⟨Θψ|Θφ⟩ = ⟨ψ|φ⟩*。
3. 在坐标表象：ψ_Θ(x) = ⟨x|Θ|ψ⟩，插入 Θ²=1、Θ|x⟩=|x⟩ 与反幺正性，得 ψ_Θ(x) = ⟨x|ψ⟩* = ψ(x)*。
4. 由 ΘH = HΘ：H(Θ|ψ⟩) = ΘH|ψ⟩ = E(Θ|ψ⟩)，故 Θ|ψ⟩ 仍是 E 的本征态。
5. 由无简并性 Θ|ψ⟩ = c|ψ⟩；由反幺正与 Θ²=1 定出 |c|=1（相位），量子数取法下可取 ψ 实。

**最容易卡住的一步。** **反幺正算符作用在叠加态上时要取系数的复共轭**（第 2→3 步）。绝大多数错误来自把 Θ 当成线性算符处理，从而无法解释为什么 Θ|x⟩=|x⟩ 会给出 ψ(x)* 而不是 ψ(x)；另外 Θ²=1 与 Θ 反幺正是否相容（事实上 Θ² = ±1，取决于自旋）也是常见争议点。

### MP-Q04 δ 势散射：无反射透射与双中心束缚态

**数学内核。** 一维部分考的是 **δ 势的匹配条件**（ψ 连续、ψ′ 的跳变量 = (2mβ/ℏ²)ψ(a)）与由它导出的**透射系数共振**：两个 δ 势形成一个「腔」，在特定动能下反射完全相消。三维部分考的是 **S 波散射长度 a 的符号判据**：a < 0 表示没有束缚态，但**两个 a<0 的中心靠得足够近时可以共同支持一个束缚态**（这是「两个弱吸引中心」的经典结论）。数学实质是**一维转移矩阵/匹配条件**与**三维零能散射的边界条件**。

**成员逐一。**

- **2026 n=3** —— 本母题唯一成员。
  - 1. 一维双 δ 势能否无反射穿透？2. 在哪些动能下发生？（要求解出共振条件）
  - 3. 三维双 δ 中心（每个 S 波散射长度 a<0）在各自中心附近的 S 波束缚波函数，并验证 a<0 时单中心不支持束缚态；
  - 4. 双中心势能否支持束缚态？条件是什么？（提示：硬核势的 a 由 d log χ(R)/dR = −1/a 定义，须从 a 的约束出发）

**递进关系。** 仅出现一次，无链。

**标准解法骨架（6 步）。**

1. 分区间写出自由解（平面波或 e^{−κr}），在 δ 处用匹配条件（ψ 连续 + ψ′ 跳跃）。
2. 一维：构造转移矩阵，写出透射系数 T(E)；令 T = 1 得共振条件。
3. 解共振条件：得到一组离散的共振动能（与腔长 a 有关）。
4. 三维：写出每个中心的 S 波约化波函数 χ(r) = rψ(r)，用 d log χ(R)/dR = −1/a 把 a 的符号与束缚态存在性挂钩。
5. 综合两个中心的方程（非齐次项来自另一个中心的场），得到一个**行列式条件**。
6. 由该条件得到「双中心束缚态存在」的临界间距/耦合强度判据。

**最容易卡住的一步。** **第 5 步「两个中心互相看对方」的自洽条件**。单中心 a<0 无束缚态的结论会诱使学生直接回答「双中心也没有」，但两中心之间会交换虚粒子形成等效吸引；必须对每个中心写出「本中心短程行为由另一中心的长程尾巴驱动」的方程并联立，才能得到正确的存在性条件。

### MP-E01 势与规范：从 A_µ 到场，剩余 Maxwell 方程的推迟解

**数学内核。** 用 (φ,A) 重新组织 Maxwell 方程组：**两组方程变成恒等式**（因为 B = ∇×A、E = −∇φ − ∂_tA 的定义本身），**另两组变成势的波动方程**（在 Lorentz 规范下解耦）。要真正解出来，还得用**推迟 Green 函数**把源（运动点电荷）积分出来，并在非相对论远场近似下展开。数学实质是「**规范自由度 → 波动方程 → 推迟积分 → 渐近展开**」这条完整的从方程到解的链。

**成员逐一。**

- **2023 n=3** —— 本母题唯一成员。
  - (a) 用 (φ,A) 表示 E、B，并验证在 φ→φ+∂_tf、A→A−∇f 下不变；
  - (b) 证明 4 个 Maxwell 方程中的两个自动满足；
  - (c) 在 Lorentz 规范 (1/c)∂_tφ + ∇·A = 0 下导出势的方程；
  - (d) 用题给的**推迟 Green 函数** G(t−t′, r−r′) = θ(t−t′)δ(t−t′−|r−r′|/c)/(4π|r−r′|)，对以速度 v(t) 运动的点电荷求出 φ(r,t)、A(r,t)，在 |R|≪|r|、|R|≪ct、|v|≪c 下展开到 O(1/|r|)、O(|v|/c)（非相对论远场，即偶极辐射区）。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（6 步）。**

1. 由定义写出 E = −∇φ − ∂_tA、B = ∇×A。
2. 验证规范变换下 E、B 不变（∇×∇f = 0、∇(∂_tf) = ∂_t∇f）。
3. 指出 ∇·B = 0 与 ∇×E + ∂_tB = 0 由 (1) 自动成立。
4. 把剩余两式代入 (1)，得 ∇²φ + (1/c)∂_t(∇·A) = −ρ/ε₀ 等，再用 Lorentz 规范解耦成两个 d'Alembert 方程。
5. 用推迟 Green 函数写出 φ(r,t) = ∫G(t−t′,r−r′)ρ(r′,t′)d³r′dt′，把 ρ、j 取为点电荷的 δ 源。
6. 在 |R|≪|r|、|v|≪c 下 Taylor 展开被积函数，得到 φ 的 1/|r| 项与 A 的偶极项。

**最容易卡住的一步。** **第 6 步的展开**：Green 函数里的 δ(t−t′−|r−r′|/c) 会把 t′ 钉在推迟时刻 t_ret = t − |r−R(t′)|/c 上，而这个 t_ret 本身又依赖待求的 R(t′)。必须先把 |r−R| 展开成 |r| − r̂·R 再代入 δ 的宗量，才能正确得到滞后展开；直接对 R 做 Taylor 而忽略 δ 的宗量依赖是最常见的错误。

### MP-E02 导体介质中的电磁波与反射（边界条件定场）

**数学内核。** 在**有耗介质**中把 Maxwell 方程化为色散关系，得到复波数 k_c = (1+i)√(σω)/√2 c，并由此读出**趋肤深度**；再用**边界条件**（E 切向连续、B 法向连续、理想导体内 E = 0）定反射/透射场。数学实质是「**复波数 + 边界条件线性方程组**」；极化反相不是独立知识点，而是边界条件的直接推论。

**成员逐一。**

- **2024 n=3** —— 本母题唯一成员。
  - (a) 在 σ ≫ ω 极限下证明金属中的阻尼波解 H(t,z) = H_c e^{−iωt+ik_c z}，k_c = (1+i)√(σω)/√2 c（Heaviside–Lorentz 与 SI 两套单位换算）；
  - (b) 用 Maxwell 方程把 E_c 用 H_c 表示（由 ∇×H = ∂_tD + j 得 E-H 振幅关系与相位差）；
  - (c) 线偏振平面波正入射理想导体（σ→∞），反射波振幅等于入射但**极化反相**，用边界条件解释；
  - (d) 有限大电导率下，按 ω/σ 领头阶求金属内的 E、B 场。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（6 步）。**

1. 写出欧姆导体中的 Maxwell 方程组（含 j = σE）。
2. 取单色平面波 e^{−iωt+ikz}，得色散关系 k² = μ₀ε₀ω² + iμ₀σω。
3. 在 σ/ε₀ ≫ ω 下取领头项，得复波数，读出衰减长度（趋肤深度）。
4. 由 ∇×H = ∂_tD + σE 得 E_c 与 H_c 的线性关系（含相位差）。
5. 写边界条件并在界面 z=0 匹配：理想导体 E_t = 0 蕴含反射系数 = −1，即振幅相等、极化反相。
6. 有限 σ：在金属内取 ω/σ 领头阶解，与真空解按边界条件拼接。

**最容易卡住的一步。** **第 5 步用边界条件解释「极化反相」**。很多解答会说「因为金属里没有电场，所以反射波必须抵消入射波」，但要真正回答题目，必须写清楚：E 的切向在导体表面为零，故 E_inc + E_ref = 0，即 E_ref = −E_inc；同时由 ∇×H 的关系，H_ref = +H_inc（切向磁场加倍）。E 反相而 H 同相这一点若混为一谈，第 (d) 问的拼接就会出错。

### MP-E03 近轴波包：梯度展开的高阶修正与光的角动量

**数学内核。** 「近轴近似」并不是一个粗略的物理假设，而是一个**受 Maxwell 方程约束的渐近展开**：零阶解 E⁽⁰⁾ = E₀(x,y)e^{i(kz−ωt)}x̂ 满足波动方程，但**不满足 ∇·E = 0**（因为 E₀ 随 x,y 变化）。于是必须加一个**纵向修正项 E⁽¹⁾(x,y)e^{i(kz−ωt)}ẑ**，其大小由 ∇·E = 0 唯一确定。数学实质是「**横向散度不为零 → 必须补一个纵向分量**」；由此算出的 ⟨L_z⟩/⟨U⟩ 就是**光子的自旋角动量**（圆偏振每光子 ℏ）。

**成员逐一。**

- **2025 n=2** —— 本母题唯一成员。
  - 1. 忽略 E₀ 的所有导数，验证 E⁽⁰⁾、B⁽⁰⁾ = ẑ×E⁽⁰⁾ 在 ω = ck 时满足 Maxwell 方程；
  - 2. 算波包单位长度的时均能量 ⟨U⟩（高斯剖面，用题给积分）；
  - 3. 保留 E₀ 的导数，在 kσ ≫ 1 下求 E⁽⁰⁾、B⁽⁰⁾ 的一阶梯度修正，提示取 E = E⁽⁰⁾ + E⁽¹⁾(x,y)e^{i(kx−ωt)}ẑ 的形式（题目式 (4) 里指数写成 kx−ωt，应与第 1 问的 kz−ωt 一致）；
  - 4. 把解写成平面波解的线性叠加，从叠加角度定性解释 E_z 修正的来源，并精确复现它；
  - 5. 求波包单位长度时均角动量 z 分量 ⟨L_z⟩ 到 kσ 的最低非平凡阶；
  - 6. 求 ⟨L_z⟩/⟨U⟩，用光子图像解释。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（6 步）。**

1. 取圆偏振近轴试探解 E = E₀(x,y)e^{i(kz−ωt)}(x̂+iŷ)/√2，验证最低阶 Maxwell 方程。
2. 算 ∇·E，发现它正比于 E₀ 的横向导数，并不为零，故零阶解不自洽。
3. 令 E_z 的一阶修正满足 ikE_z + (横向散度项) = 0，解出 E⁽¹⁾。
4. 用平面波叠加（角谱）解释：不同 k_⊥ 的平面波相位不同，横向分量倾斜，合成出了纵向分量。
5. 算动量密度与角动量密度，对横向剖面积分得 ⟨L_z⟩（保留到 kσ 的最低阶）。
6. 与 ⟨U⟩ 相比，得 ⟨L_z⟩/⟨U⟩ = ±1/ω，即每光子 ±ℏ 的自旋。

**最容易卡住的一步。** **第 3 步：为什么必须补纵向分量、补多少**。直觉上「圆偏振波只看横向」会让人认为零阶解已经正确；真正的判据是 ∇·E = 0 这个约束（在无源区），而 E₀ 的横向导数破坏了它。此外第 5 步里 ⟨L_z⟩ 的主导项来自 r×（动量密度）的横向部分与自旋部分的组合，若只算 r×⟨p⟩ 会漏掉自旋贡献并得到错误的比值。

### MP-E04 准静态场的离轴泰勒展开、感应场与近似失效判据

**数学内核。** 在**无源区**（轴附近、线圈之外）B 满足 ∇·B = 0 与 ∇×B = 0，于是 B 可以由**轴上场 B_z(z) 的泰勒系数**完全决定离轴场——这正是「轴上展开 + 无源条件」的换元法（等价于 B = −∇Φ，Φ 满足 Laplace 方程）。数学实质是**调和函数的轴对称展开**：一旦知道轴上 B_z(z) = B₀ + ½β₂z² + …，就可以唯一地写出 B_z 与 B_ρ 的离轴形式。后半部分再加一层**准静态近似的时间修正**：缓变电流产生感应电场，并要求估计磁静近似失效的尺度。

**成员逐一。**

- **2026 n=2** —— 本母题唯一成员。
  - 1. 在磁静近似下，由轴上展开 B_z(z) ≃ B₀ + ½β₂z² 出发，证明轴附近的 B_z ≃ B₀ + ½β₂(z²−ρ²/2)、B_ρ ≃ −½β₂zρ；
  - 2. 求螺线管/双线圈轴附近到 (z,ρ) 二次阶的磁场，并描述 **h = a（Helmholtz 条件）**时的场；
  - 3. 求 z=0 处轴附近最低非平凡阶的感应电场（由 ∂B/∂t 与 Faraday 定律/矢势）；
  - 4. (a) 给出第 2、3 部分有限频率修正的量级估计；(b) 估计轴上磁场计算中磁静近似在多大的 z 处失效。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（6 步）。**

1. 写出 ∇·B = 0 与 ∇×B = 0（无源区）给出的约束（或引入磁标势 ∇²Φ = 0）。
2. 写出轴上场 B_z(z) 的泰勒展开，读出 B₀、β₂。
3. 由 ∇·B = 0（或 Laplace 方程的轴对称解）确定离轴项：ρ² 项与 z² 项的系数之比固定为 −1/2。
4. 由 ∂B_z/∂z = ∂B_ρ/∂ρ（∇×B = 0）定出 B_ρ 的领头项 −½β₂zρ。
5. 对缓变电流，用 Φ 或 Faraday 定律求感应 E（E_φ 正比于 ρ·∂B_z/∂t）。
6. 估计修正量级：有限频率修正正比于 (ω·尺度/c)²；磁静近似失效的 z 满足「传播延迟与几何尺度相当」，即 z 达到 c/ω 量级。

**最容易卡住的一步。** **第 3 步「用哪个方程定系数」**。学生常试图直接对离轴点做 Biot–Savart 积分（极难），而正解是：**只用无源条件**，让 z² 项与 ρ² 项的系数由 ∇·B = 0 绑死（−1/2 那个关系）。另外第 3 问的感应电场必须通过 ∂B/∂t（Faraday 定律）而不是静态 Coulomb 项，否则会漏掉主导的 E_φ。

### MP-S01 Ising 模型：配分函数 → 自由能/热容/磁化率 → 临界与低温行为

**数学内核。** 一条固定流水线：**（i）** 写出能量 → 配分函数 Z（求和或平均场近似下的自洽方程）；**（ii）** F = −T ln Z；**（iii）** 由对 h、T 的导数得到响应函数 m、C = ∂U/∂T、χ = ∂m/∂h；**（iv）** 取临界极限读出幂律指数，或取低温极限读出涨落。数学实质是「**配分函数 → 热力学势 → 对场/温度求导 → 渐近行为**」这条链，与具体格点、是否平均场无关。

**成员逐一。**

- **2024 n=4（(Statistical Mechanics) 平均场 Ising）**——**解析近似 + 临界指数**版本。
  - (a) 由 H_MF = (1/2)NJm² − (Jm+h)Σσ_i 求配分函数与自由能；
  - (b) 导出磁化强度的**自洽方程**，h=0 时作图求解，讨论各解随 T 的物理性质，定出 T_c 及其物理意义；
  - (c) 在 β(Jm+h) ≪ 1 下求 m、C、χ 对 t = (T−T_c)/T_c 的依赖，**定出平均场临界指数 α_c、β_c、γ_c**（题给 U 正比于 Jm²）。
  - 与母题的差异：核心是**自洽方程的图形解**与**小量展开取幂律**，需要处理 h=0 时 m=0 与非零两支的分岔。
- **2025 n=4（三角形上的 Ising 模型，3 个自旋）**——**精确枚举 + 低温涨落**版本。
  - 1. 求配分函数（8 个组态，可按能量分组枚举）；2. 自由能与熵；3. h=0 时的比热，以及 T ≪ J、T ≫ J 两种极限；4. 给定 h 且 T ≪ J 时的磁化强度 M = ⟨σ₁+σ₂+σ₃⟩ 与低温磁化率 χ = ∂M/∂h|_{h=0}；5. T ≪ J 时磁化的涨落 ⟨(σ−M)²⟩。
  - 与母题的差异：没有自洽方程，改为**精确枚举**；问题从「临界指数」换成「**低温极限与涨落**」。这是典型的**换皮**（3 自旋是有限系统，不存在真正的相变，但低温/高温极限的物理结论可以对上）。

**递进关系。** 两者是**平行换皮**，不构成升级链：

```
2024 n=4  平均场 · 自洽方程 · 图形解 · 临界指数 α,β,γ
2025 n=4  有限格点精确解 · 低温/高温极限 · 磁化率与涨落
```

**标准解法骨架（6 步）。**

1. 写出模型能量（平均场下先把 Σσ_iσ_j 用 m 替换掉，把相互作用并入有效场）。
2. 求配分函数：平均场下是单自旋求和 Z = e^{−βNJm²/2}[2cosh β(Jm+h)]^N；精确解下是按能量分组枚举。
3. 由 F = −T ln Z（或 f = F/N）得自由能。
4. 求导数得 m、U、C = ∂U/∂T、χ = ∂m/∂h。
5. 在 h → 0 与 T → T_c 附近做小量展开（平均场）或在 T ≪/≫ J 下取极限（精确解），读出幂律或指数抑制。
6. 由幂律指数定出临界指数，或由低温涨落得 χ 的行为。

**最容易卡住的一步。** **第 4→5 步「先求导再取极限」的顺序**。若先令 h=0 再对 h 求导，χ 会恒等于 0；必须保留 h 求导后再令 h→0。平均场版本里第二个陷阱是自洽方程 m = tanh β(Jm+h) 的分岔讨论（h=0 时方程的根个数随 T 变化），漏掉非零根就会得不出 T_c；精确解版本的陷阱是低温极限下必须**保留到足够高阶**才能看出 χ 的指数行为。

### MP-S02 自由量子气体的热容：Bose/Fermi 积分

**数学内核。** 由分布函数写出内能 U = ∫E(k)n(E)d³k/(2π)³，再在**两种不同的极限**下求值：玻色情形取 μ = 0（光子型），得 U 正比于 T^{d+1}，热容正比于 T^d；费米情形取 μ ≫ k_BT（简并），用 Sommerfeld 展开得热容正比于 T。数学实质是**把热力学量化为可以直接查表的积分**（题面直接给了 Σ1/k² = π²/6 与 Σ(−1)^{k+1}/k² = π²/12）。

**成员逐一。**

- **2023 n=4** —— 本母题唯一成员。(a) 一维无质量玻色子（E = ℏv|k|）在 μ=0 时求单位长度热容；(b) 有质量费米子（E = ℏ²k²/2m）在 μ ≫ k_BT 时求热容，一维、单一自旋方向，允许合理近似。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（5 步）。**

1. 写内能积分 U = ∫dE g(E)E/(e^{(E−μ)/k_BT} ± 1)，写出一维态密度 g(E)。
2. 玻色、μ=0：把积分化为 ∫x^s/(e^x−1)dx 型（用题给的 ζ(2) = π²/6）。
3. 费米、μ ≫ k_BT：零温部分 + Sommerfeld 展开（或直接把 e^{(E−μ)/k_BT} 在 E_F 附近展开）。
4. 由 C = ∂U/∂T 得热容的温度依赖（线性 vs 常数 vs T^d）。
5. 检查量纲与极限（T→0 时 C→0；高温时回到经典值）。

**最容易卡住的一步。** **态密度与分布函数的匹配**：一维无质量玻色子的 g(E) 是常数，而一维费米子的 g(E) 正比于 E^{−1/2}，两者形状不同；若照搬三维的 g(E) 正比于 E^{1/2}，积分会给出错误的温度幂次（把 C 正比于 T 算成 C 正比于 T³ 之类）。

### MP-S03 相平衡条件与 Clausius–Clapeyron 关系

**数学内核。** 两相共存等价于**化学势相等** μ_液(T,P) = μ_气(T,P)（等价于 Gibbs 自由能相等）。沿共存曲线求导，利用 S = −∂G/∂T、V = ∂G/∂P，即得 Clausius–Clapeyron 方程 dP/dT = ΔS/ΔV = L/(TΔV)。数学实质是**隐函数求导**：共存曲线是 μ_液 − μ_气 = 0 的等值线。

**成员逐一。**

- **2026 n=4** —— 本母题唯一成员。
  1. 写出液气两相沿共存曲线达到热力学平衡的条件；
  2. 利用第 1 问的解并考虑液气相变的熵变，导出共存曲线上蒸气压满足的关系（即 Clausius–Clapeyron）。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（4 步）。**

1. 写出平衡条件：μ_液(T,P) = μ_气(T,P)（或 g_液 = g_气），沿共存曲线处处成立。
2. 沿曲线全微分：dμ_液 = dμ_气，用 dμ = −s dT + v dP 展开。
3. 整理得 dP/dT = (s_气 − s_液)/(v_气 − v_液) = ΔS/ΔV。
4. 把汽化潜热 L = TΔS 代入，得 dP/dT = L/(TΔV)；气相近似理想气体时进一步化为 d lnP/dT = L/(RT²)。

**最容易卡住的一步。** **第 2 步用 dμ = −s dT + v dP 而不是 μ 的显式表达式**。很多解答会去猜 μ 的具体形式（从而引入不必要的模型假设），正解是只用热力学恒等式做隐函数求导；另一个常见错误是把熵变写成「气相的绝对熵」而不是**两相之差**。

### MP-G01 非标准定义的度规：先导出度规，再算曲率，判定 Einstein / 常曲率

**数学内核。** 这是一条关于**「几何对象 → 曲率张量」**的固定流水线，考的从来不是「会不会背 Christoffel 公式」，而是：**（i）能不能从一个不是直接给出的几何描述里把 g_µν 抠出来**（嵌入超曲面的诱导度规 / 距离公式的展开 / ansatz 的系数待定）；**（ii）能不能用最少的分量计算拿到 Ricci 与标量曲率**；**（iii）能不能由 R_µν = kg_µν（或 R_µνρσ = K(g_µσg_νρ−g_µρg_νσ)）判定这是 Einstein 度量/常曲率空间，并定出常数**；**（iv）验证给定向量场是 Killing 场**。最后一步（Killing 检验）在四道题里**每次都出现**，是这条流水线的固定收尾。

**成员逐一。**

- **2022 n=4（Eddington–Finkelstein 型度规 ds² = −(1−2M/r)dv² + dv dr + r²dΩ²）**——最浅的一版，重点在**零超曲面**。
  - (a) 证明 l = f(x)g^{µν}∂_νS·∂_µ 是 S = r−2M = 0 的法向量（这是「梯度必为法向量」的直接验证，注意需先升指标）；
  - (b) 证明 l² = 0（在超曲面上），即该超曲面是**零超曲面**（视界）；
  - (c) 证明 ∂_v 是 Killing 向量场。
  - 与母题的差异：**不要求算 Ricci**，只要求最基础的度规操作（逆度规、法向量、Killing 方程）；但把「零超曲面」这一概念作为核心考点，是其他三题没有的。
- **2023 n=5（真空 Einstein 方程 + 宇宙学常数 Λ）**——**ansatz 求解**版本。
  - (a) 对 R_µν − ½g_µνR + g_µνΛ = 0 取迹，证明 R_µν = kg_µν 并定出 k（4 维下即 R_µν = Λg_µν）；
  - (b) 对 ds² = −f(r)dt² + dr²/f(r) + r²(dθ²+sin²θdφ²) 计算非零 Ricci 分量与标量曲率（f(r) 为多项式）；
  - (c) 代入 Einstein 方程解出 f(r)（含 Λ 的 Schwarzschild–de Sitter 解）；
  - (d) 证明 ∂_t 与 ∂_φ 是 Killing 向量场。
  - 与母题的差异：**必须先做一次「取迹降维」把方程化简**，再完整计算 Ricci 分量（4 个分量），最后解 ODE。计算量最大的一版，但没有「从嵌入导出度规」这一步。
- **2024 n=5（de Sitter 作为 R^{1,n} 中的超曲面）**——**嵌入诱导度规**版本。
  - (a) 证明静态坐标 (t,r,z₂,…,z_n) 是 dS_n 的局部坐标（需验证约束 −(x⁰)²+Σ(xⁱ)² = α² 被满足且变换非退化）；
  - (b) 计算由 Minkowski 度规诱导的 dS_n 度规（得到 ds² = −(1−r²/α²)dt² + dr²/(1−r²/α²) + r²dΩ²）；
  - (c) n=3 时算 Ricci 张量与标量曲率，判断 dS₃ 是否为 Einstein 度量；
  - (d) n=3 时 ∂_t 与 ∂_φ 是否为 Killing 场，证明之。
  - 与母题的差异：**多了「从嵌入方程 + 坐标变换导出诱导度规」这一步**（这是本母题里第一次要求「先导出度规」），且 (c) 明确要求**判定**（是/不是 Einstein 度量），而不是仅仅求解。
- **2026 n=6（Klein 圆盘模型）**——**从距离公式反推度规**版本，且是 Riemannian（正定）而非 Lorentzian。
  - 1. 由 cosh d(x,y) = (1−x·y)/(√(1−x·x)√(1−y·y)) 令 y = x + dx 求出 g₁₁、g₁₂、g₂₂；
  - 2. 换极坐标写出线元 ds²；
  - 3. 求非零 Christoffel 符号；
  - 4. 计算 Riemann 张量分量 R_{rθrθ}；
  - 5. 证明 R_µνρσ = K(g_µσg_νρ − g_µρg_νσ) 并定出 K；
  - 6. 求标量曲率。
  - 与母题的差异：**输入是距离函数而不是度规**（需要用 cosh d 在 y→x 的二阶展开反推 g_ij），而且要求的是**常曲率**而不是 Einstein 条件（二维两者等价，但判定形式不同：R_µνρσ = K(g_µσg_νρ−g_µρg_νσ)）；(6) 还要再算一次标量曲率 R = 2K。

**递进关系（清晰的升级链）。**

```
2022 n=4  只做度规基础操作：逆度规 → 法向量 → l²=0（零超曲面）+ Killing 检验
   │      └ 不涉及 Ricci
2023 n=5  取迹化简 Einstein 方程 → 完整计算 4 个 Ricci 分量 → 解 f(r) + Killing 检验
   │      └ 升级点：完整的曲率张量计算 + ODE 求解
2024 n=5  嵌入超曲面 → 坐标变换 → 导出诱导度规 → 算 Ricci/R → 判定 Einstein + Killing 检验
   │      └ 升级点：多一层「从嵌入导出度规」；并首次出现「是否是 Einstein 度量」的判定式提问
2026 n=6  距离公式 → 二阶展开反推度规 → 极坐标 → Christoffel → Riemann 分量
   │      → 判定 R_µνρσ = K(...) 并求 K → 标量曲率
   │      └ 升级点：输入变成距离函数（最抽象）；判定从 Ricci 层面升到 Riemann 层面
```

**标准解法骨架（7 步）。**

1. **导出度规**：嵌入则用 g_ij = ∂_aX^µ∂_bX^ν η_µν；距离公式则在 y = x+dx 处展开到二阶。
2. 写出逆度规 g^{µν}（对角情形取倒数即可，Klein 圆盘需用共形因子）。
3. 由 Christoffel 公式算非零 Γ（利用对称性与 Killing 结构尽量少算）。
4. 算 Ricci 张量的非零分量（对对角静态度规可用已知的「f(r) ansatz 公式」快速写）。
5. 缩并得标量曲率 R = g^{µν}R_µν。
6. 判定：R_µν = kg_µν（Einstein）或 R_µνρσ = K(g_µσg_νρ−g_µρg_νσ)（常曲率），并定出常数。
7. 收尾：对题给向量场验证 Killing 方程 ∇_µk_ν + ∇_νk_µ = 0（通常化为「度规分量不显含该坐标」）。

**最容易卡住的一步。** **第 1 步（导出度规）与第 6 步（判定）。**
- 2024 n=5 / 2026 n=6 的卡点都在「导出度规」：2026 需要对 cosh d(x, x+dx) 做**一致到 dx 二阶**的展开（一阶项必须在 x = y 处消掉，这正是度量相容性的体现），许多解答在展开 √(1−x·x−2x·dx−dx·dx) 时出错；2024 需要正确算出 ∂X^µ/∂t、∂X^µ/∂r 再做 Minkowski 缩并。
- 第 6 步的卡点是**判定形式**：指标位置极易写错（R_µνρσ = K(g_µσg_νρ − g_µρg_νσ) 里指标配对顺序与曲率张量约定相关），且 K 与 R 的关系是 R = n(n−1)K（二维时 R = 2K）。

### MP-G02 Killing 场：等距方程 ⟺ 协变反对称 ⟹ 沿测地线守恒量

**数学内核。** Killing 方程 k^λ∂_λg_µν + ∂_µk^λg_λν + ∂_νk^λg_λµ = 0 的坐标无关形式是 **D_µk_ν + D_νk_µ = 0**，也就是说 **∇_V X 是反对称算子**。这一个事实是所有推论的唯一来源：物理上，沿测地线 d/dτ(k_µẋ^µ) = (D_µk_ν)ẋ^µẋ^ν = 0，故 **k_µP^µ 守恒**；几何上，对 f = ½|X|² 可得 Hess f 的恒等式并进而由曲率符号排除 Killing 场。母题考的是「**把对称性翻译成守恒量**」这条 Noether 型推理链在最简单情形下的执行。

**成员逐一。**

- **2022 n=3** —— 物理卷唯一成员。(a) 由坐标形式的 Killing 方程证明 D_µk_ν + D_νk_µ = 0（利用度规相容性 D_λg_µν = 0，把偏导数换成协变导数）；(b) 对引力背景中沿测地线运动的粒子，证明 k_µP^µ 是守恒量（P_µ = m·dx^ν/dτ·g_µν）。
- **跨科目成员见 §2.5 XSUB-01**（几何 2019 队赛 n=5）——同一母题的几何分支。

**递进关系。** 物理卷内仅出现一次；但同一数学内核在几何卷以「Bochner 型恒等式」的面貌再出现一次（2019 队赛），构成**跨科目换皮**。

**标准解法骨架（5 步）。**

1. 写出坐标形式的 Killing 方程。
2. 用度规相容性 D_λg_µν = 0，把全部偏导数 ∂_λg_µν 替换为协变导数，得 k^λD_λg_µν + … = 0（或直接展开 D_µk_ν + D_νk_µ 并把三项识别出来）。
3. 得 D_µk_ν + D_νk_µ = 0，即 ∇_V X 反对称。
4. 对自由粒子沿测地线：d/dτ(k_µẋ^µ) = (D_νk_µ)ẋ^νẋ^µ = ½(D_νk_µ + D_µk_ν)ẋ^νẋ^µ = 0。
5. 用 P_µ = m g_µνẋ^ν 改写结论：k_µP^µ 守恒。

**最容易卡住的一步。** **第 4 步中把对称化的那一步**：d/dτ(k_µẋ^µ) 展开后出现的是 (D_νk_µ)ẋ^νẋ^µ，只有把 ẋ^νẋ^µ 的对称性用上、把 D_νk_µ 替换成它的对称部分 ½(D_νk_µ+D_µk_ν)，才能看出它为零。学生常在这里卡住，或者忘了测地线方程本身 ẍ^µ + Γ^µ_{νλ}ẋ^νẋ^λ = 0 也参与了这次相消。

### MP-G03 引力波四极辐射与双星并合时标

**数学内核。** 这是**量纲分析与能量守恒联立**的标准演练：给定四极辐射的振幅公式 h₊、h_×，对圆轨道代入坐标轨迹并两次对时间求导（得到正比于 ω²r² 的振幅），再对全立体角积分 p 得到功率 P（正比于 m²r⁴ω⁶），然后用 **dE/dt = −P** 与 E = −Gm₁m₂/(2r)、ω² = GM/r³ 把 r(t)、f(t) 解出来，积分到 r=0 得并合时标。最后做一次**数量级估计**。

**成员逐一。**

- **2025 n=5** —— 本母题唯一成员。
  1. 双黑洞圆轨道（质心在原点）代入 h₊、h_×，求引力波频率 f；
  2. 对 p 全方向积分并对一个轨道周期平均，求平均辐射功率 P；
  3. 由辐射导致的慢变轨道，从初始 f₀ 求 f(t)；
  4. 由初始间距 r₀ 求并合时间 T_C；
  5. m₁ = m₂ = 10M_⊙ 时，估计「宇宙年龄（10^10 年）内能并合」所允许的最大 r₀（以 au 为单位，量级估计即可）。

**递进关系。** 仅出现一次，无链。

**标准解法骨架（6 步）。**

1. 写出圆轨道轨迹 x₁(t)、x₂(t)（质心系中振幅分别为 (m₂/M)r、(m₁/M)r，频率为轨道频率 ω_orb）。
2. 代入 h₊、h_× 的公式，两次对 t 求导得 h 正比于 (G/c⁴)(μ r²ω_orb²)/L 型；引力波频率 f = 2f_orb。
3. 把 (∂_th₊)² + (∂_th_×)² 对全立体角积分，得 P = (32/5)(G⁴/c⁵)(m₁m₂)²(m₁+m₂)/r⁵（四极公式）。
4. 用轨道能量 E = −Gm₁m₂/(2r) 与开普勒 ω² = G(m₁+m₂)/r³，把 dE/dt = −P 化为 dr/dt 的方程。
5. 分离变量积分：r(t) = (r₀⁴ − 4Ct)^{1/4}，从而 f(t) 与并合时间 T_C = (5/256)(c⁵/G³)·r₀⁴/(m₁m₂M)。
6. 数值估计：令 T_C = 10^10 年，解出 r₀ 并换算为 au。

**最容易卡住的一步。** **第 3 步的角向积分与平均**。p 的公式本身已含 1/(16πG) 与 L² 因子，代入 h 的二次时间导数后要把 θ 依赖（(1+cos²θ)/2 与 cosθ）平方后对 dΩ 积分，并对一个轨道周期取平均。漏掉任一个因子都会让 P 差一个 O(1) 常数；更致命的是第 4 步把 ω 误用为引力波频率（应为轨道频率的 2 倍），而第 5 问是数量级题，这类因子错误会直接给出荒谬的 r₀。

### MP-F01 单圈发散：Feynman 规则 → 维数正规化 → 抵消项与重整化

**数学内核。** 这是量子场论里唯一真正**套路化**的计算：**（i）** 从 L 读出传播子与顶点；**（ii）** 按指定阶画出圈图；**（iii）** 用 Feynman 参数化把分母合并，用题给的 d 维动量积分公式把圈动量积掉，结果写成 **Γ(s − d/2) 的函数**；**（iv）** 在 d = 4 − ε 下把 Γ 的极点展成 **1/ε 极点**（题面直接给出 Γ(z) = 1/z − γ + O(z)）；**（v）** 定义抵消项把极点吸收，写出重整化量或 β 函数。数学实质是「**发散的局部性 + 维数正规化的正则化**」。

**成员逐一。**

- **2023 n=6（φ³ 模型）**——**单场、单发散**版本，是最简起点。
  - (a) 写出动量空间的传播子与相互作用顶点；(b) 用维数正规化计算单圈自能图；(c) 引入 m² = m_R² + δm²，问 δm² 取何值可把单圈自能写成 m_R 的有限函数。
  - 与母题的差异：只有一个发散（质量）、只需一个抵消项；但 φ³ 的自能图积分与 φ⁴ 略有不同。
- **2024 n=6（Yukawa 理论：实标量 φ + Dirac 旋量 ψ）**——**多场、判断可重整性**版本。
  - (a) 找出 φ 的单圈自能图中的所有发散，给出正确的抵消项；(b) 找出 ψ 的单圈自能图中的所有发散，给出抵消项；(c) **是否存在无法重整的发散？**
  - 与母题的差异：要处理**费米子圈**（γ 矩阵求迹、γ⁵ 在维数正规化下的处理），并且首次出现「**判断理论是否可重整**」这一非计算性问题（需要数顶点量纲，判断新出现的发散是否超出原有拉氏量能容纳的算子）。
- **2026 n=5（φ⁴ 模型）**——**四点函数 + 重整化群**版本，链条最长。
  - 1. 写传播子与顶点；2. 用维数正规化计算四点函数的单圈修正；3. 用最小减除求抵消项与一圈阶的重整化耦合；4. **写出耦合常数的重整化群跑动方程（β 函数）**。
  - 与母题的差异：对象从两点函数换成**四点函数**（多一个 Mandelstam 变量的组合），终点从「抵消项」推进到「**RG 跑动方程**」。

**递进关系（清晰的升级链）。**

```
2023 n=6  φ³ 单场 · 单圈自能（两点函数）· 单一质量抵消项 δm²
   │      └ 最小骨架
2024 n=6  Yukawa 双场 · φ 与 ψ 各自的自能 · 费米子圈（γ 矩阵/γ⁵）
   │      + 判断是否存在不可重整的发散（从"算"升级到"判"）
2026 n=5  φ⁴ · 单圈四点函数（比两点多一个运动学变量）
          + 最小减除下的重整化耦合 + 重整化群跑动方程（从"消发散"升级到"跑动"）
```

**标准解法骨架（7 步）。**

1. 从 L 读出传播子（标量：i/(k²−m²+iε)；旋量：i(k̸+M)/(k²−M²+iε)）与顶点因子（含 i、耦合常数与对称因子）。
2. 按指定阶枚举圈图（自能：单圈一个；四点：s、t、u 三个通道）。
3. 写出圈积分，用 Feynman 参数化 (AB)^{-1} = ∫₀¹dx[xA+(1−x)B]^{-2} 合并分母，必要时做动量平移。
4. 用题给的 d 维积分公式积掉圈动量，得到含 Γ(s−d/2)/Γ(s) 的表达式。
5. 令 d = 4 − ε，展开 Γ(s−d/2) 得 1/ε 极点 + 有限部分（用 Γ(z) = 1/z − γ + O(z)）。
6. 定义抵消项（最小减除/重整化条件）吸收极点，写出重整化后的质量或耦合。
7. （进阶）由重整化耦合对能标 μ 的依赖，写出 β 函数与 RG 方程。

**最容易卡住的一步。** **第 4→5 步的 Γ 函数宗量取值与 1/ε 的对应**。常见错误有两个：（i）动力学维数搞错（φ⁴ 的顶点量纲与 φ³ 不同，导致 s − d/2 的具体形式不同）；（ii）在把 Γ(s − d/2) 展开时忘了 π^{d/2} = π²(1 − (ε/2)lnπ + …) 也会带出有限项，从而在**最小减除**下漏掉或错加有限部分。2024 n=6 的额外陷阱是 γ⁵ 在 d≠4 维的处理，以及第 (c) 问需要从**顶点量纲**判断可重整性，纯算积分是回答不了的。

### MP-F02 大 N 展开：O(N) 模型的图计数与 1/N 领头阶

**数学内核。** 对 N 分量标量场，把耦合记成 g₀ = λ₀N，则每张 Feynman 图的值形如 g₀^{V}·N^{L−V}（V 为顶点数、L 为指标圈数），于是**图的 N 幂次完全由图 1 圈的条数与顶点数决定**。固定 g₀ 后取 N→∞，只有**特定拓扑**（平面图/「仙人掌」型）存活。数学实质是**图论计数 + 幂次台账**，而不是任何积分计算。

**成员逐一。**

- **2022 n=6** —— 本母题唯一成员。L = ½∂_µφ_a∂^µφ_a − ½μ₀²φ_aφ_a − (1/8)λ₀(φ_aφ_a)²，a = 1,…,N。
  - (a) 写出传播子与相互作用顶点，并列出到单圈的四点 Feynman 图；
  - (b) 定义 g₀ = λ₀N，计算上一问所有图关于 g₀ 与 N 的阶；固定 g₀ 令 N→∞，列出 1/N 领头阶的图。

**递进关系。** 仅出现一次，无链。（与 MP-F01 共享第一问，但内核不同，见 §4-Q1。）

**标准解法骨架（5 步）。**

1. 写出 O(N) 模型的传播子（δ_{ab} 结构）与顶点（O(N) 张量结构，含 1/N 的记账约定）。
2. 按圈阶枚举四点图（树图 + 单圈：s、t、u 通道 + 单圈蝌蚪修正）。
3. 对每张图数出顶点数 V、动量圈数，以及 O(N) 指标的收缩（每个闭合指标圈贡献一个 N）。
4. 把 λ₀ = g₀/N 代入，写出图值的 g₀、N 幂次。
5. 取 N→∞ 固定 g₀，保留 N 幂次非负且最高的图，即为 1/N 领头阶。

**最容易卡住的一步。** **第 3 步的 O(N) 指标计数**。顶点因子 (φ_aφ_a)² 收缩后会产生 δ_{ab}δ_{cd} 类的指标结构，**每一个闭合的指标圈贡献一个因子 N**，而这些指标圈与动量圈的数目无关。学生常只数动量圈而漏掉指标圈，从而把某张图的 N 幂次算错一阶，最终给出错误的领头阶集合。

### MP-F03 标度/共形不变性：作用量变换、守恒流与量子破缺

**数学内核。** 给定标度（或共形/Weyl）变换律，**直接计算作用量的变化 δS，令其为零，解出使不变性成立的条件**。两条等价的入口：**（i）** 从能量动量张量出发构造膨胀流 s^µ = x_νθ^{µν} 与共形流 K^{λµ} = x²θ^{λµ} − 2x^λx_ρθ^{ρµ}，算 ∂_µs^µ 发现它正比于 θ^µ_µ，于是**守恒等价于 θ^µ_µ = 0**；**（ii）** 对弯曲时空的作用量做 Weyl 变换，求 δS 并解出标度维 Δ 与共形耦合 ξ。数学实质是**变分号下的变换律计算**，最后一问则是「经典不变性为何在量子层面失效」（迹反常）。

**成员逐一。**

- **2022 n=5**——**流与反常**版本。
  - (a) 定义 s^µ = x_νθ^{µν}、K^{λµ} = x²θ^{λµ} − 2x^λx_ρθ^{ρµ}，计算 ∂_µs^µ 与 ∂_µK^{λµ}，说明 θ^µν 需满足什么条件这两个流才守恒；
  - (b) 对给定的含 e^{fσ} 的拉格朗日量（δσ = x^λ∂_λσ + f^{-1}，δφ = (1 + x^λ∂_λ)φ），证明它是标度不变的；
  - (c) 解释为什么经典标度不变的量子场论拉氏量在量子层面可能不再是标度不变的。
  - 与母题的差异：(a) 的入口是**流而非作用量**（不过是同一件事的 Noether 版本）；(b) 的模型自带了 dilaton 型的 e^{fσ} 结构；**(c) 是唯一要求定性解释迹反常的一问**。
- **2025 n=6（共形标量场）**——**完整 Weyl 变换 + 共形耦合 + AdS 等价**版本。
  - 1. 无质量标量场在刚性标度 η→Ω²η、φ→Ω^Δφ 下作用量不变，求 Δ；
  - 2. 局域标度 g_µν→Ω²(x)g_µν、φ→Ω^Δ(x)φ 下 S = −½∫d⁴x√−g g^{µν}∂_µφ∂_νφ 如何变化，能否选 Δ 使其不变？
  - 3. 求 Ricci 标量在 g→Ω²g 下的变换 R̃；
  - 4. 证明加上 ξRφ² 项后局域标度不变性可被恢复，并定出 ξ（**ξ = 1/6**）；
  - 5. 对 ds² = (−dτ²+dx²)/(Hτ)²，证明共形标量等价于一个有质量标量场，并求 m。
  - 与母题的差异：**从"证不变"升级为"求变换律本身"**（第 3 问要求 R̃ 的完整表达式），并且第 4 问的 ξ 与第 5 问的 AdS/CFT 式等价都是新环节。

**递进关系（升级链）。**

```
2022 n=5  从 θ^µν 构造流 → 守恒条件 θ^µ_µ = 0
          + 对一个现成拉氏量验证标度不变性
          + 定性解释迹反常（回答"为什么会破缺"）
2025 n=6  完整 Weyl 变换：先求 R 的变换律
          + 由 ξRφ² 定出共形耦合 ξ = 1/6
          + 在 AdS 型度规上证明等价于有质量场并求 m
          └ 从"检验不变性"升级为"构造不变的作用量 + 变换律的完整推导"
```

**标准解法骨架（6 步）。**

1. 写出变换律（标度：x→λx 或 g→Ω²g，φ→Ω^Δφ）与作用量。
2. 逐项计算变换后的作用量（注意 √−g → Ω^d√−g、g^{µν} → Ω^{−2}g^{µν}）。
3. 令 δS = 0，解出 Δ（无质量标量在 4 维：Δ = 1）。
4. 做局域变换时发现 δS 中多出正比于 (∂Ω)²/Ω² 的非不变项；引入 R 的变换律 R → Ω^{−2}(R − 6□lnΩ − 6(∂lnΩ)²) 来确定如何补偿。
5. 加上 ξRφ² 项，令其非不变部分与 (4) 中多出的项相消，解出 ξ（4 维：ξ = 1/6）。
6. （进阶）在具体度规（AdS/dS 的共形平坦坐标）上做共形变换，把作用量化成平直时空的有质量标量场，读出 m²。

**最容易卡住的一步。** **第 3/4 步「R 在 Weyl 变换下的变换律」**。这是全题最大的技术壁垒：ξ = 1/6 的推导完全依赖 R → Ω^{−2}(R − 6□lnΩ − 6(∂lnΩ)²) 中的**系数 −6**。绝大多数解答会去猜 ξ，或者用「共形平坦时 R 与 □ 的关系」绕过去，一旦代错一个系数就会得到 ξ = 1/4 之类的错误值。第二部分（2022 版）的卡点则是 (c)：必须指出发散需要引入**重整化能标 μ**，而 μ 的引入本身破坏了经典标度不变性（迹反常），仅说「量子涨落」而不提能标是不完整的。

## §2.5 跨科目：几何卷 / 计算卷里的物理内核题

### XSUB-01 【跨科目】Killing 场的一阶恒等式及其推论（与 MP-G02 同一母题的跨科目视图）

**数学内核。** 与 MP-G02 完全一致：**Killing 方程等价于 ∇_V X 反对称**。这一唯一的第一性步骤之后，物理分支走向「沿测地线的守恒量」，几何分支走向「|X|² 的 Hessian 恒等式与曲率符号障碍」。

**成员逐一。**

- **物理 2022 n=3**（`2022_ExamPaper_2022_Mathematical_Physics_22s`，n=3，individual）：(a) 坐标 Killing 方程 → D_µk_ν + D_νk_µ = 0；(b) k_µP^µ 沿测地线守恒。**物理出口**。
- **几何 2019 队赛 n=5**（`2019_Geometry2019_team`，n=5，**team**）：(a) X 为 Killing 场、f = ½|X|²，证明 (Hess f)(V,V) = g(∇_V X, ∇_V X) − R(V,X,X,V)；(b) 若 (M,g) 弱负曲率，则不存在非平凡 Killing 场。**几何出口**。

**递进关系。** 不是升级链，而是**同一内核的两个出口**；几何版的计算量与抽象度更高。

**标准解法骨架。** 同 MP-G02 的第 1–3 步；随后分叉：
- 物理：第 4 步（测地线方程 + 对称化）→ 守恒量。
- 几何：第 4′ 步用 ∇_V grad f = ∇_V∇_X X = R(V,X)X + ∇_X∇_V X（Ricci 恒等式）展开 Hess f；第 5′ 步用 ∇_V X 反对称把一项改写为 |∇_VX|²；第 6′ 步由 R(V,X,X,V) < 0 与 Hess f 的正定性矛盾。

**最容易卡住的一步。** 几何分支的卡点是**在 Ricci 恒等式中正确地把二阶协变导数交换**（∇_V∇_X X − ∇_X∇_V X = R(V,X)X + ∇_{[V,X]}X），并注意到 ∇_X X = ½grad|X|² = grad f；物理分支的卡点同 MP-G02。

### XSUB-02 【跨科目】物理内核：哈密顿动力学的辛结构与保辛数值积分

**数学内核。** 把牛顿方程 q″ = −∇V(q) 改写成哈密顿系统，则**流映射的 Jacobian 满足 ΦᵀJΦ = J**（这正是哈密顿结构的定义性守恒律）；数值方法是否保辛，就看它的单步映射是否满足同一个矩阵方程。数学实质是**辛矩阵的判据 + 一步映射的 Taylor 展开**。

**成员逐一。**

- **计算 2018 n=2**（`2018_applied2018_individual`，n=2，individual）：(a) 把 q″ = −∇V(q) 改写成哈密顿系统并证明相位空间映射是辛的；(b) 证明 velocity-Verlet 格式 p_{n+1/2} = p_n − (Δt/2)∇V(q_n)、q_{n+1} = q_n + Δt p_{n+1/2}、p_{n+1} = p_{n+1/2} − (Δt/2)∇V(q_{n+1}) 既保辛又二阶精度。

**递进关系。** 仅出现一次。**物理卷（2022–2026）从未考过辛性判据**，因此这是计算卷独有的一条物理内核母题——若只看物理卷，会完全错判「哈密顿力学」这一块只在「由 L 求 H、求守恒量、求小振动」这个角度被考过。

**标准解法骨架（5 步）。**

1. 写出哈密顿量 H = p²/2m + V(q) 与哈密顿方程 q̇ = ∂H/∂p、ṗ = −∂H/∂q。
2. 引入 J = [[0,I],[−I,0]]，验证 Hamilton 方程的矩阵形式 u̇ = J∇H(u)。
3. 对 H 作二阶展开，证明线性化流映射满足 ΦᵀJΦ = J（用 H 的 Hessian 对称性）。
4. 对 velocity-Verlet 把三步映射写成复合映射（半个 kick + drift + 半个 kick），逐块验证 ΦᵀJΦ = J。
5. 与精确解对比做 Taylor 展开，验证局部误差 O(Δt³)（全局二阶）。

**最容易卡住的一步。** **第 4 步把格式拆成三个独立映射再逐块验证辛性**。直接对整个三步格式做 Jacobian 会很乱；正解是利用「**辛映射的复合仍是辛映射**」，只需证明 half-kick（p 平移）与 drift（q 平移）各自是辛的。第 (b) 问的二阶精度则必须与显式 Euler（一阶）区分开，不能只验证辛性就算完成。

### XSUB-03 【跨科目】物理内核：Schrödinger 算符的谱等价与半经典（WKB）极限

**数学内核。** 两条独立的物理内核：**（i）** 通过**相似变换**（e^{−φ}·算符·e^{φ}）把 Fokker–Planck 算符、Witten Laplacian 与 Schrödinger 算符互相转化，从而证明三者**同谱**；**（ii）** 把 ψ = A e^{iS/ε} 代入 Schrödinger 方程，按 ε 的幂次分离实部与虚部，得到 Hamilton–Jacobi 方程（O(ε⁰)）与输运方程（O(ε¹)），并由 u = ∇S 的方程讨论经典流形的奇点（焦散）。

**成员逐一。**

- **计算 2013 队赛 n=2**（`2013_TeamProblems2013`，n=2，**team**）：给出 Fu = −Δu − ∇·(u∇φ)、Wu = −Δu + ∇φ·∇u、Su = −Δu + (¼|∇φ|² − ½Δφ)u，要求 (a) 把 F 重写为 −∇·(e^{−φ}∇(e^{φ}u))；(b) 证明三者有相同本征值；(c) 求三者的所有平衡解。
- **计算 2023 n=6**（`2023_Computational_Applied`，n=6，individual）：iε∂_tψ = −(ε²/2)∇²ψ + V(x)ψ，做 WKB 展开 ψ = A e^{iS/ε}，要求 (a) 由渐近展开导出 A、S 的方程；(b) 令 u = ∇_xS，导出 u 的方程，并讨论 u(0,·) ∈ C^∞ 时 u(t,·) 是否始终保持 C^∞。

**递进关系。** 两题内核不同（谱等价 vs 半经典展开），只是同属「量子力学的数学侧面」。**物理卷从未出现这两类题**；物理卷的量子题全部走「算符代数/简并微扰/含时驱动」路线（MP-Q01、MP-Q02、MP-Q03）。

**标准解法骨架（以 2023 为例，5 步）。**

1. 把 ψ = A e^{iS/ε} 代入方程，注意 ∇²ψ 展开后会带出 O(1/ε²)、O(1/ε)、O(1) 三阶项。
2. 分离 ε 的各阶：O(ε⁰) 得 ∂_tS + ½|∇S|² + V = 0（Hamilton–Jacobi）；O(ε¹) 得输运方程 ∂_tA + ∇A·∇S + ½A∇²S = 0。
3. 对 S 取梯度，令 u = ∇S，得 ∂_tu + (u·∇)u = −∇V（无粘 Burgers/Newton 方程）。
4. 用特征线法求解，指出即使初值 C^∞，特征线也可能在有限时间相交（**焦散**），此时 u 出现梯度灾变，不再 C^∞。
5. 结论：WKB 近似在焦散处失效。

**最容易卡住的一步。** **第 3–4 步「为什么光滑初值也会坏掉」**：学生常把 ∂_tu + (u·∇)u = −∇V 当成线性方程从而回答「始终保持 C^∞」。正解是要用**特征线相交**（∇u → ∞ 在有限时间）论证焦散的形成；这是 2013 版所没有的动力学视角。

### XSUB-04 【跨科目】物理内核：波动方程的能量方法与有限传播速度

**数学内核。** 用**能量积分**（在收缩锥/球内对 |u_t|² + |∇u|² 积分）证明有限传播速度；并用「球内能量单调不增」+「有限能量」两个条件**反证超光速行波解不可能有有限能量**。数学实质是**能量估计 + 反证法**，是完全不依赖显式解的定性方法。

**成员逐一。**

- **计算 2013 n=1**（`2013_applied2013_individual`，n=1，individual）：u_tt = Δu 在 R³×R⁺。(a) 解释不连续的行波解在什么意义下仍是解；(b) 构造速度大于 1 的「超光速」光滑行波解 u = v((x−ct)/√(c²−1), y, z) 并证明紧支集解的存在性；(c) 证明球内能量 E(t) = ∫_{|x|≤R−t}(|u_t|²+|∇u|²)dx 单调递减；(d) 证明形如 u = v(x − ct)、|c| > 1 的光滑行波解**不可能有有限能量**。

**递进关系。** 仅出现一次。物理卷中最接近的是 **MP-E03（2025 n=2）**——那里也算波包的单位长度能量 ⟨U⟩，但用的是**近轴梯度展开**而非能量法，且目的是求角动量比而非传播速度，内核不同，**不归并**（见 §4-Q3）。

**标准解法骨架（5 步）。**

1. 写出能量 E(t) = ½∫(|u_t|² + |∇u|²)d³x 与能量恒等式（乘 u_t 分部积分）。
2. 在收缩球 |x| ≤ R−t 上积分，边界通量项可配成 ½∫_{|x|=R−t}|∂_νu − u_t|²dS ≥ 0，得 E′(t) ≤ 0。
3. 由 E(t) ≤ E(0) 与能量在球外的初值为零，得有限传播速度。
4. 对超光速行波解，在随波移动的球上取能量，能量会随球体截面积增长。
5. 与第 3 步的单调性矛盾，故超光速行波解不能有有限能量。

**最容易卡住的一步。** **第 2 步的边界通量符号**。收缩球的边界以单位速度向内移动，面积分里会同时出现 u_t、∂_νu 与法向速度三项；必须把它们配成完全平方 |∂_νu − u_t|² 才能断定符号。若直接对固定球求导会得到额外项而不能断定单调性——第 (c) 问的全部技巧就在这个配平方上。

## §4 存疑：边界情况（拿不准是否同一母题）

以下 6 处按「宁可保守少归并」的原则**没有合并**或**标注为中等置信度**，列出两种解释供后续判断。

### Q1. 2022 n=6（O(N) 模型大 N 计数）是否应并入 MP-F01（单圈发散与重整化）？

- **解释 A（不合并，本报告采用）**：两题的第一问完全相同（写传播子、顶点、列单圈四点图），但**被问的东西不同**——2022 n=6 要求数 N 的幂次取 1/N 领头阶，**完全不需要做任何圈积分**；2026 n=5 要求维数正规化、提取 1/ε 极点、写 RG 方程，**完全不涉及 N**。按 §0 的 E3 规则不合并。
- **解释 B（合并）**：若把母题定义为「φ⁴ 理论的 Feynman 图与单圈修正」，则两者是同一条流水线的两个分支（一个数拓扑、一个算积分），且都在同一段教材里。**若合并，MP-F01 将变成 4 成员、跨度 2022–2026 的超级母题，score 升至 8.0 并跃居第一。**
- **判据提示**：看 2026 n=5 的题面——它连「列出单圈四点图」这一步都没单独占一问（直接要求计算单圈修正），说明命题人认为**画图是外行步骤**；而 2022 n=6 把画图当作核心考点（(a) 问）。这一对比支持解释 A。

### Q2. 2024 n=4 与 2025 n=4 的 Ising 题是否真的同一母题？（已合并，置信度中）

- **解释 A（合并，本报告采用）**：骨架同为「配分函数 → 自由能 → 对 h、T 求导 → 响应函数 → 渐近行为」，且满足换皮测试（把平均场换成 3 自旋精确解，题目与解法自动成立）。
- **解释 B（不合并）**：2024 版的核心是**自洽方程与分岔**（平均场的特有结构，3 自旋模型里根本不存在相变），2025 版的核心是**有限系统的精确枚举与低温涨落**；两者的「卡点」完全不同（一个是 tanh 方程的多根结构，一个是低温极限下保留足够高阶）。按 T2「卡点位置相同」的严格标准，可以判为**两道不同的题**。
- **影响**：若分开，多成员母题数降为 6，孤题数升至 13，MP-S01 从 TOP5 掉出。

### Q3. 2025 n=2（近轴波包）与 2026 n=2（线圈场离轴展开）是否同一母题？

- **解释 A（不合并，本报告采用）**：两题都被迫做「小参数展开 + 用无源条件定下一阶系数 + 估计近似失效」，但**展开的参数不同**（梯度 kσ 对离轴坐标 ρ,z），**方程不同**（波动方程对静磁方程），**出口不同**（光的自旋角动量对感应电场量级）。共享的是「展开技术」这一工具（属 E1 排除项）。
- **解释 B（合并）**：可以抽象出一个母题「**在无源约束 ∇·F = 0 下做多极/梯度展开，得到下一阶修正并估计适用边界**」。两题的第 4 问都在问「近似什么时候失效」，这一问法的高度相似是支持合并的主要证据。
- **判据提示**：若 2026 卷以后再出现一道「展开 + 估边界」题（不论电磁还是别的场），则 B 成立，应立即合并为一个「近似展开与失效判据」母题。

### Q4. 2022 n=5 与 2025 n=6 是否同一母题？（已合并，置信度中）

- **解释 A（合并，本报告采用）**：两者骨架相同（变换 → 算作用量/流的变化 → 令零 → 定条件），对象可替换（θ^µν 流对 ξRφ²），且都以「经典不变性的量子破缺」收尾（2022 显式提问，2025 的第 1 问 Δ 与第 4 问 ξ 是同一件事的不同侧面）。
- **解释 B（不合并）**：2022 n=5(a) 的内核是**由能量动量张量构造共形流并求守恒条件**（一个独立的、非常标准的推导）；2025 n=6 的内核是**Weyl 变换下作用量的不变性与共形耦合**（另一套标准的推导）。两者的技术动作重合度可能低于 60%（2022 几乎不涉及 R 的变换律，2025 完全不涉及能量动量张量）。
- **影响**：若分开，多成员母题数降为 6，MP-F03 从 TOP6 掉出。

### Q5. 2023 n=2 卷面第 1 题（拉格朗日量反推矢势）是否应归入「标度不变性」母题（MP-F03）？

- **解释 A（本报告采用）**：归入 MP-M02（力学类），因为它的主干是「求 H → 配方读 A → 算 B → 找守恒量 → 解轨道」，标度不变性只是 (b)(c) 两个小问。
- **解释 B**：该拉氏量的 1/r² 权重正是**共形力学**的标志，(b)(c) 问的「旋转 + 标度」双对称性与 MP-F03 的标度/共形不变性是同一数学结构，应跨类归并。**若如此，MP-F03 将横跨经典力学与量子场论，成为一条罕见的「标度不变性」纵贯母题。**
- **补充事实**：该题的 A = (2/r²)(−y, x) 给出 ∇×A = 0（r>0），即**除原点外磁场为零**——这说明模型本质上是共形平坦的（无真正的磁场），支持解释 B；但它出现在 2023 卷的力学第 1 题位置，说明命题人视其为力学题，支持解释 A。

### Q6. 2026 n=6（Klein 圆盘）算物理题还是几何题？

- **解释 A（本报告采用）**：归入 MP-G01（物理卷内的几何计算母题），因为它与 2023 n=5、2024 n=5 共享「导出度规 → 算曲率 → 判定特殊曲率性质」这条完全相同的流水线，满足 T1+T2+T3。
- **解释 B**：它是一道纯粹的 Riemann 几何题（正定度量、常曲率），与物理卷其余所有 Lorentzian 题不同；更合理的归属是与**几何卷**中「给定度量算曲率」的题合并，而非与广义相对论题合并。
- **影响**：若按 B，MP-G01 的成员数从 4 降到 3，年份跨度变为 2022–2024。**本报告按 A 归并，并在此标注。**
