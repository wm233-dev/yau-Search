## §0 组卷说明

### 0.1 一句话说明

本卷是**两科各 6 题、全部来自真实真题原文**的重组卷：计算与应用数学卷按"B 家族（数值 PDE/差分格式，17/17 年出场）+ A 家族（数值线代，16/17 年出场）"这条 17 年不变的骨架配比选材；数学物理卷按上游报告 §6 的 **A1–A6 六项 A 档优先级一对一**配比选材（度规 / 曲率 / 拉格朗日与小振动 / Killing / QFT 四步模板 / 谐振子），6 道题各覆盖一项，**不重复、不缺口**。

### 0.2 选题原则（五条，按优先级）

1. **只用真题原文，不改一个条件。** 12 道题的题面全部是 problems_full.json 中某一道真题的完整题面（含全部小问），只做排版还原；组合方式（顺序、分值、限时）是新拟的，题本身不是。
2. **优先"官方解答可核验"的年份。** 计算卷 6 题中 5 题、物理卷 6 题中 3 题来自有官方解答的年份（计算 2020–2022、物理 2022），答案可与官方解答逐行比对；其余 4 题（2024 计算 #6、2024 物理 Q1、2023 物理 Q6、2026 物理 Q6）由本卷自算，并全部过了数值/代数交叉校验。
3. **覆盖骨架考点，而不是覆盖"有趣的题"。** 依据上游两份科目报告的频次表选题：
   - 计算卷：subject_computational.md §1.2 / §2.1 / §2.2 的 47 个末级标签、17 项骨架考点、§6 的 TOP 15 优先级；"B 家族 17/17 年、A 家族 16/17 年"是该科目的两条腿，2020 年后含数值方法类考点（A–F）的题占比升到 **83%**（该科目已收缩为纯数值分析卷）。
   - 物理卷：subject_physics.md §2.3 的跨口径合并优先级表（A1 度规全勤 → A6 谐振子），以及 §1.1"六题 = 六个分支"的稳定约束、§5.1"QFT 是唯一全勤分支（2022–2026 每年 1 题）"。
4. **难易搭配 2 易 / 3 中 / 1 难**，且"难"位给最能拉开区分度的题（计算卷给 FEM 大题，物理卷给 QFT 单圈计算）。
5. **一票否决：给不出可靠答案的题不选。** 见 §5 的换题记录（共 4 道题因此被换掉，其中 2022 物理 Q6 是因为官方解答的关键图在抽取中丢失）。

#### 第 1 题（15 分）对角占优矩阵的范数界 —— 2022 #3

**(a)（4 分）A⁻¹ 存在。** 反证：设 Av = 0 且 v ≠ 0，取 k 使 |v_k| = max_j |v_j| > 0。第 k 行给出 a_kk v_k = −Σ_{j≠k} a_kj v_j，取模并用 |v_j| ≤ |v_k|：
　|a_kk| |v_k| ≤ Σ_{j≠k} |a_kj| |v_j| ≤ |v_k| Σ_{j≠k} |a_kj|。
约去 |v_k| > 0 得 a_kk ≤ Σ_{j≠k}|a_kj|，与 a_kk ≥ Σ_{j≠k}|a_kj| + 2 矛盾。故 A 非奇异。

**(b)（3 分）‖A‖_∞ = 最大绝对行和。** 记 r_i = Σ_j |a_ij|，取 k 使 r_k = max_i r_i。
- 上界：对任意 u，|(Au)_i| ≤ r_i ‖u‖_∞ ≤ r_k‖u‖_∞，故 ‖A‖_∞ ≤ r_k。
- 下界：取 v_j = sgn(a_kj)（‖v‖_∞ = 1），则 (Av)_k = Σ_j a_kj sgn(a_kj) = Σ_j |a_kj| = r_k，故 ‖A‖_∞ ≥ r_k。
两者合并得 ‖A‖_∞ = max_i r_i。

**(c)（4 分）上下界。** 对每个 i：
　r_i = a_ii + Σ_{j≠i}|a_ij| ≤ a_ii + (a_ii − 2) = 2a_ii − 2 ≤ 12（用 a_ii ≤ 7）；
　r_i ≥ a_ii ≥ Σ_{j≠i}|a_ij| + 2 ≥ 2。
故 **2 ≤ ‖A‖_∞ ≤ 12**。

**(d)（4 分）对称情形。** A = Aᵀ ⇒ 奇异值 = |特征值|。由 Gershgorin：|λ − a_ii| ≤ Σ_{j≠i}|a_ij| ≤ a_ii − 2，即 a_ii − (a_ii − 2) ≤ λ ≤ a_ii + (a_ii − 2)，故 **2 ≤ λ ≤ 2a_ii − 2 ≤ 12**。
于是 **‖A‖₂ = max|λ| ∈ [2, 12]**；A 可逆且 **‖A⁻¹‖₂ = 1/min|λ| ∈ [1/12, 1/2]**。

**分档给分细则**
- 满分（15）：四问齐全；(a) 用"最大分量 + 反证"给出一行矛盾；(c) 上下界都用到 a_ii ≤ 7 与 +2；(d) 明确指出 A 对称 ⇒ 奇异值 = |特征值|，并给出 [1/12, 1/2]。
- 部分分：(a) 3 分（若只证明"不可约对角占优 ⇒ 非奇异"而无最大分量论证，给 1 分）；(b) 上下界各 1.5 分；(c) 下界 2 分、上界 2 分；(d) ‖A‖₂ 界 2 分、‖A⁻¹‖₂ 界 2 分（只写 ‖A‖₂ ≤ 12 而未给下界，减半）。
- 零分：把 ‖A‖₂ 直接等同于 ‖A‖_∞；或在 (a) 中默认 A 可逆后再用 Gershgorin（循环论证）。

#### 第 2 题（10 分）幂法的线性收敛与渐近常数 —— 2020 #3

**解题要点。** 记 Q = [q₁, …, q_m]（正交阵，Q⁻¹ = Qᵀ），则 A^k = Q diag(λ_j^k) Qᵀ，

　v^(k) = A^k v^(0)/λ₁^k = α₁q₁ + Σ_{j≥2} (λ_j/λ₁)^k α_j q_j。

因 |λ_j/λ₁| < 1（j ≥ 2），v^(k) → α₁q₁。误差 e^(k) = v^(k) − α₁q₁ = Σ_{j≥2}(λ_j/λ₁)^k α_j q_j，由正交性

　‖e^(k)‖₂² = |λ₂/λ₁|^{2k} ( |α₂|² + Σ_{j≥3} |λ_j/λ₂|^{2k} |α_j|² )。

于是

　‖e^(k+1)‖₂ / ‖e^(k)‖₂ = |λ₂/λ₁| · [ (|α₂|² + Σ_{j≥3}|λ_j/λ₂|^{2(k+1)}|α_j|²) / (|α₂|² + Σ_{j≥3}|λ_j/λ₂|^{2k}|α_j|²) ]^{1/2} → **|λ₂/λ₁|**，

最后一步用 |λ₂| > |λ₃| ≥ |λ_j|（j > 3）与 α₂ ≠ 0。

**分档给分细则**
- 满分（10）：写出 A^k 的谱分解 → v^(k) 的展开 → 明确构造 e^(k) → 用正交性算 ‖e^(k)‖₂² → 取商并说明分母中被 |λ₂| 主导（必须出现 α₂ ≠ 0 的作用）。
- 部分分：展开式 4 分；收敛性（v^(k) → α₁q₁）2 分；渐近常数 4 分（只写"收敛比是 |λ₂/λ₁|"而未算误差商，给 1 分）。
- 零分：只叙述"幂法收敛速度由次大特征值与最大特征值之比决定"而无任何推导。

#### 第 3 题（20 分）扩散方程的 von Neumann 分析（FE 与 CN）—— 2024 #6

**(a)（4 分）L 的精度阶。** 由 Taylor：v_{m±1} = v_m ± h v′_m + (h²/2)v″_m ± (h³/6)v‴_m + (h⁴/24)v⁗_m + O(h⁵)，相加得

　L v_m = (v_{m+1} − 2v_m + v_{m−1})/h² = v″(x_m) + (h²/12) v⁗(x_m) + O(h⁴)，

#### 第 6 题（25 分）悬臂梁的 CG(3) 有限元与先验误差 —— 2021 #6

**(a)（4 分）变分问题。** 取检验函数 v 乘方程并积分，两次分部积分：

　**V = {w : ∫₀¹ (w² + (w′)² + (w″)²) dx < ∞, w(0) = w′(0) = 0}**。

**(b)（5 分）能量极小与等价性。** 令 **F(w) = (1/2)∫₀¹ (w″)² dx − ∫₀¹ f w dx**，**MP**：求 u ∈ V 使 F(u) ≤ F(w) ∀w ∈ V。

**(c)（4 分）CG(3) 格式。** 剖分 0 = x₀ < ⋯ < x_{M+1} = 1，h_j = x_j − x_{j−1}，h = max_j h_j；取

**(d)（6 分）能量范数估计。** Galerkin 正交：∫₀¹ (u − U)″v″ dx = 0 ∀v ∈ V_h³。于是对任意 v ∈ V_h³，

#### 第 4 题（20 分）中心势 αr^k 的圆轨道、稳定性、小振动与 Binet 方程 —— 2024 Q1（本卷自算）

**(a)（2 分）** L = (1/2)m(ṙ² + r²φ̇²) − αr^k。

**(b)（3 分）** p_φ = mr²φ̇ = ℓ 守恒；L_eff = (1/2)mṙ² − V_eff(r)，**V_eff(r) = ℓ²/(2mr²) + αr^k**。

**(c)（4 分）** 圆轨道：V_eff′(r₀) = −ℓ²/(mr₀³) + αk r₀^{k−1} = 0 ⟹ **ℓ² = m α k r₀^{k+2}**（要求 αk > 0，与"α、k 同号"一致）。
角速度 **Ω = ℓ/(mr₀²) = √(αk/m)·r₀^{k/2 − 1}**，周期 **T = 2π√(m/(αk))·r₀^{1 − k/2}**。
（自检：k = −1 时 T ∝ r₀^{3/2}，即开普勒第三定律；k = 2 时 T 与 r₀ 无关，即谐振子等时性。）

**(d)（3 分）** V_eff″(r) = 3ℓ²/(mr⁴) + αk(k−1)r^{k−2}，代入 ℓ² 得 **V_eff″(r₀) = αk(k+2)r₀^{k−2}**。稳定 ⟺ V_eff″(r₀) > 0 ⟺ **k > −2**（且 k ≠ 0；另需 αk > 0 保证圆轨道存在）。

**(e)（5 分）** 径向小振动：m δr̈ = −V_eff″(r₀)δr ⟹ **ω_r = √(V_eff″(r₀)/m) = Ω√(k+2)**，故 **T_r = 2π/ω_r = T_φ/√(k+2)**。
轨道闭合 ⟺ **ω_r/Ω = √(k+2) 为有理数**。特别地 k = −1（√1 = 1，开普勒椭圆精确闭合）与 k = 2（√4 = 2，各向同性谐振子）是仅有的两个"任意（小）扰动下轨道都闭合"的情形（Bertrand 定理）；k = −2 时 √(k+2) = 0（临界、无小振动），k < −2 不稳定。

**(f)（3 分）** 令 u = 1/r，由 F(r) = −V′(r) = −αkr^{k−1} 得 Binet 方程
　**d²u/dφ² + u = −m F(1/u)/(ℓ²u²) = (mαk/ℓ²)·u^{−(k+1)} = r₀^{−(k+2)}·u^{−(k+1)}**。
（自检：k = −1 时右端 = 1/r₀ = u₀，得 u = u₀ + A cos φ，即椭圆；k = 2 时右端 = r₀^{−4}u^{−3}，与各向同性谐振子的标准 Binet 方程一致。）

【校验】_mockC_check.py 第 3 节：数值积分径向运动得 ω_r/Ω = 1.732051 (k=1)、2.000000 (k=2)、2.236068 (k=3)，与 √(k+2) 逐位一致。

#### 第 5 题（20 分）φ³ 模型的单圈自能与质量反项 —— 2023 Q6（本卷自算，含约定声明）

**约定（答卷开头必须写明）**：度规 (−,+,+,+)；传播子 i/(−p² − m² + iε)（等价于 mostly-minus 下的 i/(p² − m² + iε)）；相互作用顶点 **−ig**；单圈自能记作 iΠ；m² = m_R² + δm²；维数正规化 d = 4 − ε、标度 μ，并定义 1/ε̄ = 1/ε − γ_E/2 + (1/2)ln 4π。

**(a)（5 分）**
- 传播子：**i/(−p² − m² + iε)**（三条 φ 线）；
- 相互作用顶点：**−ig**（由 L ⊃ −(1/6)gφ³，三个全同外线使 3!·(1/6) = 1）。

**(b)（10 分）** φ³ 的单圈自能图是"两个三价顶点 + 两条内线"构成的**泡图**（单顶点的 tadpole 在 φ³ 中不合法：三价顶点无法同时容纳两条外线与一条闭合内线）。对称因子 1/2，故

　iΠ(p²) = (1/2)(−ig)² ∫ d^dk/(2π)^d · [i/(k² − m²)]·[i/((k+p)² − m²)] = (g²/2) ∫ d^dk/(2π)^d · 1/[(k² − m²)((k+p)² − m²)]。

用题给的 Feynman 参数化 (AB)⁻¹ = ∫₀¹dx[xA + (1−x)B]⁻² 与 d 维积分公式：

　iΠ(p²) = i·(g²/2)(4π)^{−d/2} Γ(2 − d/2) ∫₀¹ dx [ m² − x(1−x)p² ]^{d/2 − 2}，

即

　**Π(p²) = (g²/16π²)·[ 1/ε̄ − (1/2) ∫₀¹ dx ln( (m² − x(1−x)p²)/μ² ) ] + O(ε)**。

（展开用到 Γ(ε/2) = 2/ε − γ_E + O(ε) 与 [·]^{−ε/2} = 1 − (ε/2)ln(·/μ²)。）

**(c)（5 分）** 极点部分 **Π_div = g²/(16π²)·(1/ε̄)** 与动量、质量都无关（极点是纯 1/ε̄）。由
　p² − m² + Π = p² − m_R² − δm² + Π
的有限性得

　**δm² = Π_div = g²/(16π²)·(1/ε̄)**（MS̄；若用 MS 则 δm² = g²/(16π²)·(1/ε)，常数差归入有限部分）。

重整化后 **Π_R(p²) = −(g²/32π²) ∫₀¹ dx ln( (m_R² − x(1−x)p²)/μ² )**，为有限函数。

**结构自检（答卷里写上会加分）**：① 量纲：g 的量纲为质量，g² 的量纲为质量²，与 δm² 相符；② 极点与 m 无关，符合 4 维 φ³ 超可重整、一圈只出现质量发散的结构；③ 有限部分的 ln(·/μ²) 的 μ 依赖由 m_R(μ)、g(μ) 的运行补偿（这正是"标度不变性被量子修正破坏"的同一件事）。

**分档给分细则**
- 满分（20）：(a) 5 分（传播子 3 分、顶点 2 分，符号必须对）；(b) 10 分（正确的图与对称因子 1/2 共 3 分、Feynman 参数化 3 分、d 维积分与 Γ 展开 2 分、给出 1/ε̄ 结构 2 分）；(c) 5 分（识别极点的性质 2 分、δm² 3 分）。
- 部分分：(b) 若把图取成单顶点 tadpole（对 φ³ 不合法），最多 2 分；(b) 漏掉对称因子 1/2，扣 2 分；(c) 只写"δm² 抵消发散"而无表达式，给 1 分。
- 零分：把 φ³ 的顶点写成 φ⁴ 的 −iλ（或把对称因子按 φ⁴ 的记账方式代入）；或把自能图画成单顶点的 tadpole（三价顶点无法同时容纳 2 条外线与 1 条闭环内线）并据此计算；或符号约定前后不一致（前半用 (−,+,+,+)、后半用 mostly-minus）导致 Π 与 δm² 相差整体符号。

#### 第 6 题（15 分）Klein 圆盘的度规、联络与曲率 —— 2026 Q6（本卷自算 + 数值校验）

**(1)（3 分）** 记 r² = x·x、A = 1 − r²。取 y = x + dx，展开到 |dx|²：
　cosh d = 1 + (1/2)[ |dx|²/A + (x·dx)²/A² ] + O(|dx|³)，
而 cosh d = 1 + ds²/2 + O(ds⁴)，故
　**ds² = |dx|²/(1 − r²) + (x·dx)²/(1 − r²)²**，即
　**g_ij = δ_ij/(1 − r²) + x_i x_j/(1 − r²)²**：g₁₁ = 1/(1−r²) + x₁²/(1−r²)²，g₂₂ = 1/(1−r²) + x₂²/(1−r²)²，g₁₂ = x₁x₂/(1−r²)²。

**(2)（2 分）** x·dx = r dr、|dx|² = dr² + r²dθ²，故
　**ds² = dr²/(1 − r²)² + r²dθ²/(1 − r²)**，即 g_rr = (1−r²)^{−2}、g_θθ = r²/(1−r²)、g_rθ = 0。

**(3)（3 分）** **Γ^r_{rr} = 2r/(1 − r²)，Γ^r_{θθ} = −r，Γ^θ_{rθ} = Γ^θ_{θr} = 1/(r(1 − r²))**，其余为零。

**(4)（3 分）** 由 R^ρ_{σμν} = ∂_μΓ^ρ_{νσ} − ∂_νΓ^ρ_{μσ} + Γ^ρ_{μλ}Γ^λ_{νσ} − Γ^ρ_{νλ}Γ^λ_{μσ}：
　**R^r_{θrθ} = −r²/(1 − r²)**，　**R_{rθrθ} = g_rr R^r_{θrθ} = −r²/(1 − r²)³**。

**(5)（2 分）** g_{rr}g_{θθ} = r²/(1−r²)³，而 g_{rθ}g_{θr} − g_{rr}g_{θθ} = −r²/(1−r²)³，与 R_{rθrθ} 成常数比，故常曲率形式成立，**K = −1**。
最简洁的验证：令 ρ = artanh r（dρ = dr/(1−r²)），则 **ds² = dρ² + sinh²ρ dθ²**，而 ds² = dρ² + f(ρ)²dθ² 的曲率为 K = −f″/f = −1。

**(6)（2 分）** 二维时 R = 2K，故 **标量曲率 R = −2**（也可由 R = 2g^{rr}g^{θθ}R_{rθrθ} 直接算得）。

【校验】_mockC_check.py 第 1 节：Christoffel 解析式与"对度规数值微分再求联络"的结果最大偏差 ≤ 3.6e−10；R^r_{θrθ} 数值 = −r²/(1−r²)、R_{rθrθ} = −r²/(1−r²)³、R = −2.000000（r = 0.2/0.5/0.8 三点全部命中）；r/√(1−r²) = sinh(artanh r) 逐点验证。

- 满分（15）：(1) 3 分（展开到二阶 2 分、读出度规 1 分）；(2) 2 分；(3) 3 分（三个符号各 1 分）；(4) 3 分（公式套用 2 分、值 1 分）；(5) 2 分（比例常数与 K 值各 1 分）；(6) 2 分。
- 部分分：(1) 只保留 |dx|²/A 而漏掉 (x·dx)²/A² 项，扣 2 分（度规错）；(2) 漏掉 r²dr²/(1−r²)² 的合并，扣 1 分；(4) 只给 R^r_{θrθ} 不换算 R_{rθrθ}（或反之），不减分但必须标明下标位置。
