> 给分总原则：**关键构造与关键引理分开给分**；只写结论、或方向性错误（结论错误）者零分；结论正确但缺 1–2 个论证环节者给部分分；论证正确但书写有小瑕疵者不扣（除特别注明）。

### A1（2021 Q2，12 分）Aut of the splitting field of x³ − 3x + 1 over Q

**关键步骤**
1. f 在 Q 上不可约：三次多项式无有理根即可。f(1) = 1 − 3 + 1 = −1 ≠ 0，f(−1) = −1 + 3 + 1 = 3 ≠ 0，故无一次因子，不可约。取一根 α，则 [Q(α) : Q] = 3；分裂域 E ⊇ Q(α)，故 [E : Q] = |Gal(E/Q)| 是 3 的倍数，且 Gal(E/Q) 是 S₃ 的传递子群（同构于 S₃ 或 A₃ = Z/3Z 的某个子群）。
2. 判别式：对 g = X³ + pX + q，disc(g) = −4p³ − 27q²。这里 p = −3, q = 1，故 disc = −4(−27) − 27 = 108 − 27 = **81 = 9²**（本报告脚本已复核）。
3. disc 是 Q 中的平方 ⟺ Gal(E/Q) ⊆ A₃（因为 Gal 的奇偶性由 disc 是否为平方决定）。于是 |Gal| 整除 |A₃| = 3，又 [E : Q] = |Gal| ≥ 3（f 不可约），故 |Gal| = 3。
4. 因此 **Aut(E/Q) = Gal(E/Q) ≅ Z/3Z**（3 阶循环群）。附带：disc > 0 说明三个根全实，复共轭不给出新自同构。

**最终答案**：Aut(E/Q) ≅ Z/3Z（循环 3 阶）。

**分档给分**：正确判定不可约并说明理由 3 分；写出 disc(g) = −4p³ − 27q² 并算得 81 4 分；由"disc 是平方 ⟺ 含于 A₃" + 次数 3 定出循环 3 阶 5 分。
**部分分**：算对 disc = 81 但未用之（2–4 分）；用"三个实根"直接断言 Gal 循环（缺 A₃ 论证，扣 3 分）。
**零分**：答 S₃ 或 A₃ 之外的群；只写"答案是 Z/3Z"无论证。

### A2（2022 Q1，12 分）Rational root theorem + Q(√2, √3) = Q(√2 + √3)

**(a) 关键步骤**
设 p(a/b) = 0（在 K 中）。两边乘 b^n 得
  a_n a^n + a_{n−1} a^{n−1} b + ⋯ + a_1 a b^{n−1} + a_0 b^n = 0.   (★)
在 R 中对 (b) 取模：b | a_n a^n；对 (a) 取模：a | a_0 b^n。
"互素"有两种口径，两种都能收口，**答卷里必须声明用哪一种**：
- **口径 I（理想互素：(a) + (b) = R）**：取 u, v ∈ R 使 ua + vb = 1，则 1 = (ua + vb)^n 展开式中每一项都含 a^n 或 b，故 a^n R + bR = R。由 b | a_n a^n，写 1 = x a^n + y b 并乘以 a_n：
  a_n = x(a_n a^n) + y(a_n b) ∈ bR，即 **b | a_n**。同理 a | a_0。

### A3（2021 Q1，16 分）x^p − x − a 在 F_p 上不可约且可分

**关键步骤（不可约性，12 分）**
1. 设 α 是 x^p − x − a 在代数闭包中的一个根，则 α^p = α + a。用归纳法：**α^{p^k} = α + k a**（k ≥ 1）。
2. Frobenius 轨道：因为 F_p 是素域、a ≠ 0，映射 k ↦ ka 在 F_p = Z/pZ 中单射，故 {α, α + a, α + 2a, …, α + (p−1)a} 是 **p 个互不相同的元素**。这 p 个元素恰好是 x^p − x − a 的全部根（代入验证：(α + ka)^p − (α + ka) − a = α^p + ka − α − ka − a = 0）。
3. 由 Frobenius（生成 Gal(F̄_p/F_p)）的作用，这些根全是 α 的共轭；轨道长度 p ⟹ α 在 F_p 上的极小多项式次数为 p。该极小多项式首一、次数 p、以 α 为根 ⟹ 它整除 x^p − x − a，次数相同，故二者相等，**x^p − x − a 在 F_p 上不可约**。
   （等价写法：Artin–Schreier 定理——特征 p 域上 x^p − x − a 或有一次根或不可约；而 x ∈ F_p 时 x^p − x − a = −a ≠ 0 无根，故不可约。）

**关键步骤（可分性，4 分）**：A′(x) = p x^{p−1} − 1 = −1（特征 p 下 p = 0），是单位，与 A 互素 ⟹ A 无重根 ⟹ 可分。

**分档给分**：Frobenius 迭代 α^{p^k} = α + ka 4 分；轨道有 p 个元素 4 分；由轨道长度 = 极小多项式次数得不可约 4 分；可分性（求导 = −1，与 A 互素）4 分。

**零分**：结论写成"在 F̄_p 上可约/分裂"；或不分可分性且未提特征 p 求导。

### A4（2020 Q3，16 分）R = F[x, y]/(y² − x² − x³) 的整性判定与正规化

**(a) 8 分：R 是整环**
把 y² − x² − x³ = y² − x²(1 + x) 看作 F[x][y] 中关于 y 的二次多项式。它在 F(x)[y] 中不可约（若有根则 y = ±x√(1+x) ∈ F(x)，但 1 + x 在 F[x] 中不是平方：次数为 1）；又它在 F[x][y] 中是本原的（两个系数的 gcd 为 1），由 Gauss 引理它在 F[x][y] = F[x, y] 中不可约。F[x, y] 是 UFD，不可约元是素元，故 (y² − x² − x³) 是素理想，商环 **R 是整环**。

**(b) 8 分：正规化**
记 K = Frac(R)，t = y/x ∈ K（x ≠ 0，因为 x 不是零因子）。由关系 y² = x²(1 + x) 与 y = tx 得 t² x² = x²(1 + x)，约去 x² 得
  **t² = 1 + x**,  于是 **x = t² − 1, y = t x = t³ − t**.
- 因为 t² = 1 + x ∈ R，所以 t 在 K 中整于 R；于是 F[t] ⊆ R̄（R̄ 记 R 在 K 中的整闭包）。
- 反向：K = F(t)（上面已得 x, y ∈ F(t)，故 Frac(R) ⊆ F(t) 且显然 F(t) ⊆ K），而 F[t] 是 PID 因而在其分式域 F(t) 中整闭；由 R ⊆ F[t] 得 R̄ ⊆ (F[t] 在 F(t) 中的整闭包) = F[t]。
故 **R 的正规化 = F[t] = F[y/x]**，它是多项式环；几何上即把有结点的三次曲线 y² = x²(1+x) 在结点 (0,0) 处的两个分支分开的参数化 t ↦ (t² − 1, t³ − t)。

**分档给分**：(a) 不可约性论证 6 分（"1 + x 不是平方"2 分 + Gauss 引理/本原性 2 分 + UFD 中不可约 ⟹ 素、商环为整环 2 分），书写 2 分；(b) 求出 t² = 1 + x 并显式写出 x, y 4 分，双向包含（t 整 + F[t] 整闭）4 分。

### A5（2024 Q1，16 分）有限群的忠实表示

   括号内的几何和为 n（当 n | k）或 0（当 n ∤ k）。
3. 于是：k = 0 时 ⟨x_n, φ_0⟩ = ∫_0^{2π} x = 2πc（与 n 无关）；k ≠ 0 且 n ∤ k 时内积恰为 0；k ≠ 0 且 n | k 时等于 ∫_0^{2π} x(v) e^{−ikv/n} dv → ∫_0^{2π} x = 2πc（控制收敛）。
   因此对每个固定的 k，n > |k| 时 ⟨x_n − c, φ_k⟩ = 0 ⟶ 0。
   （数值复核：n = 5 时 ⟨x_n, e^{ikt}⟩ 仅当 5 | k 时非零，且等于 ∫_0^{2π} x(v) e^{−ikv/5} dv，与理论一致。）
4. 三角多项式在 L²([0, 2π]) 中稠密，{x_n} 一致有界，故对一切 ψ ∈ L² 有 ⟨x_n − c, ψ⟩ → 0。

**最终答案**：x_n ⇀ c（常数函数），其中 **c = (1/2π)∫_0^{2π} x(t) dt**（x 的均值，即其第 0 个 Fourier 系数）。

**分档给分**：换元 + 几何和正交性（得到"n ∤ k 时为 0、n | k 时为 ∫x(v)e^{−ikv/n}dv"）8 分（漏掉几何和的这一步最多 4 分）；由稠密性 + 一致有界延拓到全 L² 6 分；正确写出极限 c（而非 0）2 分。
**部分分**：只证明"存在弱收敛子列"（2–3 分）。
**零分**：断言极限是 0（漏掉 k = 0 分量）；或断言逐点/强收敛（一般均不成立）。

### An5（2022 Q5，16 分）外部调和函数的 |x|u(x) 极限

**关键步骤（Kelvin 变换 + 可去奇点，n = 3）**
1. 不妨设 Ω ⊂ B_{1/2}（平移缩放不影响结论）。对 0 < |y| < 2 定义
   **ṽ(y) := |y|^{2−n} u(y/|y|²) = u(y/|y|²)/|y|**（n = 3）。
   Kelvin 变换保持调和性，故 ṽ 在去心邻域 0 < |y| < 2 上调和。
2. 去心邻域上的调和函数结构（可去奇点定理的定量形式）：存在在 0 的整邻域上调和的 h 与常数 c，使
   **ṽ(y) = h(y) + c |y|^{2−n}**（n = 3 即 h(y) + c/|y|）。
3. 换回 u：由 x = y/|y|² ⟺ y = x/|x|²，得
   u(x) = |x|^{2−n} ṽ(x/|x|²) = |x|^{2−n} h(x/|x|²) + c.
   令 |x| → ∞：h(x/|x|²) 有界 ⟹ 第一项 → 0；而题设 u(x) → 0，故 **c = 0**。
4. 于是 u(x) = |x|^{2−n} h(x/|x|²)，h 在 0 附近连续 ⟹ **|x| u(x) = h(x/|x|²) → h(0)（|x| → ∞）**，极限存在。
5. （可选的显式值）由 Green 表示 u(x) = ∮_{∂Ω}[u(y) ∂_{ν_y}Φ(x − y) − Φ(x−y) ∂_ν u(y)] dS(y)（Φ(x) = 1/(4π|x|)，ν 为 Ω 的外法向）与 1/|x − y| = 1/|x| + O(|x|^{−2})（y ∈ ∂Ω）得
   **lim_{|x|→∞} |x| u(x) = −(1/4π) ∮_{∂Ω} (∂u/∂ν) dS = (1/4π) ∮_{∂Ω} (∂u/∂ν_in) dS**（ν_in 指向 Ω 内部）。
   自检：Ω = B_1、u = 1/|x| 时 ∮_{∂B_1} ∂_r(1/r) dS = −4π，得极限 = 1，与 u 的显式行为一致。

**分档给分**：Kelvin 变换（指数 2 − n 正确、说明保持调和）4 分；去心球上调和函数的分解（或等价的可去奇点论证）6 分；用 u → 0 消去常数项并得出极限存在 4 分；显式值或自检 2 分。
**部分分**：只证出 u(x) = O(1/|x|)（例如用极值原理比较）而无极限存在性（8–10 分）；只给"h(0) 即极限"而未说明 h 有界（扣 2 分）。
**零分**：直接假设 u 在无穷远有展开 u = A/|x| + B/|x|² + ⋯ 并取 A；或把 u → 0 直接当成 |x|u → 0。

### An6（2025 Q2，28 分）Hardy 不等式与最佳常数

**(1) 12 分：不等式（顺带得到 C = 4/(n−2)²）**
1. 散度恒等式：∇·(x/|x|²) = n|x|^{−2} − 2|x|^{−2} = **(n − 2)|x|^{−2}**。
2. 先设 u ∈ C_c^∞，supp u ⊂ B_R。对向量场 u² x/|x|² 在环域 {δ < |x| < R} 上用散度定理，展开得
   ∇·(u²x/|x|²) = 2u (∇u·x)/|x|² + (n − 2)u²/|x|²。
   外边界 |x| = R 上 u = 0；内边界 |x| = δ 上的项 ≤ ‖u‖_∞² ω_n δ^{n−1}/δ = O(δ^{n−2}) → 0（**这里用到 n ≥ 3**）。故得 Hardy 恒等式
   (n − 2)∫ u²/|x|² dx = −2∫ u (∇u·x)/|x|² dx.
3. Cauchy–Schwarz：
   (n−2)∫u²/|x|² ≤ 2(∫u²/|x|²)^{1/2}(∫|∇u|²)^{1/2} ⟹ ∫u²/|x|² ≤ (4/(n−2)²)∫|∇u|².
4. 由 C_c^∞ 在 H¹(R^n) 中稠密（n ≥ 3 时成立，可用径向截断 χ_k(x) = ψ(k + log|x|) 验证 ‖∇χ_k‖_2 → 0），取 u_k → u 于 H¹，沿子列 a.e. 收敛，对非负被积函数用 Fatou：
   ∫u²/|x|² ≤ liminf ∫u_k²/|x|² ≤ (4/(n−2)²) lim ∫|∇u_k|² = (4/(n−2)²)∫|∇u|².
   （顺带得到 u²/|x|² ∈ L¹(R^n)。）
5. 临界性说明：n = 2 时 |x|^{−2} ∉ L¹_loc，取 u ≡ 1 于 B_1（支在 B_2 内）左端发散、右端有限，不等式不成立——这就是题设 n ≥ 3 的原因。

**(2) 16 分：最佳性（常数不能再小，且取不到）**
1. 取 η ∈ C_c^∞(R^n)，0 ≤ η ≤ 1，η ≡ 1（|x| ≤ 1）、η ≡ 0（|x| ≥ 2）。对 0 < ε ≤ (n−2)/4 令
   **u_ε(x) = |x|^{−(n−2)/2 + ε} η(x)**，记 α_ε = (n−2)/2 − ε > 0，则 u_ε = |x|^{−α_ε} η。
2. u_ε ∈ H¹：在 B_1 上 u_ε² /|x|² = |x|^{−n+2ε}，∫_{B_1}|x|^{−n+2ε}dx = ω_n/(2ε) < ∞；|∇u_ε| = α_ε|x|^{−α_ε−1}，∫_{B_1}|∇u_ε|² = α_ε² ω_n/(2ε) < ∞；在 1 < |x| < 2 上两项都是 O(1)（对 ε ≤ (n−2)/4 一致）；|x| ≥ 2 上为 0。
3. 于是
   ∫u_ε²/|x|² = ω_n/(2ε) + O(1),  ∫|∇u_ε|² = α_ε² ω_n/(2ε) + O(1),
   比值 = (1/α_ε²)(1 + O(ε)) → **1/((n−2)/2)² = 4/(n−2)²**（ε → 0⁺）。
4. 故任何使不等式成立的常数 C 必满足 C ≥ 4/(n−2)²；结合 (1) 得 **C_opt = 4/(n−2)²**。
5. 取不到（加分点）：Cauchy–Schwarz 取等要求 u 是临界齐次的 |x|^{−(n−2)/2}，而 ∫(|x|^{−(n−2)/2})²/|x|² = ω_n∫_0^∞ r^{−1}dr = +∞，该函数不属于 H¹(R^n)，故最佳常数不可达（与 Poincaré 不等式最佳常数由第一特征函数取到形成对照）。

**分档给分**：(1) 12 分 = 散度恒等式 3 + 内边界项消失（显式用到 n ≥ 3）3 + Cauchy–Schwarz 4 + 稠密性/Fatou 2。(2) 16 分 = 临界函数族构造 5 + B_1 上两个积分的计算 7 + 取比值与 ε → 0 4。
**部分分**：(2) 构造出 |x|^{−(n−2)/2+ε}η 但积分算错（8–10 分）；只说明"下确界 ≤ 4/(n−2)²"而未说明任意 C 必须 ≥ 该值（扣 4 分）。
**零分**：(2) 用 u = |x|^{−(n−2)/2} 作为极值函数（该函数不在 H¹ 中）；(1) 用 n = 2 的论证（漏掉内边界项不消失这一步）。

## §4 本卷失分预警（最容易踩的坑，按题）

**A1**：把"disc 是平方"直接当成 Gal 循环的**充分**条件（还必须有 [E:Q] = 3 / f 不可约）；把问题当成求 Aut(Q(α)) 而不是分裂域的自同构群。判别式公式记成 +4p³ + 27q² 会得到 −81（不是平方），直接导致答成 S₃。

**A2**：(a) 是本题最大的坑——**"relatively prime" 在一般整环上没有唯一含义**，用"约去"时必须说明依据（理想互素的 Bézout 论证，或 UFD 上的 Gauss 引理）；此外不要假设 R 是 UFD 却不声明。(b) 只验证"t 满足某二次方程"不足以证明两域相等，必须**双向包含**。

**A3**：最典型的错误是"x^p − x − a 在 F_p 中无根 ⟹ 不可约"（这只排除一次因子；对合数次数甚至完全不成立）。必须走 Artin–Schreier/Frobenius 轨道。第二个坑是**忘记可分性**（特征 p 下易被忽略求导这一步，而它恰好给出 −1，是最简单的一分）。

**A4**：(a) 只画图说"曲线不可约"不给代数论证；(b) 把 t 取成 x/y（它**不整**于 R，F[x/y] 不是整闭包），或只证 F[t] ⊆ R̄ 而不证 R̄ ⊆ F[t]。整闭包的证明必须**两步**：t 整 + F[t] 在其分式域中整闭。

**A5**：(3) 只做单方向（"G 交换 ⟹ 可同时对角化 ⟹ 嵌入 (C^×)^n"），缺"生成元个数 ↔ 对偶群生成元个数"这一步；(4) 的坑有两处：忘记"平均内积 ⟹ 共轭进 O(2)"（直接分类 GL_2(R) 的有限子群很难），以及**漏掉 Klein 四元群**（D_2）与 D_1 的记号约定。千万不要把 Q₈ 列进来。

**A6**：(c) 降次时 p = b − a²/3 = 8 − 48 = −40 是唯一容易算错的地方（12²/3 = 48，不是 36 或 144）；(d) 与 (e) 之间不得循环论证——必须先有"无平方因子 ⟹ 整基"的一般判据，再回头看 1957 = 19 × 103 无平方因子。另外注意 (c) 问的是基 {1, θ, θ²} 的判别式（= disc(f)），不是域判别式 d_K（二者在本题恰好相等，但那是 (e) 的结论，不能提前使用）。

**An1**：(b) 的 E 可能有无穷测度，直接用 1_E ∈ L¹ 是漏洞（需先取 E ∩ B_R）。此外 (b) 的结论是"包含 0 的**开邻域**"，写成"包含一个正测度集"不得分。

**An2**：漏掉二重根对应的 r ln r 项（只写 A r + C/r 会用三个条件解不出）；把 Euler 方程按常系数方程处理（得到 e^{kr}）。注意 r = 1 是常点，三阶方程三个条件唯一确定解——**不写唯一性会被扣 1 分**。

**An3**：直接在无界带形域上引用最大模原理（结论在无界区域上不自动成立）；忘记"f 有界"这条假设的用途（它保证 g 有界，才能做 e^{εz²} 截断）；指数方向写反（A_0^{z−1}A_1^{−z} 与 A_0^{1−z}A_1^{z} 差一个符号，会造成 0 分与 6 分的区别）。

**An4**：最经典的失分是**漏掉 k = 0 分量而答"极限是 0"**（正确极限是均值）。其次是用"逐点收敛"或"强收敛"替代弱收敛（一般都不成立）。几何和 Σ_j e^{−2πikj/n} ∈ {0, n} 是本题的"题眼"，不做这一步基本拿不到 8 分里的一半。
