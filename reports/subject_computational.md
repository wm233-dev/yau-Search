### 1.4 17 年**从未考过**的内容（按"教科书章节"排查）

以下条目在 27 份应用/计算卷（段）的全部题面中**找不到任何直接对应**（检索 + 逐题阅读双重确认）：

1. **快速变换算法**：FFT 从未作为算法被考（2019 团队 #2 只把 DFT 当作不确定性原理的对象）。
2. **稀疏矩阵与稀疏直接法**：没有稀疏存储、稀疏 Cholesky/LU、填充（fill-in）相关题。
3. **预处理（preconditioning）**：共轭梯度只考过一次（2011 团队 #1），从不涉及预条件子。
4. **多重网格（multigrid）**：从未出现。
5. **蒙特卡洛 / 拟蒙特卡洛 / 随机算法**：从未出现（这是一个 17 年的空白，值得注意）。
6. **压缩感知 / LASSO / 近端算法 / ADMM**：**在计算卷中从未出现**；LASSO 只在 2013 概率团队 #5、2015 概率团队 #1 的统计卷里出现（跨科目邻近考点，见 §3.4）。
7. **随机数值线性代数 / 随机化 SVD**：从未出现。
8. **深度学习 / 反向传播 / 自动微分 / 随机梯度下降**：从未出现（2018 团队 #5 的次梯度法是"经典凸优化"，不是 SGD）。
9. **有限体积法 / ENO-WENO / 通量限制器 / 熵条件**：从未出现；守恒律高阶格式只考过 Lax–Wendroff 型构造一次（2022 #5）。
10. **谱方法 / 谱元 / 边界元**：从未出现（Chebyshev 只用于插值与求积）。
11. **无矩阵方法、并行/GPU、复杂度类（P/NP）**：从未出现；"复杂度"只在 2010 个人 #5（O(n²)/O(pn²)）、2024 #1（O(n) flops）出现。
12. **反问题正则化（Tikhonov/TSVD）**：从未出现（2016 团队 #2 是逆谱问题，不是正则化）。
13. **符号计算 / 计算机代数系统**：只有 2014 个人 #2 的 gcd(f, X^N−1) 快速算法一件。
14. **偏微分方程的自动网格 / 自适应加密（AFEM）**：从未出现。
15. **计算几何 / 凸包 / Delaunay**：从未出现。
16. **图论与组合算法（在计算卷中）**：2013/2015/2018 考过多次，但 **2018 年之后彻底消失**（J4 标签最后一年 = 2018）。

### 3.2 该科目的"固定套路"（8 条可背诵的流程模板）

1. **求 CFL 数模板**（出现 ≥5 次）：写出格式 → 代入 Fourier 模态 u^n_j = g^n e^{ijkΔx} → 得放大因子 g(θ) → 求 max|g(θ)| ≤ 1 的 λ 上界 → 报 λ0。（2011T#2、2012I#3、2016I#1/T#1、2017T#2、2024#5）
2. **能量法稳定模板**：乘以 u_j 求和 → 分部求和（离散 SBP）→ 边界项配平 → 得 dE/dt ≤ 0 或 E^{n+1} ≤ E^n。（2010T#5、2014I#3/T#3、2017I#5、2018I#1、2023#5）
3. **"求系数使格式二阶精确"模板**：Taylor 展开 + 匹配 1、Δx、Δx² 项 → 三个线性方程定 a,b,c；再用 Fourier 定 λ0。（2011T#2、2016T#1、2017T#2）
4. **SVD/奇异值模板**：A=UΣVᵀ → 用 U、V 的正交性把范数化成 Σ 的函数 → 取前 k 项。（2010I#6、2012I#4、2015T#5、2021#4、2025#4）
5. **谱半径判收敛模板**：迭代 x_{k+1}=Mx_k+c 收敛 ⟺ ρ(M)<1；对角占优/SOR 则用行和与 |1−ω| 上界估计 ρ(M)。（2012T#3、2014I#4、2017I#4、2019T#3、2022#2/#3）
6. **不动点/Newton 收敛阶模板**：写出 φ 或误差递推 → 比较 φ′(x*)、φ″(x*) 是否为 0 → 定线性/二次/多点法的最高阶。（2017I#2、2020#2、2021#3、2025#1）
7. **有限元误差估计模板**：变分形式 → Galerkin 正交性 (u−u_h ⊥ V_h) → Céa 引理 → 插值误差 → 能量范数 O(h^k)；再用对偶（Aubin–Nitsche）得 L² O(h^{k+1})。（2012T#2、2013I#4、2021#6、2026#1）
8. **凸性/一阶方法模板**：下降引理 → 展开 ‖x_{k+1}−x*‖² → 望远镜求和 → 得 O(1/k) 或 O(L²α/2) 界。（2016I#5/T#5、2018T#5、2019T#4、2026#2）

### 3.3 已退役的方法（别把复习时间压在这上面）

- **数论/组合算法**（Fibonacci 快速幂、RSA 因数分解、gcd 快速算法、Eisenstein 多项式、乘性相关、Siegel 引理、图的 Hamilton 性/匹配/超立方体谱）：**2018 年后再未出现**，共 16 题次集中在 2012–2018。
- **Minkowski 问题/等周不等式/图论 resigning** 等"应用几何"题：2015 年后再无。

### 3.4 跨科目邻近考点（本卷不考、但同一年别的卷在考）

- **LASSO / 软阈值 / 高维稀疏恢复**：2013 概率团队 #5（"the lasso procedure is to obtain an estimate of the parameter vector β through minimizing … ½‖Y−Xβ‖₂² + λ·‖β‖₁" `[原文]`）、2015 概率团队 #1。
- **GLM 的 MLE 局部二次展开与 Hessian 谱界**：2024 概率统计 #4（与 2026 #2 的 Newton/BFGS 是同一套工具的另一面）。
→ 若目标是"高维统计计算"，必须同时准备概率统计卷；计算卷自身 17 年只给到"核范数 + 次梯度 + VC 维 + 不确定性原理"这一步。

## 7. 上游报告纠错（逐条：原文说法 / 核实结果 / 证据）

我核对了 6 份批次报告中与本科目相关的全部段落；以下 6 条为**可复现的事实错误或数据缺陷**，另有 3 条口径问题单列。

### 纠错 1｜2019 团队 #3(iii) 的收敛条件

- **原文说法**（`report_2019_2021.md` §1.4 表内）："分块矩阵 A=[[I,X],[Xᵀ,O]]：非奇异、特征值由 X 的奇异值给出、Richardson 迭代收敛条件 …… 收敛要求 ‖X‖₂<√2（本报告推算）"。
- **我的核实结果**：**不成立**。迭代 x_{n+1}=x_n−(Ax_n−b) 的迭代矩阵是 I−A；A 的特征值为 λ_±(σ_i)=(1±√(1+4σ_i²))/2（另有 λ=1，重数 n−m）。对负支 λ_−(σ)<0 有 |1−λ_−|=(1+√(1+4σ_i²))/2 > 1（只要 σ_i>0）。因此 **ρ(I−A)>1 对一切非零 X 成立，迭代永不收敛**——不是"‖X‖₂<√2 时收敛"。
- **证据**：数值扫描（numpy，脚本 archive/work/_num.py）：σ₁=0.1 时 ρ(I−A)=1.0099；σ₁=1.0 时 1.6180；σ₁→0⁺ 时 ρ(I−A)→1.00000001（即**只在 X=0 的退化情形**才趋于收敛）。随机 3×3（σ_max=0.914）得 ρ(I−A)=1.5416。该报告只检查了正支 λ_+ 且把判据写成了 |λ_+−1|<1（σ<√2），漏掉负支。
- **备注**：原始题面只问 "Under what conditions on X would the iteration converge…"，未给答案；因此这是报告自身推算的错误（其自己标注了"本报告推算"）。
