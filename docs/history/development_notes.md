# Development notes — 这批材料是怎么做出来的

> 这是一份**过程记录**，不属于研究报告主体。研究结论见 [../FINAL_REPORT.md](../FINAL_REPORT.md)。
> 保留它的原因：说明数据的来路、口径变更史，以及哪些结论是人工判断而非脚本计算。

## 1. 总体做法

语料分析由多个独立分析单元并行完成，每个单元负责一个年代段、一个科目或一项专项任务，
各自通读自己范围内的全部题面后产出报告。**所有报告都写明了数据口径与存疑清单。**

| 批次 | 数量 | 产出 |
|---|---|---|
| 年代段分析 | 6 | 每 3 年的逐卷结构表、考点频次、代表题、风格变化 |
| 科目综合报告 | 6 | 六科横向综合（考点频次、演变、孪生题、优先级 TOP15） |
| 解题讲义 | 3 | 三科各 10 道真题的完整解答 |
| 对抗性审稿 | 3 | 对上述讲义的逐题复核（含数值复算与反例） |
| 总决赛分析 | 3 | 总决赛 2012–2025 的分科分析 + 与初赛的差异对比 |
| 考纲覆盖 | 1 | 319 条考纲的逐条命中统计 |
| 母题归并 | 6 | 六科全部 757 题的母题归类 |
| 模拟卷 | 3 | 六科仿真模拟卷（含答案与评分标准） |
| 学习路线 | 1 | 考点 → 书目 → 章节 → 真题的 12 周路线图 |

## 2. 数据口径变更史（重要）

`data/problems_full.json` 在整理过程中被修订过三次，**各报告自述的题量因此可能不同**：

| 版本 | 题数 | 改动原因 |
|---|---|---|
| v1 | 757 | 初版：单一正则切题 |
| v2 | 758 | 修正 2024 分析卷的编号识别 |
| v3 | 751 | 合并因公式换行产生的碎片小问（部分碎片被并进相邻题） |
| v3 修订 | **757** | 修正团体卷科目标题识别（2013 团体卷的 "Probability and Statistics Problems" 标题未匹配，导致概率 6 题被并入应用段） |

**结论**：以 `data/problems_full.json` 的 **757** 为准；报告里出现 751 / 758 的地方是旧快照口径。

## 3. 制作过程中发现并修正的既有错误

| 级别 | 内容 |
|---|---|
| 数据缺陷 | 多科目团体卷切分损坏：2013/2016/2017/2018 团体卷的「最后一题」吞掉整份剩余内容，**丢掉约 80 道题**（已在统一流水线中修复） |
| 数据缺陷 | 2025/2026 数学物理卷被按题内编号切碎 |
| 数据缺陷 | 2013 团体卷概率段被并入应用段 |
| 事实错误 | 某报告称 2023 代数 Q1 中 GL₂(F₃) 不可解 —— 实为可解（2T 有唯一正规 2-Sylow Q₈，2T/Q₈ ≅ C₃） |
| 事实错误 | 某报告把 Witt 向量记成 2021 代数 Q6 的工具 —— 实际只在 2020 代数官方解答里出现 |
| 事实错误 | 2024–2026 报告里的 t^4047 应为 t^4051 |
| 事实错误 | 2022 物理 Q2 分值 35 → 25；2024 物理小问数 36 → 24 |
| 事实错误 | 「2020 概率官方解答 P3 自相矛盾」是误判（p=0 时游走恒为 −1，必然命中） |
| 覆盖缺口 | 总决赛目录里的 .doc / .docx / .JPG 原卷被整个漏掉（7 卷 + 4 卷），导致 2012–2014 分析/几何/概率卷全空 |
| 覆盖缺口 | 2020 年 3 份加密 PDF 被误判为「无文字层」，实际公开口令可解 |
| 判断偏差 | 「chars < 800 就是扫描件」不成立：多数只是「一题一张纸」的短卷 |

以上每一条都在对应报告的「上游纠错」章节有完整记录与证据。

## 5. 诚实的边界

* 所有「解题思路 / 解答」除 2020–2022 官方解答外，都是**本项目独立推导**，已经过一轮对抗性审稿，
  但**不保证零错误**；审稿报告已标出高风险题目。
* 逐条人工判断的部分（母题归并、难度 1–5、复习优先级）**含主观性**，各报告都给出了判定口径，
  请把它们当作「有依据的建议」而不是「标准答案」。
* 语料中的公式损伤是**系统性**的，任何依赖精确符号的结论都应回原卷核对。
