# RECOVERED from DOCX (2014 Geometry (Team).docx, math in OMML)
S.-T Yau College Student Mathematics Contests
Geometry and Topology, Team, 2014
1. Let phi: S^2 -> T^2 smooth map, show any top de Rham cohomology class v in H^2(T^2), we have phi*v = 0.
2. f: D^2 -> D^2 homeomorphism, Show f must map boundary point to boundary point. (D^2 closed unit disc)
3. Let w1, w2, ..., wk be one-forms. Show wi linearly independent if and only if w1 ^ ... ^ wk != 0.
4. Show every map F: S^n -> S^{n1} x ... x S^{nk}, k >= 2, n1 + ... + nk = n, nj > 0 has degree 0.
5. Proof any smooth map f: CP^n -> CP^n has a fixed point.
6. Let M be the closed surface generated by carrying a small circle with radius r around a closed and knotted curve C embedded in R^3 such that the center moves along C and the circle is in the normal plane to C at each point. Show that integral over M of H^2 dsigma >= 4 pi^2.
