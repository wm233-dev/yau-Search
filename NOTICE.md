# NOTICE — third-party material and copyright scope

This repository contains two different kinds of material.

## 1. Original work (covered by the MIT licence in `LICENSE`)

* all source code under `scripts/`
* the data-processing pipeline, taxonomy, tagging rules and analysis logic
* the original analysis text written for this project, including
  `reports/*.md`, `docs/*.md` and the commentary embedded in them
* the generated search page `yau_index.html` and the JSON schemas under `data/`

## 2. Third-party material (NOT covered by the MIT licence)

* **Contest problems** — the text under `corpus/` and the problem statements
  stored in `data/problems_full.json`, `data/problems_enriched.json`,
  `data/papers.json` and the `data/mother_*.json` files are transcriptions of
  the *S.-T. Yau College Student Mathematics Contests* papers (2010–2026
  preliminary rounds, 2012–2025 final rounds).
* **Official solutions** — the solution texts included in the same files for
  the years in which the organisers published them (2020–2022 preliminary;
  a few final-round papers).
* **Official syllabi** — the six syllabus documents transcribed into
  `corpus/finals/`.
* **Rendered page images** — `data/render/*.png` and
  `archive/dumps/images/*.png` are renderings of pages of those papers.

The copyright of all of the above remains with the competition organisers and
the original authors. This repository claims no rights over it, does not
relicense it, and includes it only to make the problems searchable and
citable for study and research purposes.

If you are a rights holder and want a file removed or amended, please open an
issue in this repository and it will be handled promptly.
